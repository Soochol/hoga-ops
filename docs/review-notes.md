# 날짜별 자유 캔버스 복기 노트

상단 **복기 노트 작성**에서 연다. 왼쪽 날짜 목록은 복기 대상일의 최신순이다.
과거 노트를 수정해도 날짜 순서는 바뀌지 않는다. **이전 기록 / 다음 기록**은 빈 날짜를
건너뛰며 양 끝에서는 비활성화한다. 날짜 선택기로 빈 날짜를 열어도 자동 생성하지
않으며 **이 날짜에 작성하기**로 시작한다. **오늘 작성**은 KST 기준 기존 노트를 이어 연다.

목록 제목 옆 아이콘에서 **간단히**(날짜·제목·상태)와 **자세히**(종목·기존 하루 결론 포함)를
고른다. 마지막 선택은 브라우저에 저장해 새로고침·앱 재실행에도 유지한다. 검색은 제목·
종목·기존 하루 결론·날짜를 대상으로 하며, 캔버스의 모든 글을 검색하는 기능은 아니다.

## 자유롭게 작성

새 날짜는 **빈 페이지**에서 시작한다. 텍스트·메모·이미지·도형·화살표를 원하는 위치에
놓고 크기·색·글자 크기를 바꾼다. 글은 더블클릭으로 편집하고 이미지 파일 드롭과 붙여넣기도
지원한다. **템플릿**의 하루 결론·잘한 판단·바꿀 행동·다음 원칙은 선택해서 추가하는 메모다.
필수 항목이 아니며 이름·내용·위치·크기를 바꾸거나 삭제해도 된다.

- **연필**: 차트 위를 포함한 캔버스에 자유롭게 그린다. 선 색상·직접 색상 선택·굵기를 지원한다.
- **지우개**: 문지른 **연필 선 전체**를 지운다. 이미지·텍스트·도형과 잠긴 선은 보존한다.
  잠긴 페이지 안의 선도 지우지 않는다. 이미지나 메모 삭제에는 선택 도구와 Delete를 사용한다.
- **실행 취소 / 다시 실행**: 편집기 하단 버튼 또는 Ctrl/⌘ Z, Ctrl/⌘ Shift Z를 사용한다.
  지우개 한 번의 드래그도 한 작업으로 되돌린다. 저장된 결과는 유지되지만 실행 취소 이력은
  현재 편집기 세션 범위이며 새로고침·날짜 재진입 뒤까지 보장하지 않는다.
- **페이지 추가**: 기존 내용을 남기고 옆에 새 빈 페이지를 추가한다. 하단 페이지 버튼으로 이동한다.
  각 페이지는 같은 자유 캔버스의 프레임이다. 전체 보기는 페이지 밖 객체까지 포함한다.
- **읽기로 전환**: 배치 편집을 막고 이동·확대로 읽는다. **수정**으로 다시 편집한다.
  **복기 완료**는 하루 정리를 마쳤다는 표시이며 서버의 **저장됨** 상태와 별개다.

편집기는 Excalidraw의 선택 속성·그룹·잠금·확대·실행 취소 도구를 함께 제공한다.
미리보기의 도구 배치는 실제 편집기의 기본 도구 모음과 이 부분에서 다르다.

## 기존 내용 보존

기존 날짜별 노트를 처음 열면 글·기록·이미지를 페이지 1에 한 번 펼친다. 원래 제목·하루
결론·판단·행동·결과·마무리 문장은 원래 review 필드에도 그대로 보존한다. **기존 기록 원문**은
그 당시 구조의 읽기 화면이다. 이후 캔버스에서 바꾼 글을 원문에 역으로 덮어쓰지 않는다.
변환 표시는 페이지 프레임에 저장하며, 페이지를 지워도 원문을 자동으로 중복 추가하지 않는다.
캔버스를 변환한 문서는 원문 글과 캔버스 내용을 합쳐 문서 크기 제한을 적용한다.

기존 schema 1 자유 배치 보드는 **기존 보드**에서 그대로 열며 URL·내용을 유지한다.
날짜별 노트는 같은 schema 2·whiteboards API·revision·IndexedDB 초안 계약을 사용한다.
다른 창과 충돌하면 원본을 덮지 않고 **내 편집을 별도 노트로 저장**으로 복구한다.
자동 저장·장애·초안 복원은 [화이트보드 저장 안내](whiteboard.md#저장과-복구)를 따른다.

## 이미지·차트·백업

**차트/이미지 추가**, 파일 드롭, 이미지 붙여넣기로 원본 해상도를 보존해 추가한다.
한 장 최대 16MB/24MP, 문서 최대 12MB, 편집 파일 가져오기 이미지 최대 100장 제한을 유지한다.
차트의 **복기 노트에 추가**는 실제 PNG와 Code·봉 주기·캡처 시각·종목 복귀 링크를 객체에
보관한다. 종목 링크는 `/live?code=`를 열며 당시 기간·지표 상태를 복원하지 않는다(ADR-0157).

국내 종목 **분봉**의 버튼은 클릭한 창에 실제 보이는 마지막 거래일의 노트를 열거나
만들어 다음 다섯 영역을 자동 첨부한다. 코스피·코스닥 분봉은 각각 전체 폭으로 위아래에 놓는다.

1. 해당 거래일의 코스피 5분봉
2. 같은 거래일의 코스닥 5분봉
3. 코스피·코스닥의 외인·기관·개인 당일 누적 순매수 표(억원)
4. 종목 일봉·거래량(기본 최근 실제 60봉, 분봉의 거래일 강조)
5. 현재 보이는 종목 분봉·보조지표·그리기

각 영역은 별도 고정 PNG이며 한 페이지 안에서 겹치지 않게 세로로 배치하고 묶어 이동한다.
개별 편집은 캔버스의 그룹 내부 선택·그룹 해제를 사용한다. 내용이 있는 페이지는 유지하고
새 페이지를 추가하며, 빈 페이지가 있으면 먼저 사용한다. 종목 분봉 원본의 해상도를 유지한다.
일봉은 분봉과 같은 가격 시장을 사용하고 REST 우회 중 KRX 외 시장에 KRX 일봉을 대신 쓰지 않는다.
분봉이 60거래일보다 넓으면 그 날짜들을 포함하도록 일봉 범위를 넓힌다.

순매수는 시장별 기준을 표시한다. 과거는 제공된 일별 확정 이력(현재 API의 최근 120일)에
같은 날짜가 있을 때만 사용하며, 당일은 확정치 또는 마지막 잠정 표본의 KST 시각을 남긴다.
미제공 값은 **미제공**, 확인된 0은 **0**으로 구분하고 조회 실패·빈 자료·일부 조회 경고를
각 이미지에 표시한다. 일부 자료가 없어도 나머지 영역을 보존한다. 재시도는 차트에서 다시
추가한다. 캡처 시각과 복기 대상일은 별도로 보관하며 첨부 후 시세로 이미지를 갱신하지 않는다.
그 외 봉 주기·지수·미국 종목은 기존 한 장 첨부와 대상 노트 선택 방식을 유지한다.

**PNG 내보내기**는 현재 캔버스 전체를 이미지로 만든다. **더보기 → 편집 파일 내보내기**는
글·이미지·그림·배치·원문을 `.whiteboard.json`으로 보관한다. 기존 보드의 가져오기에서
원본을 덮지 않고 새 날짜별 노트 사본으로 복원할 수 있다. 휴지통 이동·복원에서도 유지한다.
사용자 서버에 예시 차트나 노트를 자동 생성하지 않는다.

## 안내와 외부 링크

성공·저장 오류·충돌 안내는 캔버스 위의 하단 패널로 표시한다. 안내를 열고 닫거나
재시도해도 캔버스의 위치·높이는 바뀌지 않는다. 실제 저장 실패·복구 동작은 유지한다.

웹페이지 자체를 실행하는 임베드는 지원하지 않으며 해당 도구를 메뉴에서 숨긴다.
이전 버전에서 생성되어 저장에 실패한 임베드 초안은 다시 열 때 주소가 든 링크 메모로
바꿔 저장한다. 원래 주소·위치·그룹·잠금·삭제 상태를 유지하며 외부 페이지를 자동 접속하지 않는다.
일반 텍스트나 객체의 웹 링크는 계속 사용할 수 있다.

캔버스 도구·추가 도구·선 색상의 툴팁은 다른 페이지의 공통 텍스트 툴팁을 사용한다.
도구명·단축키를 유지하며 500ms 호버와 키보드 포커스로 표시하고 Esc·누르기·스크롤로 닫는다.
