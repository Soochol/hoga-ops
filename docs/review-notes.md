# 날짜별 복기 노트

상단 **복기 노트 작성**에서 연다. 왼쪽 날짜 목록을 누르면 읽기 화면이 바로 열린다.
목록은 복기 대상일의 최신순이며, 과거 노트를 수정해도 날짜 순서는 바뀌지 않는다.
검색은 제목·종목명·하루 결론·날짜를 대상으로 한다. 날짜 선택기로 빈 날짜를 열어도
문서를 자동 생성하지 않으며 **이 날짜에 작성하기**를 눌러 시작한다.

## 읽기와 이동

- 헤더의 **이전 기록 / 다음 기록**은 작성된 문서만 순서대로 이동한다. 빈 날짜는 건너뛴다.
- 본문 아래에도 인접 기록으로 가는 버튼이 있다. 마지막 기록에서는 해당 방향을 비활성화한다.
- 종목별 기록의 썸네일·제목을 누르면 당시 판단·행동·결과와 이미지를 펼친다.
  **전체 펼치기 / 전체 접기**도 제공한다. 이미지는 눌러 크게 볼 수 있다.
- 같은 브라우저·서버에서 노트별 펼침 상태와 읽기 스크롤 위치, 마지막으로 선택한 문서를 기억한다.
- 왼쪽 목록 제목 옆 아이콘에서 **간단히**(날짜·제목·상태)와 **자세히**(종목·하루 결론 포함)를
  고른다. 마지막 선택은 브라우저 localStorage에 저장해 새로고침·앱 재실행에도 유지한다.
  저장소를 차단했다면 안내하며 현재 화면의 선택은 사용할 수 있다.

## 매일 작성

**오늘 작성**은 KST 날짜의 활성 노트를 이어 연다. 같은 날 여러 창에서 동시에 시작해도
하나의 기존 문서를 반환한다. 가져온 사본이나 충돌 복구본이 같은 날짜에 있으면 생성 시각이
빠른 활성 문서를 기본으로 연다. 사본은 목록에서 따로 열 수 있다.

**수정**에서 제목·하루 결론·잘한 판단·바꿀 행동·다음 원칙을 입력한다. **기록 추가**로
종목 없는 관찰도 남길 수 있다. 종목 코드는 선택 사항이며 완성된 6자리만 반영한다.
기록 제목·종목명과 당시 판단·행동·결과를 편집할 수 있다. 삭제한 기록은 같은 편집
화면의 **삭제 취소**로 복구할 수 있고 이미지 파일은 서버에서 자동 삭제하지 않는다.

**차트/이미지 추가**, 파일 드롭과 이미지 붙여넣기는 각 이미지를 새 종목 기록으로 추가한다.
이미지 자체의 원본 해상도는 보존한다. 노트당 기록 최대 200개, 이미지 한 장 최대 16MB/24MP,
문서 최대 12MB를 적용한다. 복기 대상일과 이미지의 캡처 시각은 다른 값이다.

**복기 완료**는 정리를 마쳤다는 표시다. 서버 저장 성공을 뜻하는 **저장됨**과 구분한다.
완료 후에도 **수정**으로 다시 편집할 수 있다. 자동 저장·오프라인 초안·다중 창 충돌 시
복구본으로 보관하는 절차는 [기존 저장·복구 안내](whiteboard.md#저장과-복구)와 같다.
날짜 이동 중에도 저장 세션은 살아 있으며 앞선 저장 응답이 최신 입력을 지우지 않는다.

## 라이브 차트 연결

차트 도구의 **복기 노트에 추가**에서 복기 대상일이나 기존 노트를 고른다. 실제 차트 PNG,
종목 코드·봉 주기·캡처 시각을 기록으로 보관한다. 종목 차트 열기는 `/live?code=`로 이동하며
같은 과거 기간이나 지표 상태를 복원하지 않는다. 별도의 저장 학습뷰 계약은 변경하지 않는다.

## 보존과 호환

- 기존 `/whiteboard?board=<id>` 북마크는 기존 자유 배치 보드를 그대로 연다.
- **기존 보드**는 기존 캔버스·PNG 내보내기·가져오기 기능을 유지한다. 기본 목록에는 날짜별
  복기 노트만, 기존 보드 목록에는 자유 배치 보드만 표시한다.
- 새 노트는 서버 `whiteboards/boards/`의 schema 2이며, 기존 보드는 schema 1로 읽고 쓴다.
  UI 표시 옵션은 문서 내용에 섞어 저장하지 않는다.
- **더보기 → 편집 파일 내보내기**는 글과 이미지가 포함된 `.whiteboard.json`을 만든다.
  기존 보드의 가져오기에서 새 노트 사본으로 복원할 수 있다. 원래 문서를 덮어쓰지 않는다.
- **더보기 → 휴지통으로 이동**, 왼쪽 **휴지통**, **더보기 → 노트 복원**을 지원한다.
  사용자 서버에 예시 노트를 자동 생성하지 않는다.
