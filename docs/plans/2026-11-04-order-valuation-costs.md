# 호가주문의 수수료·세금 반영

호가주문 설정의 `수수료·세금 반영`은 기본 OFF다. ON이면 이 창의 상단 보유분 손익과
`보유종목` 표를 사용자 입력 매도비용 기준의 추정치로 표시한다. 표의 평가금액은
`순매도 예상금액`, 손익은 `예상손익`으로 표시한다. 다른 창과 공급자 잔고는 바뀌지 않는다.

## 계산 계약

현재 표시시장 시세 P, 전체 보유수량 Q, 공급자 원본 소수 평단가 A를 사용한다.
주문 입력수량과 매도가능수량은 평가 수량이 아니다.

- 총평가액 G = P × Q
- 추정 매도 수수료 F = floor(G × 입력 수수료율 / 100)
- 추정 매도 거래세 T = floor(G × 입력 거래세 합계율 / 100)
- 순매도 예상금액 N = G − F − T
- 원본 매입원가 C = A × Q
- 예상손익 = ceil(N − C), 예상수익률 = (N − C) / C × 100을 소수 둘째 자리에서 표시

비용은 각각 원 미만을 버린다. 손익은 기존 계약대로 원 단위 올림이며 음수도 +∞ 방향이다.
수익률은 정확한 손익·매입원가의 비율을 반올림하고 동률이면 0에서 먼 쪽을 택한다.
금액·수량은 BigInt 정수, 평단가·율은 decimal 문자열로 계산한다. 안전한 정수 표시 범위를
넘으면 추정하지 않는다. 유효하지 않은 평단가에는 손익·수익률을 표시하지 않는다.

예시 입력 P=10,000원, Q=10주, A=9,000.125원, 수수료율=0.01%, 거래세율=0.2%이면
G=100,000원, F=10원, T=200원, N=99,790원, C=90,001.25원이다.
예상손익은 9,789원, 예상수익률은 10.88%다. OFF의 손익은 9,999원, 11.11%다.
이 예시의 비율은 계좌에 자동 적용하는 비율이 아니다.

키움의 원본 평단가는 `pur_amt` 합계/보유수량이며 매입금액이 없으면 `pur_pric`으로
대체한다. 토스는 `averagePurchasePrice`를 전달한다. 두 wire 모두 매입 수수료 포함 여부를
명시하지 않으므로 원본을 그대로 쓰고 매입비용을 추가 차감하지 않는다. 평단가 원의
정본 호가 연결과 주문 생성·정정·취소·매수 가능 금액·입력줄 `금액`은 그대로다.

## 적용률과 저장 범위

저장소에는 계좌별 적용률 엔진이 없다. 체결의 `commission`/`tax`는 과거 체결비용이며
미래 매도율로 역산하지 않는다. 로컬 모의매매도 수수료를 계산하지 않는다.

수수료율과 거래세 합계율은 사용자가 확인한 추정치로 입력한다. 빈칸·잘못된 입력은
미확인이다. 0은 사용자가 면제를 확인한 값이다. 두 값 모두 0~100%, 소수 6자리까지,
합계 100% 이하만 계산한다. 미완성 입력도 저장해 이전 정상율이 조용히 남지 않게 한다.
미보유 0주·잔고 미수신·조회 실패에는 상단 손익을 비우고, 보유중 손익 0원은 표시한다.

율은 창별 `OrderWindowSettings` 안에서 계좌 ID의 타입/값·증권사·실전/모의·상장시장·
상품·표시시장·주문경로·KST 날짜별로 보관한다. 같은 범위의 일반주식은 같은 입력률을
사용한다. KOSPI/KOSDAQ과 KRX/NXT/UN 시세시장, KRX/NXT/SOR 주문경로를 구분한다.
새 날짜나 다른 범위에는 다시 확인해야 한다. 최근 64개 범위를 보관한다.
창별 저장·마지막 편집 설정의 새 창 복사·프리셋 스냅샷은 기존 경로를 사용한다.
기존 주문 설정에는 별도 되돌리기 버튼이 없으며 토글 OFF로 기존 계산을 복원한다.
프리셋 복원은 마지막 편집 설정을 덮어쓰지 않는다.

ETF/ETN과 상품·상장시장 미확인은 추정 평가를 지원하지 않는다. 거래세 면제 여부만으로
보유기간 과세를 계산할 수 없기 때문이다. ON 상태에서 비용을 확인할 수 없는 종목은
총평가액으로 대체하지 않고 값 대신 `—`를 표시한다. 설정에 미지원 사유를 안내한다.
최소수수료·실제 정산·체결시장 배분·슬리피지·양도/배당소득세는 추정 범위 밖이다.

## 금융 근거

코드에 증권사 기본요율이나 법정세율을 내장하지 않았다.

- [키움 ETF주문종합 안내](https://download.kiwoom.com/hero4_help_new/0220.htm)는
  현재가 평가금액과 매도시 수수료·세금을 구별한다. 이 기능은 보유분의 순매도 예상액만
  표시하며 예수금 등을 합친 추정자산을 제공하지 않는다.
- [토스증권 국내주식 거래설명서 변경표](https://home-files.tossinvest.com/files/notice/f489f890-98e5-4356-816e-5d1d14c16dab.pdf)는
  2025-12-29 시행 문서에서 일반주식과 ETF/ETN 거래세, 매매차익·과표차익에 따른 과세를
  구별한다. 이 문서의 세율을 모든 계좌·거래일·상품에 적용하지 않는다.
- [키움 ETN 안내](https://www.kiwoom.com/m/domestic/stock/VEtnMainView)는 ETN의
  상품 성격과 과세를 설명한다. 상품의 거래세 면제와 전체 세금 면제를 구분하는 근거다.
