# 호가주문의 매도비용 기본값과 평가

`수수료·세금 반영` 토글은 기본 OFF다. 이름은 ARIA와 화면 읽기 전용 라벨에만 남긴다.
비용 영역의 제목·설명·주의·도움말과 관련 호버 툴팁은 표시하지 않는다. ON이면 짧은
`수수료 (%)`·`세금 (%)` 입력만 표시한다. 기존 버튼은 우측에
`미체결 주문` → `보유종목` → `내 체결` 순서로 배치한다.

## 기본 수수료의 비교 기준

2026-11-04에 아래 공식 자료를 직접 읽었다. 비교 기준은 일반 온라인 현금 국내주식
매도, 단일 100만원 약정, 온주, 온라인 전용 계좌의 기본 HTS/웹/자체 MTS 요율이다.
신규 첫달 우대·이벤트·협의·한시 0원·오프라인·ARS·소수점 수수료는 제외했다.
세 표본은 이 기준에서 금액 구간이나 정액 가산액이 없는 비례 요율이다.

0.014%다. 시장 점유율 가중 평균이나 전체 증권사 평균이 아니며 실제 계좌 적용률을
조회한 값도 아니다. SOR은 체결시장 배분을 알 수 없으므로 두 중앙값 중 큰 0.015%를
사용한다. 수수료는 주문경로를 따르며 UN/NXT 표시 시세만으로 체결경로를 추론하지 않는다.

## 법정 세금 기본값

세금은 증권사 평균을 사용하지 않는다. 2026년 일반 상장주식의 매도 거래세 합계율은
KOSPI 0.05% 증권거래세 + 0.15% 농어촌특별세 = 0.20%, KOSDAQ은 거래세 0.20%다.

- [증권거래세법 시행령 제5조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0005&lsiSeq=280901&urlMode=lsScJoRltInfoR): 2026-01-02 시행 현행 조문, 2025-12-31 개정을 포함하며 유가증권 1만분의 5, 코스닥 1만분의 20.
- [농어촌특별세법 제5조 제1항 제5호](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0005&lsiSeq=285905&urlMode=lsScJoRltInfoR): 2026-05-12 시행 현행 조문, 증권 양도가액의 1만분의 15.
- [농어촌특별세법 시행령 제5조 제1항](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0005&lsiSeq=280835&urlMode=lsScJoRltInfoR): 해당 증권시장을 유가증권시장으로 정한다.
- [토스 국내주식 거래설명서](https://home-files.tossinvest.com/files/notice/f8b692a8-2b29-46c4-b279-f6bf865e64d5.pdf): 2025-12-29 심의 문서. NXT는 KOSPI/KOSDAQ 상장주식을 거래하는 플랫폼이며 별도 상장시장이 아니다. 일반주식 세목과 ETF/ETN 과세 차이도 구분한다.

세금은 종목의 실제 상장시장을 사용한다. KRX/NXT/UN 가격시장이나 KRX/NXT/SOR
주문경로를 KOSPI/KOSDAQ으로 해석하지 않는다. 내부 기본값 모델에 검토일 2026-11-04,
유효범위 2026-01-01~2026-12-31과 시장별 세목을 보존한다. 이 범위 밖의 새 날짜에는
자동율을 제공하지 않으며, 2027년 이후의 세율을 가정하지 않는다. 세법 변경 시 이
모델을 다시 검토해야 한다. ETF/ETN과 상품·상장시장 미확인은 계속 미지원이다.

## 저장·누락·전환

율은 창별 `OrderWindowSettings`에 계좌 ID 타입/값·증권사·실전/모의·상장시장·상품·
시세시장·주문경로·KST 날짜별로 보관한다. 기존 수동 필드는 기본값보다 우선한다.
명시적 0, 지운 빈칸, 미완성/오류 입력도 덮어쓰지 않는다. legacy에서 필드 자체가
없으면 해당 필드만 기본값으로 채운다. 날짜나 범위가 바뀌면 새 범위의 기본값으로
바로 계산하므로 매일 재확인 문구나 추가 동작은 없다. 이전 범위 수동값은 보존된다.
최근 64개 수동 범위를 보관한다. 창별 독립·마지막 편집 설정 복사·프리셋 깊은 복사는
기존 경로를 따른다.

미보유·잔고 미수신/조회 실패에는 상단 손익을 비운다. 비용 미확인/입력 오류·미지원은
gross나 성공한 0으로 대체하지 않는다. 비율 필드는 `aria-invalid`로 상태를 전달하고
미지원 입력은 비활성화한다. 화면에 별도 비용 설명은 만들지 않는다.

## 계산 계약과 범위

이 창의 상단 보유분 손익과 보유종목 표만 바뀐다. 총평가액 G=P×Q는 현재 표시시장
가격 P와 전체 보유수량 Q를 사용하며 주문 입력수량·매도가능수량은 사용하지 않는다.
F=floor(G×수수료율/100), T=floor(G×거래세 합계율/100), 순매도 예상금액 N=G−F−T다.
원본 소수 평단 A에 대한 원가 C=A×Q를 빼 예상손익 ceil(N−C)를 표시한다.
수익률은 정확한 (N−C)/C×100을 소수 둘째 자리로 반올림하며 동률은 0에서 먼 쪽이다.
금액/수량은 BigInt, 평단·율은 decimal 문자열을 사용하고 안전한 표시 정수 범위를 넘으면
계산하지 않는다. 기존 간이 평가의 비용별 원미만 절사 계약을 유지하므로 세목별 절사,
최소수수료·거래 합산·증권사 실제 정산과 차이가 날 수 있다.

2026년 KRX/SOR 기본값에서 P=10,000원, Q=10주, A=9,000.125원이면 G=100,000원,
F=15원, T=200원, N=99,785원, C=90,001.25원이다. 예상손익 9,784원, 10.87%다.
NXT 주문경로 기본값이면 F=14원, N=99,786원, 손익 9,785원, 10.87%다.
OFF는 기존대로 손익 9,999원, 11.11%다.

키움의 평단가는 공급자 매입금액/보유수량, 토스는 원본 `averagePurchasePrice`다.
매입비용 포함 여부를 wire가 명시하지 않으므로 매입 수수료를 추가 차감하지 않는다.
다른 창·공급자 잔고·평단가 원의 정본 가격 연결·주문 실행/정정/취소·매수 가능 금액·
입력줄 주문금액은 유지한다. 실체결·슬리피지·양도/배당소득세·ETF/ETN 보유기간 과세는
이 간이 평가에 포함하지 않는다.
