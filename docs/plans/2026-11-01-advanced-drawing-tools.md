# 추가 그리기 도구 구현

사용자 요청: 피보나치 확장·경로·콜아웃·회귀 채널을 기존 빠른 도구 메뉴 안에 구현한다.

- 피보나치 확장: A→B 드래그 후 C 클릭. 기본 레벨 0/0.618/1/1.272/1.618/2/2.618.
  값은 C.price + (B.price − A.price) × 레벨. 세 핸들·레벨 표시·우측 연장·라벨을 편집한다.
- 경로: 클릭 정점, 호버 미리보기, Enter/더블클릭 완료. 최소 2점·최대 128점.
  점별 드래그/정확한 KST 좌표, 점 추가/삭제, 시작/끝 화살표. Escape·우클릭·blur·
  도구/종목 전환 시 취소한다. 미확정 정점은 저장/히트 테스트 대상이 아니다.
- 콜아웃: 대상 봉에서 메모 위치로 드래그한 뒤 입력한다. 클릭만 하면 기본 간격을 쓴다.
  대상은 실시간 Point, 메모 간격은 CSS px로 저장한다. 상자만 드래그해 위치를 바꾸고
  대상 핸들은 봉 좌표를 바꾼다. IME/Shift+Enter 줄바꿈/더블클릭 재편집/글자 크기 지원.
- 회귀 채널: candle pane의 로드된 구간을 드래그한다. 관측 봉 서수에 대한 OLS,
  잔차 모집단 σ = sqrt(SSE/n), 상/하 기본 2σ. 기준가 7종, 채움, 우측 연장 지원.
  시작/끝 봉과 구간 기준가가 유효해야 하고 최소 2봉이다. 로드되지 않은 구간은
  계산하지 않으며 선택 시 안내한다. 현재 봉 주기/데이터로 재계산하고 데이터 사본이나
  계산 결과는 영속화하지 않는다. 구간 이동/핸들/좌표 설정은 시간만 편집한다.

모든 도구는 공통 저장 스키마를 확장하고 기존 데이터 키/버전은 유지한다. 렌더·선택·
영역 선택이 같은 투영을 쓴다. 회귀 계산은 불변 봉 배열별 범위/기준가 캐시를 두어
포인터 이동/차트 프레임마다 전 구간을 다시 순회하지 않는다. 라이브 봉 배열 교체 시
캐시는 자동으로 분리된다. 추가 의존성은 없다.

검증: 계산/투영/좌표/저장/clone/잠금/undo 단위 테스트와 실제 차트 E2E 생성·편집·
복제·취소·리로드 및 기존 그리기 회귀 테스트. 실행 결과와 입력 지문은
`docs/diagnostics/2026-11-01-advanced-drawing/verification.json`에 기록한다.
