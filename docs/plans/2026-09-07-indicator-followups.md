# 지표 후속 최적화 실행 계획

사용자 요청: 세 후속 항목을 계획한 뒤 구현·검증·PR·머지까지 진행한다.

1. 분포·POC의 내부 가격 bin 집계를 공통화한다. qty, 최초·마지막 체결 시각을 함께 보존하고 기존 최상단 가격 합산/동률 우선순위를 유지한다. 동일 원본 파일과 가격 격자·세션 경계면 QueryEngine 수명 내 bounded cache로 원본 집계를 공유한다. 서로 다른 경계는 다른 키다.
2. 완료된 과거일의 hover cutoff에 bin별 정확한 timestamp/누적량 인덱스를 적용한다. 임의 millisecond는 이진 탐색으로 계산하며 last_trade_ms와 동시호가 경계를 보존한다. 파일 stat fingerprint, LRU 32MiB 및 항목 수 상한, 인덱스 최대 행 수와 정수 overflow 폴백을 둔다. 오늘/명시적 cache=None은 기존 조회를 유지한다. 원본 대비 반복 스크럽 시간·첫 생성 비용·실제 저장 바이트를 측정한다.
3. 히트맵은 완료일 1분 캐시가 있을 때만 coarse를 파생한다. total 동률 시 대표 레벨 tuple을 정본 tie-break로 정의해 직접/재집계가 동일하도록 하고 depth 캐시 버전을 올린다. 마지막 대표 행·가격별 max·세션 경계를 그대로 보존한다. 1분 캐시가 없으면 요청 해상도로 직접 계산한다. 선택 소스 응답은 payload 절감과 토글 비용을 비교해, 이득이 불확실하면 이번 단계에서는 세 소스 즉시 전환을 유지한다.

- 원시 집계 호출 수, 메모리 상한/eviction, 동시 동일 요청, 실패 후 재시도, 캐시 없음의 회귀 검사.
