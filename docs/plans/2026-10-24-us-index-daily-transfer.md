# 미국 지수 일봉 이력 반복 전송 축소

사용자 요청에 따라 나스닥 종합·S&P 500·SOX의 **일봉 HTTP 응답 전송만** 줄였다.
공급자, KIS 지수별 공유 스냅샷, single-flight, 장중 2초/그 밖 60초 조회, 실패 백오프,
기존 당일 봉 합성과 완료 일봉 우선순위는 유지한다. 국내 수집과 미국 종목 경로도 유지한다.
새 WebSocket·백그라운드 수집기·영속 캐시는 추가하지 않았다.

## 전송 계약

`/api/live/index-candles`의 미국 지수 `timeframe=D`만 적용한다.

1. 첫 조회 또는 식별값이 없는 구버전 클라이언트에는 전체 봉을 보낸다.
2. 응답의 `daily_history_revision`은 지수·요청 시작/종료일·마지막 봉을 제외한 전체
   이력의 SHA256이다. 시각·거래일·OHLC·거래량 모두 대조한다. 매 조회에서 기존
   조립 결과를 검증하므로 서버 상태나 클라이언트의 오래된 가정에 기대지 않는다.
3. 다음 조회는 같은 이름의 선택적 query parameter로 식별값을 보낸다. 같으면
   `daily_history_unchanged=true`, `candles`에는 마지막 봉만 보낸다. 메타데이터와
   경고는 그대로 보낸다. 마지막 봉이 없는 응답은 빈 목록이다.
4. 다르면 `daily_history_unchanged=false`와 전체 목록·새 식별값을 보낸다.
   과거 정정, 누락 이력 보충, 삭제, 새 거래일 추가와 조회 범위 변경이 여기에 해당한다.
   잘못되거나 이전 판본의 식별값도 전체 응답으로 처리한다.
5. FE의 기존 query key와 데이터 캐시는 계속 전체 봉 목록을 가진다. 일치 응답은
   요청 때 보관한 이전 목록의 마지막 행을 빼고 새 마지막 행을 붙인다. 날짜별 union으로
   오래된 임시 봉을 남기지 않는다. 서버가 보낸 권위 있는 전체 목록과 같은 결과다.
6. 기준 캐시·응답의 식별값/지수/범위/행 순서가 맞지 않으면 식별값 없이 한 번만
   전체 조회한다. 그 응답도 잘못되면 기존 조회 오류 처리로 정상 데이터를 유지한다.
   경고 때문에 다른 캐시의 행을 보존한 경우 식별값을 지워 다음 조회가 전체 응답을 받게 한다.

일치 여부는 본문 압축·304 응답·완료 일봉의 영구 불변 가정에 의존하지 않는다.
W/M·분봉·국내 응답에는 새 필드를 내보내지 않고, FE도 미국 D 이외에는 식별값을 보내지 않는다.
이 최적화는 벤더 호출 수를 줄이거나 시세 지연을 바꾸는 기능이 아니다.

## 검증 결과

기존 화면 관측의 실제 응답 기록을 새 직렬화 경로로 재생했다. 각 지수의 마지막
종가도 변경해, 가격이 바뀌는 상황에서도 일봉 이력 전송을 줄이는지 확인했다.
이 값은 장중 새 시세의 실시간 측정이나 패킷 캡처가 아니다.

| 응답 | 기존 본문 | 개선 후 본문 | 봉 개수 |
| --- | ---: | ---: | ---: |
| S&P 500 일봉 | 30,505 B | 1,573 B | 240 → 1 |
| 나스닥 종합 일봉 | 33,678 B | 1,586 B | 240 → 1 |
| SOX 일봉 | 31,017 B | 1,564 B | 240 → 1 |
| 위 3개 일봉 + 기존 3개 분봉·3개 헤더 | 136,350 B | 45,873 B | **66.36% 감소** |

2초 간격 단순 환산으로 전체 응답 본문은 약 4.09 → 1.38 MB/분이다. 요청 수·HTTP
오버헤드·원본 KIS 트래픽은 이 비교에 포함하지 않는다. 원본 처리 비용과 서버 캐시
소유권을 바꾸지 않고 재전송만 줄였다.

무자격 Playwright의 6개 차트에서도 240봉을 최초 표시하고 다음 2초 응답 1봉으로
240봉 표시를 유지했다. 과거 정정은 전체 240봉, 새 거래일은 전체 241봉으로 반영하고
그 뒤 다시 1봉만 전송했다. HTTP 오류 동안 봉을 유지하고 기존 재시도 후 복구했다.
이 fixture의 일봉·분봉 응답 본문도 116,799 → 37,448 B로 67.94% 감소했다.

- BE HTTP·기존 국내/미국 경로·wire 계약: 224개 통과.
- FE 조회 캐시·기존 지수 실시간 경로: 30개 통과.
- 관련 Playwright E2E: 23개 통과. 전송량 증빙을 저장하도록 바꾼 테스트 1개도 재통과.
- 타입 검사(앱/단위/E2E)·Vite 빌드·Ruff 통과.
- 계약 스냅샷을 임시로 불일치시켜 실패를 확인하고 원복 후 12개 계약 검사 통과.

운영 서버는 재시작하거나 변경하지 않았다. 국내 수집 대상·계정별 예상 등록 수·수집
프로세스의 전후 비교와 검증 입력 지문은 아래 기록에 남긴다. 주말이므로 국내 장중
실수신이나 개선 코드의 운영 배포 후 실시간 시세 지연을 검증했다는 뜻은 아니다.
