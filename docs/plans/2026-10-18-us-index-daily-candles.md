# 미국 지수·개별 종목 일봉 구현 계획 — 지수는 한투, 종목은 키움 REST

작성: 2026-10-18. 상태: 워크트리 구현 완료·기존 실패 3건 해소·백엔드/프런트 전체 검증 통과.

사용자 요청: 보완한 설계를 바탕으로 나스닥 종합, S&P 500, 필라델피아 반도체지수의 일봉을 기존 프로젝트에 적용할 구현 계획을 작성한다. 추가 요청으로 해외 개별 종목의 키움 REST 지원까지 고려한다. 현재 확인된 해외 종목 범위는 미국주식이며, 일본·홍콩 등 다른 국가까지 지원한다고 해석하지 않는다. 이 문서는 설계와 구현 범위의 기준이다. 배포 상태와 검증 결과는 별도 검증 기록에 남긴다.

## 목표와 범위

`/live`의 기존 검색·차트 창에서 세 해외지수와 미국 개별 종목의 완료된 일봉을 조회한다. 처음에는 화면에 필요한 최근 구간만 받고, 왼쪽 이동이나 날짜 이동으로 필요한 과거를 추가 조회한다. 여러 창은 같은 서버 캐시와 진행 중인 조회를 공유한다.

| 데이터 종류 | 공급자 | 첫 제공 기능 | 기존 경로와의 관계 |
| --- | --- | --- | --- |
| 국내 주식·국내 지수 | 기존 키움 | 기존 기능 유지 | 기존 코드·venue·인증·캐시 계약 유지 |
| 미국 현물지수 | 한투 `FHKST03030100` | 나스닥 종합·S&P 500·SOX 일봉 | 기존 지수 차트 API에 공급자 분기 |
| 미국 개별 종목 | 키움 REST `usa06012` | 종목 검색·선택·일봉·과거 이동 | 미국 종목 전용 식별자·조회 진입점 추가 |

| 앱의 안정적인 ID | 표시 이름 | 공급자 코드 | 주기 | 시장 시간대 |
| --- | --- | --- | --- | --- |
| `NASDAQ_COMPOSITE` | 나스닥 종합 | `COMP` | `D` | `America/New_York` |
| `SP500` | S&P 500 | `SPX` | `D` | `America/New_York` |
| `SOX` | 필라델피아 반도체지수 | `SOX` | `D` | `America/New_York` |

기능은 A(세 지수 일봉)와 B(미국 개별 종목 일봉)로 나누어 검증한다. 아래 지수별 세부 계약은 A에 적용하며, 거래일·완료 구간·최근 갱신·실패 보존은 B에서도 공유한다. 미국 종목을 고려한다는 이유로 A의 최초 출시에 모든 해외주식 기능을 묶지 않는다.

첫 제공 범위는 일봉·가격 차트·과거 이동·최근 구간 갱신이다. 나스닥100, 주봉·월봉·분봉, 실시간 시세 스트리밍, 해외주식 매매, 지수선물은 후속 범위다. 해외지수에 호가·최대벽·투자자 수급·거래대금 기능을 연결하지 않는다. 지수 거래량도 이번 단계에서는 표시·거래량 기반 지표에 사용하지 않는다. 미국 종목의 거래량은 필드 의미와 수정주가 관계를 별도 실측한 뒤 표시한다.

국내 종목·지수의 데이터 공급자와 시간축 계약을 유지한다. 범용 공급자 프레임워크, 새 데이터베이스, 디스크 캐시, 별도 상시 수집 프로세스는 도입하지 않는다.

## 실측 근거와 현재 구조

한투 실서버 `FHKST03030100`, `GET /uapi/overseas-price/v1/quotations/inquire-daily-chartprice`에서 세 지수의 일봉 OHLC를 확인했다. 시장 구분은 `N`, 기간 구분은 `D`다.

- [나스닥·S&P 500 실응답](../research/2026-10-18-kis-us-index-daily-probe.json): `COMP`, `SPX`의 2026-10-01~16 데이터 각 12개를 종료일 이동으로 확보했다.
- [보유 범위 실측](../research/2026-10-18-kis-us-index-daily-history-boundary-probe.json): 나스닥은 2000-01-03, S&P 500은 2005-06-02가 최초 반환일이었다. 각 최초일 전날까지 1900년부터 조회한 구간은 정상 처리·0건이었다. 이는 현재 관측값이며 보관 기간 보장이 아니다.
- [SOX 실응답](../research/2026-10-18-kis-sox-daily-probe.json): 2026-10-05~16 일봉 10개를 확인했다. SOX의 최초 보유일은 아직 측정하지 않았다.
- 짧은 구간에서 10행, 긴 구간에서 100행이 반환됐다. **고정 행 수나 `tr_cont`만으로 완결성을 판단하지 않는다.**
- `output2`가 날짜별 일봉이다. `output1`은 과거 기간 조회에서도 최신 시세를 담았다. 과거 봉·기간별 종가를 만드는 데 `output1`을 사용하지 않는다.
- [키움 실응답의 AAPL 대조군](../research/2026-10-18-kiwoom-us-index-daily-probe.json): `stex_tp=ND`, `stk_cd=AAPL`, `usa06012`로 일봉 100행과 연속조회 `Y`를 확인했다. NYSE·AMEX 종목, 미국 종목 전체 마스터, 수정주가의 기준일·분할 경계, 최대 과거 범위·세션 포함 범위는 아직 실측하지 않았다.
- 키움 [공식 미국주식 일봉 예제](https://github.com/Kiwoom-Securities/Kiwoom-REST-API/blob/main/examples/미국주식/차트/get_overseas_stock_daily_chart.py), [공식 명세](https://github.com/Kiwoom-Securities/Kiwoom-REST-API/blob/main/kiwoom/_data/kiwoom_api_spec.json): `POST /api/us/chart`, `usa06012`; `ND`=NASDAQ, `NY`=NYSE, `NA`=AMEX. 수정주가·환율 적용 옵션과 `result_list` 응답을 제공한다. 문서 지원과 실측 완료 범위를 구분한다.
- 키움 미국주식 호출 제한은 [공식 서비스 안내](https://openapi.kiwoom.com/intro)를 기준으로 등록하고, 실제 제한 응답과 함께 조정한다. 종목목록의 분당 제한과 미국 피크 시간 정책을 국내 TR 설정으로 대체하지 않는다.

현재 재사용할 구조:

- `hoga/live/index_registry.py`: 앱 지수 ID·표시명 목록.
- `hoga/live/api.py`: `/indices`, `/index-candles`, `/index-quotes`, `/index-investor-net`의 조립 지점.
- `hoga/live/candle_models.py`, `candle_fetch_result.py`: 소수점 OHLC를 보존하는 공급자 중립 지수 캔들 계약.
- `hoga/live/kis_client.py`, `kis_runtime.py`: 존치 중인 한투 인증·공유 클라이언트·호출 제한·재시도.
- `frontend/src/api/liveIndices.ts`, `live/buildIndexBundle.ts`: 기존 조회 훅과 지수 차트 번들.

이번 변경에서 반드시 해소할 가정:

1. `_validate_index_range()`가 국내용 `kis_index_code` 유무로 지원 여부를 판단한다.
2. 일봉 라우트가 키움 클라이언트를 직접 생성한다. `/index-quotes`도 전체 활성 지수에 키움 현재가를 요청한다.
3. `collect_index_candles_with_cache()`는 반환된 데이터가 일부여도 요청 범위 전체를 캐시에 추가한다. 해외의 부분 응답을 그대로 넘길 수 없다.
4. `index_cold_fetch.py`의 3개월 분할 자체는 응답이 완전하다는 보장이 아니다.
5. 지수 일봉 캐시에 최근 구간 TTL이 없고, 프론트 일봉 폴링도 없다.
6. 일봉 앵커는 09:00 KST이고 `buildIndexBundle()`은 한국 정규장 세션을 만든다. 실제 미국 세션으로 오인하지 않도록 경계를 분리해야 한다.
7. 종목 API 검증·활성 코드·그룹 상태는 국내 6자리 코드에 기대고 `LiveCandle` OHLC는 정수다. 미국 티커나 달러 가격을 그대로 넣으면 경로 누출 또는 소수점 손실이 생긴다.
8. `kiwoom_venue.py`의 `_NX`/`_AL` 접미는 국내 venue 인코딩이다. 미국 거래소 구분과 합치면 안 된다.

## 확정할 설계 계약

### 1. 공급자 선택은 기존 API 조립 지점에서 한다

`index_registry.py`에 해외지수 세 항목과 최소 기능 정보를 추가한다. 앱 ID와 공급자 코드를 분리하고, 국내 업종코드와 해외지수 코드를 같은 필드로 해석하지 않는다.

최소 정보는 시장(`KR`/`US`), 시장 시간대, 일봉 공급자, 해당 공급자 코드, 지원 주기, 시세·수급·거래량·거래대금 지원 여부다. 국내 항목의 기존 동작을 기본값으로 보존하고, 국내 레거시 코드 필드는 사용처를 확인하며 점진적으로 정리한다. 미국 종목은 B의 별도 목록으로 관리하며 지수 레지스트리에 수천 개 티커를 등록하지 않는다. 이번 변경으로 모든 공급자 코드를 통합하는 대규모 리팩터링을 하지 않는다.

`/index-candles`는 해외지수 `D`에만 새 한투 서비스를 연결한다. 국내 `D/W/M`과 분봉은 기존 키움 경로를 사용한다. 해외에 지원하지 않는 주기를 요청하면 명시적인 422 오류를 반환한다. 키움 호출 후 실패를 한투로 재시도하는 공급자 폴백은 두지 않는다.

`/index-quotes`와 `/index-investor-net`은 각 기능을 지원하는 지수만 처리한다. `/indices`에 해외 ID가 추가됐다는 이유로 국내 현재가 루프·시장 수급 요청에 섞이지 않게 한다. 해외 차트 상단의 가격은 마지막 일봉 종가·거래일로 표시하고 실시간 현재가로 표시하지 않는다.

### 2. 한투 어댑터는 실제 확보한 구간을 함께 반환한다

추가할 주 모듈은 다음 두 개다. 미국 개별 종목이라는 두 번째 실제 소비자가 생겼으므로 날짜·구간·최근 갱신 서비스만 공급자 중립으로 공유한다.

- `hoga/live/kis_global_index_candles.py`: `output2` 파싱, 날짜 커서 순회, 검증, 부분 결과 생성.
- `hoga/live/us_daily_candles.py`: 미국 지수·종목이 공유하는 구간별 메모리 캐시, 최근 구간 재조회, 요청 공유, API 응답 메타데이터 조립. 공급자별 페이지·파싱은 주입한 함수가 소유한다.

`KisClient`에는 인증된 일봉 1페이지를 받는 얇은 메서드를 추가한다. 새 어댑터가 별도의 `httpx.Client`·토큰 provider를 만들지 않는다. 페이지마다 기존 `_get()`과 계정별 호출 제한을 거치고 사용자 조회는 기존 foreground 경로를 사용한다. 기존 뉴스·파생 기능과 같은 런타임을 공유하며, 이번 기능을 위해 삭제된 KIS 계정 풀·별도 capacity 계층을 복원하지 않는다.

공통 지수 OHLC 계약을 재사용하되 미국 종목을 지수 모델·지수 ID로 위장하지 않는다. 미국 일봉용 공급자 중립 모델은 소수점 OHLC와 원본 거래일(`trading_date`, `YYYYMMDD`)을 보존하고, 지수는 기존 `IndexCandlePoint`로 변환해 소비할 수 있게 한다. 국내 정수 `LiveCandle`을 전역으로 float로 바꾸지 않는다. 결과는 봉 목록 외에 검증 완료 구간, 미조회 구간, 위반, 예산 중단 여부를 포함하는 별도 결과 계약으로 정의한다. 국내 `IndexCandleFetchResult` 소비자가 새 필드를 필수로 제공하게 만들지 않는다.

조회 알고리즘:

1. 요청 구간의 종료일부터 조회한다. 응답의 유효 날짜·숫자·OHLC 관계와 요청 범위를 검증한다.
2. 원본 날짜를 기준으로 중복을 제거하고 보존한다. 중복 날짜는 이번 조회의 새 응답을 우선한다.
3. 첫 페이지에서 얻은 최저 날짜가 요청 시작일보다 뒤라면, 종료일을 `최저 날짜 - 1일`로 이동해 계속 조회한다. 반환 행 수가 100 미만이어도 왼쪽 잔여 구간을 확인한다.
4. 성공적으로 순회한 오른쪽 구간만 완료로 인정한다. 다음 요청 실패·유량 제한·시간 초과 시 이미 받은 봉은 반환하되 왼쪽 구간은 미조회 상태로 남긴다.
5. 정상 0건은 **그 요청 구간의 빈 결과**로만 인정한다. 주말·휴일의 빈 구간을 전체 역사 끝으로 해석하지 않는다. 파싱 실패·잘못된 envelope·오류 응답을 정상 빈 결과로 바꾸지 않는다.
6. 같은 날짜만 반복되거나 커서가 과거로 진행하지 않으면 중단하고 경고한다. 날짜 필드 파싱이 깨져 커서를 결정할 수 없으면 완결성을 주장하지 않는다.
7. 조회당 기본 예산은 최대 8페이지·15초로 두고 주입 가능한 설정으로 관리한다. 예산 도달은 지원 이력의 끝이 아니라 부분 결과다. 최초 화면에서는 최근 약 1년을 우선 요청하므로 전체 역사 다운로드를 시작하지 않는다.

`history_start`는 광범위한 이전 구간의 정상 0건과 최초 양성 봉을 함께 확인한 경우에만 관측값으로 만든다. 관측 시각과 재검사 만료를 보관한다. 소스 이력이 확장될 수 있으므로 영구적인 요청 차단 상수로 사용하지 않는다. SOX는 미확인 상태에서 시작하며, 오래된 구간의 0건을 임의의 시작 날짜로 바꾸지 않는다.

### 3. 해외 캐시는 부분 구간과 최근 봉의 수명을 구분한다

기존 국내 `IndexCandlesCache`의 의미를 한 번에 바꾸지 않는다. 해외 서비스가 별도의 작은 메모리 캐시를 소유하고, 공통 캔들·구간 계산 유틸리티는 필요한 만큼만 재사용한다. ADR-0048의 메모리 캐시 방침을 따른다.

- 봉의 정본 키는 `(instrument_key, price_basis_key, trading_date)`다. 지수는 원지수값, 미국 종목은 거래소·티커·수정주가 기준·통화가 구별된다. 구간 커버리지와 봉 목록을 따로 저장하고 겹치는 구간은 병합한다.
- 조회 완료된 과거 구간은 프로세스 수명 동안 재사용한다. 미조회 구간은 캐시 hit로 취급하지 않는다.
- 최근 14개 미국 달력일은 변경 가능한 구간으로 분리하고 성공 조회 TTL을 기본 300초로 둔다. 최근 구간을 다시 받아 새 봉과 정정 값을 날짜별로 upsert한다.
- 과거 빈 구간·관측된 보유 하한은 유한 TTL(초기 24시간)을 적용한다. 최근 구간의 빈 결과는 300초로 다시 확인한다. 인증·네트워크·파싱 오류는 빈 구간 캐시를 만들지 않는다.
- 실패 시 마지막 정상 봉과 마지막 성공 시각을 유지한다. 실패 시각을 성공 갱신 시각으로 덮지 않는다. 자동 재시도는 30초에서 최대 300초까지 backoff하고 수동 재시도도 동시 요청을 합친다.
- 식별자·가격 기준별 조회를 직렬화하고 캐시를 다시 검사해 같은 구간·겹치는 구간의 중복 조회를 줄인다. 동일 요청은 진행 중인 태스크를 공유한다. 한 창의 취소가 다른 창의 공유 조회를 취소하지 않도록 서비스가 작업 수명을 소유한다. 완료·실패·서버 종료 시 pending 항목과 태스크를 정리한다.
- 전체 요청 구간을 매번 재다운로드하지 않는다. 최근 구간 갱신은 tail만, 과거 이동은 누락된 왼쪽 구간만 조회한다. 정규화된 날짜별 저장으로 중첩 배치를 무한 append하지 않는다.
- 기존 REST bypass 설정을 해외에도 적용한다. bypass 중에는 캐시만 반환하고 조회를 시작하지 않는다. 상태·누락 범위를 응답에 남긴다.
- 미국 종목은 세 지수와 달리 식별자 수가 유계가 아니다. 종목/가격 기준 단위 LRU·활성 요청 상한을 둔다. 축출 시 봉과 해당 완료 구간을 함께 제거하고, 없는 봉의 커버리지만 남기지 않는다. 진행 중인 항목의 수명은 cache eviction과 분리한다.

### 4. 미국 거래일과 차트 표시용 시각을 구분한다

거래일 정본은 한투 `stck_bsop_date`다. 한투 일봉의 날짜를 미국 시장의 거래일로 보존하며 미국 마감 시각을 한국 날짜로 변환해서 봉 날짜를 하루 뒤로 옮기지 않는다.

1차 구현에서는 전체 차트 엔진을 다중 시간대로 바꾸지 않는다. `trading_date`를 기존 날짜축용 `t_ms`로 변환하는 **해외 일봉 전용 표시 경계 한 곳**을 두고, 호환성을 위해 같은 날짜의 09:00 KST 앵커를 사용할 수 있다. 이 값은 실제 미국 개장 시각이 아니라 표시용 좌표다. 국내 `daily_anchor_ms()`의 기존 계약을 변경하지 않는다.

`buildIndexBundle()`의 해외 일봉 경로는 명시적인 거래일을 사용한다. KRX 세션 정보를 미국의 실제 개장·마감 정보로 표시하거나, 한국 거래일 목록으로 미국 봉을 삭제·추가하지 않는다. 기존 `RangeBundle`이 요구하는 세션 좌표는 날짜축용 가상 좌표로 제한하고 호가·장중 정렬 기능에서 사용하지 않는다. 툴팁 날짜·기간 필터·과거 이동·중복 제거는 원본 거래일과 일치해야 한다.

최근 봉의 포함 판단은 `ZoneInfo("America/New_York")`의 시각으로 수행한다. 1차 정책은 당일 뉴욕 날짜의 봉을 16:30 ET 이후에만 표시 후보에 포함하는 보수적 기준이다. 장중 또는 그 이전에는 현재 미국 거래일 봉을 제외한다. 서머타임은 시간대 라이브러리로 계산하며 고정 KST 시각을 사용하지 않는다. 이 시각은 우리 표시 정책이고 공급자의 데이터 확정 보장이 아니다.

새 미국 휴장일 데이터셋이나 시장 달력 엔진은 1차에 만들지 않는다. 휴장일에는 응답에 존재하는 거래일만 표시한다. 마지막 반환 거래일·마지막 성공 조회 시각을 보여주고, 휴장일을 모르는 상태에서 “오늘 봉 없음 = 장애”나 “최신 거래일까지 완전”이라고 판정하지 않는다. 조기 폐장일도 보수적으로 같은 표시 기준을 사용한다. 당일 봉은 다음 미국 거래일에도 최근 구간 재조회로 정정 가능하게 둔다.

### 5. API 변경은 해외지수에 필요한 정보만 추가한다

기존 `/api/live/indices`와 `/api/live/index-candles`를 유지한다. 목록에는 시장·지원 주기·지원 기능을 전달해 프론트와 백엔드가 같은 제한을 사용한다. 공급자 자격정보는 전달하지 않는다.

해외 일봉 응답에는 다음 메타데이터를 추가한다. 기존 국내 응답은 기존 기본 동작으로 읽히게 optional/default 계약을 둔다.

- 봉별 `trading_date`.
- `market`, `market_timezone`, `source`.
- `latest_bar_date`: 실제 표시한 마지막 미국 거래일.
- `last_successful_check_at_ms`: 해당 최근 구간을 공급자에서 마지막으로 정상 확인한 시각.
- `coverage`: 요청 구간 중 조회가 완료된 구간과 미조회 구간.
- `truncated`: 요청 예산 때문에 남은 구간이 있는지.
- `history_start`: 존재할 때만 최초 보유일 관측값과 확인 시각.
- `refresh_status`: 정상 조회·stale·자격 미설정·오류·bypass를 구분할 상태.

가능하면 기존 `data_warnings` 계약으로 실패·부분 결과를 전달하고, 필요한 사유는 `hoga/live/data_warnings.py`, 프론트 warning 타입·정책에 함께 등록한다. 정상 역사 끝은 오류로 표시하지 않는다. 응답에 `coverage`만 추가하고 실제 캐시의 커버리지 의미를 고치지 않는 구현은 허용하지 않는다.

### 6. 화면 선택·복원·갱신을 함께 연결한다

해외 ID를 `LiveIndexId`, 검증 함수, 검색 결과, URL `?index=...`, 창·그룹·저장 상태 복원에 연결한다. 공급자 코드 `COMP`·`SPX`를 주식 6자리 코드 공간에 넣지 않는다.

- 해외지수 선택 시 **선택 대상 창**의 주기를 `D`로 정규화한다. 이전 종목에서 쓰던 `1m`·초봉·주봉·월봉을 그대로 요청하지 않는다. 단축키·드롭다운·URL·저장 상태 복원도 동일한 지원 주기 검증을 거친다. 다른 창의 주기는 바꾸지 않는다.
- `TimeframeControl`에 지원 주기 목록을 전달하고 해외지수에서는 일봉만 선택 가능하게 한다. 각 기능마다 `isUSIndex` 조건을 흩뿌리기보다 기존 capability 경계에서 결정한다.
- 해외지수에 종목 WS/SSE 구독, 국내 수급·호가·거래대금·거래량 기반 sidecar를 요청하지 않는다. 숨겨진 패널의 쿼리도 비활성화한다. OHLC에서 계산 가능한 기존 가격 지표는 지원되는 경로만 유지한다.
- 차트 상단은 “마지막 일봉 종가 / 미국 거래일”을 사용한다. 마지막 성공 조회 시각과 stale·미설정·재시도 상태를 구분한다. 마지막 거래일이 금요일이라고 주말에 자동 오류를 표시하지 않는다.
- 해외지수의 최근 구간을 포함한 열린 차트는 기본 300초 간격과 창 복귀 시 재확인한다. 과거 전용 창에는 tail 폴링을 하지 않는다. 서버 TTL·진행 중인 요청 공유로 여러 창의 조회를 합친다. UI 타이머는 화면 비활성화·언마운트 시 정리한다.
- 과거 이동은 현재 범위와 캐시를 활용한다. 부분 결과 후에는 진행이 확인된 미조회 구간만 이어 받고, 진행 없음·API 오류 시 자동 반복을 멈춰 재시도 상태를 표시한다. 관측된 역사 끝에서 무한 좌측 요청을 만들지 않는다.
- 과거 봉 prepend나 최근 봉 갱신이 사용자의 스크롤 위치·가격축·핀·그룹을 초기화하지 않게 한다. 현재 종목의 이전 응답이 새 지수 차트에 잠시 보이지 않도록 placeholder 식별자를 검증한다.

## 추가 범위 B — 미국 개별 종목을 키움 REST로 지원

### B1. 국내 코드와 미국 종목 식별자를 분리한다

미국 종목은 `{kind: "us_stock", exchange: "NASDAQ" | "NYSE" | "AMEX", symbol, label}`로 표현한다. 앱 식별자는 예를 들어 `us-stock:NASDAQ:AAPL`이다. 티커만으로 전 세계 종목을 식별하지 않고, 한글명·표시명도 키에 넣지 않는다. 같은 티커가 서로 다른 거래소에 있을 때 구분한다. 공급자 wire 코드는 한 곳에서 `NASDAQ→ND`, `NYSE→NY`, `AMEX→NA`로 변환한다.

`LiveInstrument`의 union에 이 분기를 추가하고, 현재의 “index가 아니면 국내 stock” 분기를 전수 점검한다. `instrumentToActiveCode()`는 미국 종목에 국내 6자리 코드를 돌려주지 않는다. subject key·차트 workarea key·query key·드로잉 식별자·그룹/핀·관심종목·최근검색·저장된 창·새 탭 URL에 거래소와 티커를 보존한다. URL은 `?market=US&exchange=NASDAQ&symbol=AAPL`처럼 명시적으로 표현한다.

기존 국내 `?code=005930`와 `?index=SP500`은 유지한다. 국내 API의 6자리 정규식만 영문 허용으로 느슨하게 바꾸지 않는다. KRX/NXT/UN 선택기와 `_NX`/`_AL` 접미를 미국 종목에 적용하지 않는다. 점·하이픈이 있는 티커는 공급자 마스터의 실제 값을 보존하며, 임의로 Yahoo 등의 티커 형식으로 변환하지 않는다.

### B2. 미국 종목 목록은 별도 캐시로 검색에 합류시킨다

키움 `usa10099`(종목리스트), `usa10098`(거래소구분 조회), `usa10100`(종목 조회)을 기존 REST seam의 TR 표에 등록한다. 미국 목록은 국내 종목 마스터의 스키마·코드 정규식에 합치지 않고 별도 메모리 캐시로 둔다. 검색 모델에 source가 구별되는 후보를 합류시키고 이름·영문명·티커·거래소를 표시한다.

- `usa10099`는 공식 안내상 계좌별 분당 5회 제한이다. 목록은 긴 TTL(초기 24시간)·single-flight·last-good으로 공유한다. 키 입력마다 전체 목록을 요청하지 않는다.
- 초기 목록·연속조회·거래소별 응답 완결성을 실측한다. 일괄 목록이 없거나 부분 실패하면 목록 상태를 구분하고, 거래소+티커의 직접 조회 경로를 제공한다. 미설정·검색 실패를 존재하지 않는 종목으로 표시하지 않는다.
- 초기에는 거래소를 확정한 AAPL 같은 종목으로 수직 경로를 먼저 검증한다. 목록을 받았다는 이유만으로 모든 상품·모든 과거 기간까지 검증됐다고 표시하지 않는다. `isEtf` 등 상품 분류를 보존하고 지수와 주식/ETF를 섞지 않는다.
- 공급자 마스터가 바뀌면 다음 갱신에 반영한다. 이번 단계에서 별도 티커 변경·상장폐지 이력 데이터베이스는 만들지 않는다. 해석할 수 없는 옛 식별자는 국내 코드로 fallback하지 않고 재선택 상태를 표시한다.

### B3. `usa06012` 전용 어댑터와 거버너를 사용한다

`hoga/live/kiwoom_us_daily_candles.py`를 추가한다. `POST /api/us/chart`의 `usa06012`와 `result_list`를 사용하며, 국내 `ka10081` 파서·venue 인코딩을 재사용하지 않는다.

- `stex_tp`, `stk_cd`, `strt_dt`, `upd_stkpc_tp`, `exrt_appl_tp`를 명시한다. 최초 지원 통화는 USD이며 `exrt_appl_tp=0`으로 한다. 주가를 원화로 환산하지 않는다.
- `cur_prc`를 종가로, `dt`를 미국 거래일로 파싱한다. 응답의 소수점을 보존하고 국내 원화 정수 파서·반올림 규칙에 넣지 않는다. 와이어 숫자는 Decimal 등으로 검증하고 차트 응답은 기존 number 계약에 맞춘다.
- 미국 종목 일봉의 프리마켓·정규장·애프터마켓 포함 범위를 실측하고 `session_scope`를 정의한다. 지수의 16:30 ET 표시 정책을 검증 없이 미국 종목에 복사하지 않는다. 정규장 봉으로 확인된 경우에만 그 정책을 적용하고, 장후 포함 데이터라면 그 소스의 완료 시점을 별도로 정의한다. 완료 시점을 확인하지 못한 당일 봉을 완료봉으로 내보내지 않는다. 범위가 다른 시세는 같은 캐시 키로 합치지 않는다.
- 페이지 순회는 키움의 `cont-yn`/`next-key`로 수행한다. 한투의 종료일 이동 알고리즘을 복사하지 않는다. `strt_dt`의 실제 날짜 방향·과거 점프·수정주가 기준일 관계는 실측으로 확인한 뒤 결정한다.
- 페이지마다 기존 `kiwoom_access.run_with_capacity`와 `kiwoom_rest_runtime`을 거친다. 기존 설정을 무조건 국내 5회/초로 가정하지 않고 미국 조회·미국 전체·차트 그룹·종목리스트 제한을 확인해 기존 scheduler에 필요한 최소 설정을 추가한다. 공식 안내의 피크 시간(한국시간 09~10시)도 고려한다. 새 독립 HTTP 클라이언트·인증·임의 sleep 루프는 만들지 않는다.
- 원시 행 수가 아니라 날짜 진행·커서·종료 여부와 검증 결과로 실제 완료 구간을 산출해 공통 미국 일봉 서비스에 넘긴다. 실패·페이지 예산·반복 next-key는 부분 결과이며, 최초 100행만 받고 전체 요청을 완료로 캐시하지 않는다.
- 한투 자격이 없더라도 키움 자격만으로 미국 종목 일봉이 동작해야 한다. 키움 장애 시 미국 종목을 한투로 자동 우회하지 않는다.

### B4. 수정주가 기준을 구현 전 검증 게이트로 둔다

미국 종목에는 분할 등 기업행동이 있으므로 지수처럼 가격 기준을 생략할 수 없다. 기본 표시 목표는 **USD 수정주가**다. 단 `upd_stkpc_tp=1` 옵션의 존재만으로 과거 배치 간 척도가 같다고 가정하지 않는다.

1. AAPL·NVDA의 실제 분할 전후 구간을 raw/adjusted로 비교한다. `strt_dt`와 커서 페이지 경계를 바꿔 같은 거래일 OHLC가 같은 수정 기준을 갖는지 실측한다. 미국 거래량도 분할 조정 여부를 별도 확인한다.
2. 공급자의 수정 기준이 조회 기준일 상대라면 차트 전체의 `adjusted_as_of`를 고정한다. 페이지마다 날짜를 바꿔 기준이 달라지지 않게 한다. 기준일이 API에 직접 없으면 공통 기준에서의 커서 순회로 해결 가능한지 검증한다.
3. 캐시·진행 중인 요청 키에 raw/adjusted·수정 기준일·통화를 포함한다. 가격 기준 변경 시 OHLC·완료 구간을 함께 무효화한다. 오래된 수정주가도 새로운 분할 뒤에는 바뀔 수 있으므로 **최근 14일만 재조회하면 충분하다는 지수 정책을 그대로 쓰지 않는다.**
4. 동일 척도의 연결을 증명하기 전에는 adjusted 데이터를 출하하지 않는다. 실측이 불명확하면 범위·방식을 재검토하고, 원주가를 수정주가로 조용히 표시하지 않는다. 원주가를 별도 제공할 경우에도 응답·UI에 가격 기준을 명시한다.

기업행동 전체를 복원하는 자체 조정 엔진은 만들지 않는다. 공급자의 의미를 확인하고 그 기준을 캐시·차트 전체에서 유지하는 데 한정한다.

### B5. 공통 날짜·캐시 서비스와 별도 종목 진입점을 연결한다

미국 지수와 종목은 `us_daily_candles.py`의 거래일 보존·커버리지·tail TTL·last-good·요청 공유를 재사용한다. 단 공급자별 완결성 판정과 종목의 수정 기준 변경 정책은 각 어댑터/가격 기준 경계에 남긴다. 여러 국가·모든 자산을 위한 상속 트리나 플러그인 시스템을 만들지 않는다.

미국 종목 API는 가칭 `GET /api/live/us-stock-daily-candles?exchange=NASDAQ&symbol=AAPL&from=...&to=...`로 분리한다. 응답에는 요청한 종목 식별자·통화·가격 기준과 앞서 정한 미국 일봉 metadata를 포함한다. 기존 `/past-daily-candles?code=005930`의 계약을 깨지 않는다. 클라이언트는 같은 차트가 소비하는 `RangeBundle`로 변환하되 미국 종목을 `index:<id>`로 위장하지 않는다.

미국 종목 선택은 해당 창을 `D`로 정규화하고 기존 국내 수집·WS·주문·스크리너 일봉·수급·호가·최대벽·뉴스 경로를 호출하지 않는다. 가격 기반 지표도 국내 코드 전용 보조 API가 아닌 현재 미국 봉을 소비하도록 연결하거나 지원하지 않음을 명시한다. 거래대금 `acc_trde_prica`가 존재하더라도 단위·의미를 검증하기 전에는 `trade_value_won`에 넣지 않는다. 가격·툴팁·축은 USD 소수점과 실제 정밀도를 보존한다.

관심종목·그룹·검색 기록은 표시용 식별자 저장을 지원하되, 국내 자동 수집 universe에 미국 티커를 등록하지 않는다. 창 저장·복원과 시장 데이터의 저장뷰 캡처는 구분한다. 미국 종목의 캡처·study 저장은 해당 데이터 계약이 준비될 때까지 비활성화한다.

## 구현 순서와 변경 파일

각 단계에서 동작하는 수직 경로를 검증한다. 기능을 작은 PR로 나누더라도 모든 단계가 끝나기 전에는 사용자 기능 완료로 보고하지 않는다.

### 단계 1. 계약·레지스트리·설계 기록

- `hoga/live/index_registry.py`: 세 해외 ID와 공급자·지원 기능 추가. 기존 국내 필드 사용처 점검.
- `hoga/live/candle_models.py`, `candle_fetch_result.py`: 해외 거래일과 완료/미조회 구간을 담는 최소 결과 타입 추가.
- `docs/adr/0136-kis-removal-kiwoom-full-replacement.md`: 뉴스·파생 예외처럼 **해외 현물지수 일봉 한정** KIS 사용 예외를 반영한다. 사용자 요청과 이번 실측 파일을 근거로 남긴다.
- ADR-0048의 메모리 원칙과 공급자 간 상호 import 금지를 유지한다.

완료 기준: 세 ID·코드·지원 기능이 양쪽에서 모순 없고 국내 조회 경로가 해외 코드를 해석하지 않는다.

### 단계 2. 한투 페이지·일봉 어댑터

- `hoga/live/kis_client.py`: 인증·유량·재시도 계층을 사용하는 공개 1페이지 메서드 추가.
- `hoga/live/kis_global_index_candles.py` 신규: 파서·날짜 순회·예산·검증·부분 결과 구현.
- 기존 실측 JSON에서 작은 OHLC fixture를 만든다. 키·토큰·계좌정보는 포함하지 않는다.

완료 기준: 10행/100행/비정형 짧은 페이지, 중복, 반복 커서, 중간 오류를 가짜 응답으로 검증하고 누락 구간을 성공으로 표시하지 않는다.

### 단계 3. 캐시 서비스와 기존 API 연결

- `hoga/live/us_daily_candles.py` 신규: 미국 지수·종목 공통 구간 캐시·tail TTL·last-good·pending 작업 소유·동시 조회 공유 구현. A에서는 지수 어댑터만 연결하고 B에서 미국 종목을 추가한다.
- `hoga/live/api.py`: 해외 `D` 분기, metadata, 주기 검증, quote/investor 기능 필터, bypass 적용. 서비스의 생성·종료 수명을 기존 router/app 패턴에 연결한다.
- `hoga/live/data_warnings.py`, `hoga/api/error_codes.py` 및 관련 타입: 실패·부분 응답·미지원 주기의 명시적 계약 반영.
- 기존 국내 `index_candles_cache.py`, `index_cold_fetch.py`는 해외의 새 완료 계약을 우회하는 데 사용하지 않는다. 필요한 순수 유틸리티 외에는 국내 의미를 변경하지 않는다.

완료 기준: 한투 자격증명만 있어도 해외지수 일봉을 조회할 수 있다. 국내는 기존 키움, 해외지수는 한투만 호출한다. 미설정·장애 시 기존 캐시를 보존하며 정상 빈 응답으로 위장하지 않는다. 미국 종목 B의 공급자는 키움이다.

### 단계 4. 프론트·거래일·최근 갱신

- `frontend/src/live/liveInstrument.ts`, `liveInstrumentCapabilities.ts`: 새 ID·지원 기능.
- `frontend/src/api/liveIndices.ts`: wire 타입·metadata·부분 결과 병합·해외 tail 갱신.
- `frontend/src/live/buildIndexBundle.ts`: 해외 거래일→표시 좌표 경계, 가상 세션 취급.
- `frontend/src/live/useLiveChartData.ts`: 해외 조회 날짜·sidecar 게이트·마지막 종가 상태 연결.
- `frontend/src/live/liveNavigate.ts`, `TimeframeControl.tsx`, `workspace/ChartWindow.tsx`, 필요 시 `frontend/src/state/workspace.ts`: 선택 창과 복원 상태의 지원 주기 정규화.
- `LiveSymbolSearch`와 검색 모델은 기존 목록을 재사용한다. 지수별 새 검색 UI를 별도로 만들지 않는다.
- 기존 역사 이동의 소유 모듈과 상태바에서 partial/끝 도달/재시도/미설정을 연결한다. 수정 전에 실제 소유 함수를 재확인하고 `LiveChartRoot` 전체를 리팩터링하지 않는다.

완료 기준: 검색·직접 URL·저장 창 복원으로 연 세 지수 모두 일봉을 표시한다. 거래일이 KST 자정이나 DST 변경으로 이동하지 않고, 국내 창의 주기·구독 동작은 유지된다.

### 단계 5. 지수 A 통합 검증·수동 확인·문서 정리

아래 검증을 통과한 뒤 제한된 실서버 재확인을 수행한다. 구현 중 일반 테스트는 실인증·네트워크에 의존하지 않는다. 프로브에서는 주문·WS 연결을 하지 않고, 기존 캐시 토큰과 보수적 페이싱을 사용한다.

### 단계 6. 미국 종목 B의 식별자·목록·실측 게이트

- B1의 식별자를 `LiveInstrument`, `liveNavigate`, 그룹/핀·관심종목·최근검색·URL·워크스페이스 복원에 연결한다. 현재 `kind !== index` fallback을 찾아 국내 경로로 들어가지 않게 한다.
- 미국 목록용 모듈/라우트와 검색 source를 추가한다. `hoga/live/kiwoom_rest.py`의 TR 표, 관련 `kiwoom_capacity.py`/runtime 설정을 확장하고 국내 master를 바꾸지 않는다.
- NASDAQ·NYSE·AMEX에서 마스터로 확인된 종목을 각각 실제 조회한다. 연속조회·과거 점프·USD 소수점·수정주가·환율 옵션·세션 범위·권한 실패를 기록한다. 수정 기준 실측이 끝나기 전에 조정된 장기 차트를 완성했다고 보고하지 않는다.

### 단계 7. 미국 종목 B의 어댑터·API·차트 연결

- `hoga/live/kiwoom_us_daily_candles.py` 신규와 미국 종목 전용 라우트를 추가한다. `us_daily_candles.py`에 동일한 완료 구간 계약으로 연결한다.
- 미국 종목 전용 프론트 조회 훅과 번들 변환을 추가하고 기존 차트 창에 연결한다. `LiveCandle`의 국내 정수 모델·`kiwoom_venue.py`는 미국 지원을 위해 느슨하게 바꾸지 않는다.
- 가격 기준·통화·티커·거래소가 캐시/query/placeholder 식별자 전체에 반영되는지 확인한다. 수정 기준이 바뀌면 최근 tail뿐 아니라 필요한 과거 캐시도 갱신한다.
- 해외지수와 미국 종목의 날짜·최근 갱신·지원 주기 처리를 공유하고 국내 전용 sidecar 요청을 차단한다.

### 단계 8. 미국 종목 B 통합 검증과 최종 범위 기록

- 아래 B 검증표를 완료하고 A·국내 경로 회귀를 확인한다. 초기 미국 일봉 지원을 분봉·실시간·주문 지원으로 확대해서 보고하지 않는다.
- ADR-0136에는 KIS 예외를 지수 일봉에만 한정한다. 미국 종목은 키움 REST 경로로 추가되므로 KIS 예외 범위를 넓히지 않는다.
- 최종 구현 문서에 A와 B의 완료 여부·실측한 종목/거래소·미검증 범위를 구분해 기록한다.

## 완료 기준

1. 세 지수를 기존 검색·URL·저장 창에서 열면 일봉이 보이고 지원하지 않는 주기는 요청되지 않는다.
2. 차트의 날짜와 OHLC가 저장된 실응답 및 제한된 새 실호출과 일치한다. 전체 과거를 미리 받지 않는다.
3. 과거 팬에서 받은 범위와 미조회 범위를 구분하고, 페이지 제한·실패 때문에 생긴 구멍이 영구 캐시되지 않는다.
4. 새 미국 거래일·정정 봉은 재시작 없이 최근 구간 갱신으로 반영되고, API 장애 시 마지막 정상 데이터와 상태가 유지된다.
5. 다중 창 요청을 공유하고, 한투/키움 호출 격리·기존 국내 차트·REST bypass·창/작업 정리 회귀 테스트가 통과한다.
6. 나스닥 2000-01-03, S&P 500 2005-06-02의 양성/이전 구간 음성 경계를 재확인한다. SOX도 과거 표본을 추가 조회하되 실제 경계를 측정하기 전에는 최대 보유일을 표시하지 않는다.
7. ADR-0136의 좁은 예외와 운영 설명이 구현 범위·실측 근거와 일치한다. 키·토큰이 fixture·로그·문서에 포함되지 않는다.
8. 미국 종목 B에서는 NASDAQ·NYSE·AMEX의 마스터로 확인한 종목을 검색·선택하고 키움 REST로 일봉을 받는다. 거래소·티커·USD 정밀도·원본 거래일이 URL·다중 창·복원·캐시까지 유지된다.
9. 수정주가를 제공하려면 B4의 분할·동일 척도·캐시 무효화 실측과 테스트가 통과해야 한다. 확인되지 않은 수정주가를 기본값으로 출하하지 않는다.
10. 미국 종목은 국내 수집·호가·주문·study 경로에 들어가지 않고, 한투 지수 경로와 키움 종목 경로가 자격·장애·요청 예산 측면에서 구분된다. A만 끝났다면 B까지 완료했다고 보고하지 않는다.

롤백은 A(해외지수 목록·한투 분기)와 B(미국 종목 노출·키움 미국 TR 분기)를 나누어 수행할 수 있어야 한다. 미국 종목 식별자를 저장한 뒤 기능을 되돌렸을 때는 해당 창을 미지원으로 표시하고 국내 코드로 재해석하지 않는다. 신규 디스크 시세 데이터나 국내 데이터 마이그레이션은 만들지 않지만, 워크스페이스 저장 상태의 새 instrument 종류에 대한 하위 버전 동작은 검증한다. 이 계획의 완료는 문서 작성이며, 구현·PR 생성·운영 배포·재기동은 아직 수행하지 않았다.


## 구현 중 확정한 수정주가 정책

2026-10-18 키움 실측에서 `upd_stkpc_tp=1`의 과거 가격은 `strt_dt`에 따라 달랐다.
NVDA의 2024-06-07 종가는 조회 기준일 2024-06-07에서 1,208.88,
2024-06-11에서 120.888이었다. AAPL의 2020-08-28도 각각 499.23과 124.8075였다.
따라서 이번 구현은 **USD·수정 전 가격(`upd_stkpc_tp=0`)**으로 명시한다.
환율은 적용하지 않는다. 수정주가를 제공하려면 공통 기준일을 고정하고 분할 시
이전 전체 구간을 무효화하는 후속 작업이 필요하다. 원본 거래량은 API에 보존하되
세션·가격 기준 검증이 끝나기 전 화면과 거래량 지표에는 사용하지 않는다.
미국 종목 당일 봉은 뉴욕의 다음 날짜가 될 때까지 제외한다.
[수정주가 실측](../research/2026-10-18-kiwoom-us-stock-basis-probe.json)과

## 구현된 사용 경로와 지원 범위

`/live` 검색에서 나스닥·S&P500·SOX 또는 미국 종목명/티커를 선택한다.
해외 대상은 저장된 봉 주기나 단축키와 관계없이 D로 열리며, 검색·관심목록·URL·그룹·핀
복원을 지원한다. 최근 구간은 5분 간격으로 다시 확인하며 WS로 미국 데이터를 구독하지 않는다.

- 지수: `/api/live/index-candles?index_id=NASDAQ_COMPOSITE&timeframe=D&from=20261001&to=20261018`
- 종목: `/api/live/us-stock-daily-candles?exchange=NASDAQ&symbol=AAPL&from=20261001&to=20261018`
- 특수 티커: `exchange=NYSE&symbol=BRKb`, `exchange=NYSE&symbol=AHT_pd`
- 목록: `/api/live/us-stocks` — 지원 거래소만 선별하고 `(exchange, symbol)`로 중복을 제거한다.

키움 마스터 원본은 19,378행이었으며, NASDAQ·NYSE·AMEX만 남기고 중복을 제거한
검색 목록은 12,758종목이었다. NP 거래소는 공식 일봉 요청 구분(NA/ND/NY)에 없으므로
이번 범위에 포함하지 않는다. `BRKb`, `AHT_pd`처럼 소문자·밑줄이 포함된 티커도
원문 그대로 보존한다. 둘 모두 실제 일봉 12건을 확인했다.
[티커 형식 실측](../research/2026-10-18-kiwoom-us-master-symbol-formats.json),
[특수 티커 실조회](../research/2026-10-18-us-daily-symbol-case-smoke.json) 참조.

확보했다. [연속조회 검증](../research/2026-10-18-us-daily-continuation-smoke.json) 참조.
장기 요청이 조회 예산을 넘으면 오른쪽 완료 구간부터 보여 주며, 자동 추가 조회 횟수에는
상한이 있다. 남은 구간은 화면의 `더 조회`로 이어서 받을 수 있다.

임의의 최대 보유 연도를 확정하지 않는다.

미국 종목 자동 수집·저장 학습뷰, 일본·홍콩 등 다른 시장은 이번 제공 범위 밖이다.
