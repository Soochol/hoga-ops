# 기관·외국인 순매수 순위 구현 계획

작성일: 2026-10-09 KST

우측 순위 패널에 `기관`·`외국인` 탭을 추가한다. 장중 추정 순매수 금액 상위 종목을 최대 100개 표시한다. 금액은 억원, 현재가·등락률은 선택한 거래소 기준으로 보완한다. 시장 필터, ETF 제외, 클릭·드래그 차트 이동, 관심 그룹 메뉴는 기존 동작을 유지한다.

## 조사 근거와 범위

- [키움 ka10065 공식 가이드](https://openapi.kiwoom.com/m/guide/apiguide/01/ka10065): 장중투자자별매매상위. `trde_tp=1` 순매수, `orgn_tp=9999` 기관계·`9000` 외국인, `amt_qty_tp=1` 금액. 시장은 `000` 전체·`001` 코스피·`101` 코스닥이다.
- [키움 공식 예제](https://github.com/Kiwoom-Securities/Kiwoom-REST-API/blob/main/examples/국내주식/순위정보/get_domestic_intraday_investor_trade_top.py)와 읽기 전용 실콜에서 경로는 `/api/dostk/rkinfo`다. 공식 가이드의 `/api/dostk/stkinfo` 경로 표기와 다르다.
- 응답 래퍼는 `opmr_invsr_trde_upper`, 금액 필드는 `netslmt`. 금액 조회에서 매수·매도·순매수는 부호 있는 백만원 단위다. 예: 기관계 SK스퀘어 `buy_qty=+129591`, `sel_qty=-65331`, `netslmt=+64260`. 제공된 순매수 값을 사용하며 원으로 정규화한다.
- [장중투자자별매매상위 공식 도움말](https://download.kiwoom.com/hero4_help_new/1053.htm)은 주기적으로 갱신되는 추정치라고 설명한다. 확정 일별 순위로 표시하지 않는다.
- ka10065에는 거래소·일자 입력이 없다. KRX/NXT/통합 어느 기준인지 단정하지 않는다. 순위 응답 `venue=null`, 보완 시세 `quote_venue=KRX/NXT/UN`으로 기준을 분리하고 화면에 `순위: 거래소 지정 미지원 · 시세: …`를 표시한다. 거래소를 바꾸면 시세와 캐시는 변경되지만 순위 API 조건은 같다.
- 실제 기관·외국인 조회에서 각각 100개 행과 `cont-yn=N`을 받았다. 휴장일에 조회한 이전 자료이므로 장중 갱신 검증의 근거로 삼지 않는다.
- ka90009는 일자별 자료이며 금액 단위가 천만원이고 실제 25행을 받았다. 거래소 선택 시 외국인 순위에 같은 자료가 반환된 사례도 있어, 이번 장중 상위 100개 기능은 ka10065로 구현한다.

## 구현 순서

1. 공용 REST TR 테이블에 ka10065 경로·래퍼·필수 입력·커서를 등록한다.
2. 순위 fetcher에 `institution`·`foreign`을 추가한다. 각 페이지를 공용 거버너로 제출하고 최대 8페이지 내 상위 100개를 확보한다. 금액이 양수인 종목만 금액순으로 정렬·중복 제거·재번호 부여한다.
3. 현재가가 없는 순위 자료에 ka10095 배치 시세를 보완한다. 최대 100종목을 한 요청으로 공용 거버너에 제출한다. 시세가 누락된 종목은 null을 유지한다. 순위·시세 요청 실패는 정상 결과로 캐시하지 않는다.
4. API에 nullable `investor_net_buy_won`(원)·`quote_venue`를 추가한다. 장중 추정 순위는 정규장에 30초, 장외에 60초 캐시·폴링하며 기관/외국인·시장·시세 거래소·거래일을 분리한다. 휴장일은 상류 호출 없이 빈 당일 순위를 반환한다.
5. 기존 네 탭은 첫 줄, 프로그램·기관·외국인은 둘째 줄에 표시한다. 금액을 종목명 아래 억원으로 표시하고 드래그 고스트에도 보존한다. 탭 전환 시 등락률 재정렬을 기본 순위로 초기화한다.
6. 단위·조건·배치·커서·유량 경계·TTL·동시 요청·거래일·실패·ETF 필터 및 UI 전환·금액·차트 이동을 검증한다. 타입 검사·린트·빌드와 실제 Chrome에서 280px 패널 레이아웃을 확인한다.

## 진행 상황

구현 및 로컬 검증 완료.

- `/api/live/rankings?kind=institution` 및 `kind=foreign`으로 조회한다.
- 최대 100개는 ETF 제외 전 기준이다. 필터링이나 결측·순매도 제거 후 목록은 100개보다 적을 수 있다.
- 순위 거래소 지정이 지원되지 않는다는 표시와 선택 거래소의 시세를 연결했다. 기관은 기관계 합계, 외국인은 외국인 투자자 조건이다.
- 기존 프로그램 탭과 일반 순위 네 종류의 동작을 함께 검증했다.

## 검증 결과

- Python: 투자자·프로그램·기존 순위, REST seam, 용량 경계 테스트 **110개 통과**.
- 프론트: RankingDrawer·QuoteRow·rankingSort·liveRankings 테스트 **61개 통과**.
- `npm run typecheck`, 변경 파일 ESLint, Python Ruff, `git diff --check` 통과.
- `npm run build` 통과. 기존 live-workspace 청크 크기 경고는 남아 있다.
- 실제 Chrome에서 실제 컴포넌트와 모의 API로 280px 패널을 확인했다. 일곱 탭과 금액·현재가·등락률이 패널 안에 표시되고, 기관·외국인·프로그램 전환이 정상이다. 폰트 요청 11개가 모두 HTTP 200이고 자바스크립트 오류는 없다.
- 2026-10-09는 휴장일이다. 구현 후 실제 장중 갱신·실제 유량은 검증하지 않았다. 운영 배포·재기동은 수행하지 않았다.

## 2026-10-09 상위 100개 확장

사용자 요청에 따라 기관·외국인만 최대 100개로 확장했다. 프로그램은 최대 50개를 유지한다. ka10065 실제 응답에서 확인한 100개 행을 활용하며, 연속조회도 100개 확보 시 종료한다. 보완 시세 ka10095의 실측 배치 상한이 100종목이므로 한 요청으로 조회한다. 화면 설명과 금액순 순위·배치 상한·페이지 종료 테스트를 함께 수정했다.
