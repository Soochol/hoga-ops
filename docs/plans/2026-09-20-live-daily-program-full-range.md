# Live 프로그램 순매수 전체 기간 확장 계획

작성일: 2026-09-20  
상태: 구현 및 검증 완료

## 대상과 문제

`/live`의 **프로그램 데이터 창 → 일별 탭**은 기간 선택이 `5일 / 20일 / 60일`로
고정되어 있었다. 화면에 이미 적재된 데이터가 더 많더라도 최대 60행까지만 볼 수 있고,
최근 조회 범위(130달력일)보다 오래된 데이터는 요청할 방법이 없었다.

일봉 차트의 프로그램 pane은 차트 조회 범위를 이미 따르고 있으므로 이번 변경 대상이 아니다.

## 제품 결정

- 기존 기간 칩에 `전체`를 추가한다.
- `전체`는 무제한 일괄 요청이 아니라 **점진 확장**으로 동작한다.
- 먼저 이미 받은 데이터를 60행 단위로 펼친다.
- 받은 데이터를 모두 표시한 뒤 사용자가 `과거 데이터 더 보기`를 누르면 이전
  130달력일을 한 페이지씩 가져온다.
- 과거 데이터는 명시적 사용자 동작으로만 요청하고, 최근 데이터의 60초 폴링에는 포함하지 않는다.
- 날짜 중복 시 최근 조회 응답을 정본으로 사용한다.
- 오류가 나면 성공한 데이터는 유지하고 같은 구간을 `다시 시도`한다.

이 방식은 초기 화면과 벤더 API에 큰 부하를 만들지 않으면서 원하는 만큼 과거로 확장할 수 있다.

## UI 동작

1. 일별 탭의 선택지는 `5일 / 20일 / 60일 / 전체`다.
2. `전체` 진입 시 최신 60행을 보여준다.
3. 적재된 행이 더 있으면 `더 보기`로 다음 60행을 즉시 펼친다.
4. 적재된 행을 모두 펼치면 버튼이 `과거 데이터 더 보기`로 동작해 이전 페이지를 요청한다.
5. 요청 중에는 `과거 데이터 조회 중`, 실패 시에는 오류 문구와 `다시 시도`를 표시한다.
6. 종목 변경 시 펼침 수는 60행으로 초기화한다.
7. 선택한 `전체` 상태는 기존 표시 설정과 함께 로컬 저장소에 보존한다.

합계와 일평균은 현재 화면에 표시된 행을 기준으로 계산한다.

## 데이터 설계

### 최근 구간

기존 `ProgramWindow` 조회를 유지한다. 종목별 최근 130달력일을 60초 주기로 갱신한다.

### 과거 구간

`useDailyProgramTradeHistory`가 수동 infinite query를 담당한다.

- 첫 페이지: 최근 구간 시작일 바로 전날부터 과거 130달력일
- 다음 페이지: 직전 페이지 시작일 바로 전날부터 과거 130달력일
- 쿼리 키: 종목 코드와 최근 구간 시작일
- 자동 실행 없음, 재시도 없음, 과거 페이지는 무기한 fresh
- API warning이 있으면 페이지를 성공 처리하지 않아 커서가 진행되지 않음
- 종목/기간이 없거나 연결되지 않았으면 inert

최근 구간과 과거 페이지는 `t_ms`를 키로 합친 뒤 시간 역순으로 정렬한다. 병합 순서는
과거 데이터를 먼저 넣고 최근 데이터를 나중에 넣어, 겹치는 날짜는 최신 응답이 덮어쓴다.

## 변경 범위

- `frontend/src/state/programTradeDisplay.ts`
  - 일별 기간 타입에 전체를 뜻하는 `0` 추가
  - 저장값 검증에 `0` 허용
- `frontend/src/live/useDailyProgramTradeHistory.ts`
  - 과거 130일 페이지 수동 조회 hook 추가
- `frontend/src/live/workspace/DataWindow.tsx`
  - 최근/과거 데이터 병합
  - 과거 조회 상태와 액션을 카드에 전달
- `frontend/src/sidebar/ProgramTradeSummaryCard.tsx`
  - `전체` 칩과 점진 펼침/과거 조회 UI 추가

백엔드 API 계약은 바꾸지 않는다.

## 테스트 계획과 완료 기준

- 카드 UI
  - `전체` 선택 시 60행부터 시작
  - 캐시된 행을 먼저 펼치며 이때 네트워크 콜 없음
  - 캐시를 모두 펼친 다음 동작에서만 과거 페이지 요청
  - `dailySpan: 0` 저장 확인
- 과거 조회 hook
  - 사용자 동작 전 요청 없음
  - 페이지 범위가 겹치지 않고 과거 방향으로 이동
  - warning/실패 후 같은 커서 재시도
  - 종목 없음/연결 끊김 상태에서 요청 없음
- 회귀
  - 기존 프로그램 데이터 창 테스트
  - 프론트 전체 단위 테스트와 타입 검사
  - 일별 프로그램 및 Live smoke E2E

완료 조건은 사용자가 `전체`에서 이미 받은 모든 행을 볼 수 있고, 필요할 때 이전 기간을
반복해서 추가 조회할 수 있으며, 로딩·실패·재시도가 기존 데이터 손실 없이 동작하는 것이다.
