# 미국 지수 차트 갱신 설계

대상은 나스닥 종합·S&P 500·SOX. 사용자 요청에 따라 실측 후 설계를 정하고 구현한다.
근거는 `docs/research/2026-10-22-us-index-live-*.json`이다. 두 회사 WS는 등록 ACK만
성공하고 180초간 지수 0건이었다. 한투 REST는 2초 간격 조회에서 진행 중 봉 가격이
바뀌었다. 새 분봉의 관측 시점은 실제 거래소 대비 지연 시간의 보장이 아니다.

## 결정

- 기존 한투 `FHKST03030200` 스냅샷을 지수별 single-flight/메모리 캐시로 공유한다.
  분봉 주기·헤더·D/W/M·창/브라우저 수가 늘어도 업스트림 호출은 지수당 2초에
  최대 한 번이다. 세 지수 합계 최대 약 1.5회/초이며 기존 KIS 공용 15회/초 버킷을 쓴다.
- 뉴욕 평일 09:30~17:20은 2초, 그 밖은 60초. 이는 **조회 예산 시간대**이며 휴장일,
  조기폐장 또는 실제 개장 상태를 추정하는 캘린더가 아니다. 장후 보정도 유지한다.
  빈 응답·이전 날짜만 반환하면 60초로 둬 휴장일에 빠른 조회를 반복하지 않는다.
  화면이 가려지면 빠른 브라우저 폴링을 멈추고, 다시 보이면 갱신한다. 상시 수집기는 없다.
- 서버가 `refresh_interval_ms`를 내려 헤더와 차트가 같은 정책을 따른다. 실패는
  2/4/8/16/32/60초로 백오프하고 마지막 정상 데이터와 확인 시각을 보존한다.
  정상 빈 응답으로 기존 창을 지우거나 더 오래된 스냅샷으로 되돌리지 않는다.
- D/W/M의 진행 중 당일 봉은 최근 102분을 합산해 만들지 않는다. 같은 응답의
  `output1` 당일 OHLC를 날짜·코드·최신 분봉 종가와 검증한 뒤 일시적으로 합친다.
  완료 일봉 캐시·검증 완료 구간에는 저장하지 않는다. W/M은 기존 검증된 일봉과
  당일 봉을 집계하고, 과거 미조회 구간을 건너뛰어 완전한 봉을 만들지 않는다.
  완료 일봉이 같은 날짜에 있으면 기존 완료 일봉이 우선한다.
- 과거 전용 D/W/M 조회에는 최신 분봉을 요청/혼합하지 않는다. 국내 지수 WS,
  미국 개별주식의 60초 갱신, 과거 분봉 보유 범위와 무지연 미확인 표시는 유지한다.

## 검증

가상 시계로 2초 TTL·다중 요청 합류·뉴욕 DST/자정/주말·장후 보정·백오프·정상 복구·
빈/역행 응답·완료/진행 중 D/W/M·과거 격리를 검사한다. HTTP 직렬화와 BE/FE 계약,
브라우저의 빠른 봉 갱신·상태·기존 기간 전환을 확인한다. 검증 서버는 무자격이며
실측 자격증명을 복사하지 않는다. 기존 운영 서버는 재시작하지 않는다.
