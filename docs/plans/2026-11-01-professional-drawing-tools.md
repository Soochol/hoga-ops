# 빠른 도구 메뉴와 1차 분석 그리기

2026-11-01 사용자 승인 범위. 차트의 그리기를 개선하며 화이트보드의 Excalidraw는
변경하지 않는다. 앱의 기존 테마·타이포그래피·밀도 토큰과 저장 데이터는 유지한다.

## 사용자 동작

- 그리기 버튼 → 검색/즐겨찾기/분류별 목록 → 도구 선택 → 차트에 생성.
- 수평 레이는 시작점을 클릭한다. 추세선은 기존 두 점 드래그 후 설정에서 연장한다.
- 피보나치 되돌림은 두 점을 드래그한다. 0은 끝 가격, 1은 시작 가격이며 반전 가능하다.
  기본 0/0.236/0.382/0.5/0.618/0.786/1, 선택 옵션 1.272/1.618과 가져온 레벨을 지원한다.
- 평행 채널은 기준선을 드래그하고 세 번째 점으로 폭을 클릭해 확정한다. Esc·우클릭·
  포인터 취소·창 포커스 상실·도구 또는 종목/봉 범위 전환은 미확정 채널을 버린다.
- 롱·숏 포지션은 캔들 pane에서 진입→목표 영역을 드래그한다. 기본 손익비 2:1이며
  진입·목표·손절 핸들을 조절한다. 가격 순서가 뒤집히는 편집은 반영하지 않는다.
- 기본 단발 생성 후 새 항목이 선택된다. 연속 그리기를 켜면 일반 도구를 유지한다.
  일자 고저시종 기준선은 단발, 지우개는 연속인 기존 정책을 유지한다.
- 속성 패널 설정에서 이름·좌표를 한 번에 적용한다. 값의 소수 정밀도와 Unix-ms를
  보존하고 시각 입력은 KST(밀리초 포함)로 해석한다. 펜은 기존 개별 점 편집 대신
  이름·스타일 편집을 제공한다.
- 그리기 목록에서 현재 종목·봉 슬롯의 항목을 선택·숨김·잠금·삭제한다. 잠긴 항목은
  숨김/편집/삭제도 차단하며 목록의 해제 버튼으로 복구한다.

## 구현·호환성

- 새 종류: hray, fib, channel, long-position, short-position.
- analysisGeometry는 렌더·hit-test·영역 선택이 공유하는 투영을 소유한다.
- analysisTools는 draft→preview/commit 생성과 채널의 두 단계 제스처를 소유한다.
- 기존 translate/pricesOf/timesOf/refCoords에 신규 종류를 연결해 그룹 이동·정렬·복제와
  undo/redo를 재사용한다. 잠금은 기존 store에서 계속 집행한다.
- 형식 wrapper·키 버전은 바꾸지 않는다. 신규 도구의 style slot은 구버전 defaults에
  기본값으로 추가한다. 즐겨찾기·연속 그리기·최대 32개 스타일 템플릿은 기존 defaults에
  선택 필드로 저장하며 부재는 구버전 payload와 호환된다. 다른 탭에 실시간 동기화하는
  새 storage 리스너는 추가하지 않는다.
- 포지션은 계획용이다. 실주문, 자동 체결/손익 확정, 계좌 조회, 비용 반영은 하지 않는다.
- 앵커 VWAP·고정 구간 매물대와 봉 슬롯 간 공유는 후속 범위다.

## 검증

타입 검사, 전체 프런트엔드 단위 테스트, Vite build와 신규·기존 그리기 E2E를 수행한다.
현재 head/base·입력 지문·도구 버전·명령·결과는
`docs/diagnostics/2026-11-01-professional-drawing/verification.json`에 기록한다.

전체 단위 검사에서 기존 `chartTradeAccounts`의 storage 리스너가 정책 선언에 누락된
것을 확인했다. 동작이나 검증 가드를 바꾸지 않고 `NON_DEFAULT_PERSISTENCE`에 실제
키의 shared-synced 정책을 등록한다.
