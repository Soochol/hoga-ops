# 우측 패널의 전체 순위를 조건검색에 추가

2026-11-01 사용자 승인. 이미 구현한 거래대금·상승률 순위를 유지하고 신규 5종과
등락률 하락 방향을 추가한다.

| 조건 타입 | 우측 순위 원천 | 기본 / 최대 N | 값·갱신 |
|---|---|---|---|
| `volume_surge_rank` | `surge`, ka10023 | 100 / 5,000 | 원본 1분 기준 급증률 %, 10초 |
| `volume_rank` | `volume`, ka10030 | 100 / 5,000 | 당일 누적 거래량 주, 10초 |
| `program_net_buy_rank` | `program`, ka90003 | 50 / 5,000 | 순매수금액 원, 30초 |
| `institution_net_buy_rank` | `institution`, ka10065 | 100 / 100 | 기관 추정 순매수금액 원, 30초 |
| `foreign_net_buy_rank` | `foreign`, ka10065 | 100 / 100 | 외국인 추정 순매수금액 원, 30초 |

등락률 `direction=down`은 같은 ka10027의 하락 방향이다. 등락률 낮은 순이며 절댓값이
아니다. `direction` 누락은 기존 `up`이고, 명시적 기본값을 요청 키와 발생 제외 키에서
정규화해 기존 저장 조건·제외가 유지된다. 근거에는 방향을 보존하며 같은 행에서
상승·하락 근거를 각각 열 수 있다.

## 계약과 평가

새 조건은 카탈로그·메뉴·wire·저장 CRUD·AND/OR·상태·발생 제외·자동 갱신·정확 재실행
금지에 함께 등록한다. 상한은 정수이며 입력을 임의 보정하지 않는다. 기관·외국인은
현재 패널과 같은 100위까지 사용하며 더 깊은 공급자 조회를 새로 구현하지 않는다.

`screener_rankings`는 종류와 방향별 최대 N 요청을 한 번 수행하고 우측 패널이 소유하는
fetcher의 조회·캐시·거버너를 재사용한다. 시장 순위 산정 후 ETF·거래정지·스코프를
적용한다. 거래대금은 공급자 순위, 나머지는 기존 패널 fetcher가 보존한 원래 순위를
쓴다. 순위 단독 조회를 위해 전체 시장 OHLCV overlay를 추가하지 않는다.

기관·외국인은 정규장 개장 후 추정치이며 순위 거래소는 null이다. `quote_venue`만 선택한
시세 거래소를 담는다. 프로그램·기관·외국인은 수량이 아니라 양수 순매수금액 순위다.
누락·비유한 값·잘못된 수량/금액·날짜·거래소·방향 불일치는 명시적 조회 오류다.
신규 근거 `market_rank_match`에는 원본 값과 단위를 구별할 종류를 보존한다.

일반 순위를 하나라도 포함하면 10초, 순매수 순위만 있으면 30초로 자동 조회한다.
사용자 주기 설정은 유지한다. 혼합 조회에서도 순매수 fetcher의 30초 캐시는 공유된다.
같은 날의 10초/30초 관측 차이는 전일 데이터로 표시하지 않고 실제 혼합 시각으로 알린다.

## 휴장일과 검증

이전 [기준일 개선](2026-11-01-ranking-session.md)의 날짜 판정·관측 기록을 재사용한다.
하락 방향은 상승 기록으로 대체하지 않고, 기관·외국인의 순위/시세 거래소를 구분해
복원한다. 기록이 없는 날짜·범위와 자료 부족은 평가 불가이며 0건으로 처리하지 않는다.

기존/분리 계산 정책, AND/OR, 필터 후 원래 순위, 두 등락 방향의 독립 공유,
원본 단위·금액·null 거래소, 저장/HTTP 직렬화, 오류·입력 상한, 휴장 기록 복원을 검사한다.
브라우저에서는 5종 추가·수정·저장·새로고침·근거 열기와 기존 상승 조건의 하락 전환을
확인한다. 검증 기록은 `2026-11-01-screener-market-ranks-validation.json`에 남긴다.
