# 계산 기준 분리 구현과 검증

2026-10-24. 사용자 승인 설계: [수정주가·신고거래량 분리](2026-10-24-screener-adjustment-bases.md).
기존 ADR-0057의 단일 계수 정책은 `legacy_v1`에서 유지하고 새 정책만 분리했다.
운영 코드·서버를 교체하거나 운영 988종목을 일괄 재수집하지 않았다.

## 실행·저장 계약

- 정책이 없는 요청·기존 저장 조건·미저장 초안은 `legacy_v1`이다. 기존 파일의 자동 이관·재보정은 없다.
- 새 조건검색 버튼과 ‘새 기준으로 복사’는 `separate_bases_v2`를 명시한다. 복사는 원본 id와 발생 제외를 가져오지 않는다. 다른 정책으로 기존 id를 덮어쓰면 422다.
- 새 저장 조건은 `saves.v2.json`(schema 2), 새 발생 제외는 `exclusions.v2.json`이다. 목록 응답만 두 저장소를 합친다. 구버전은 기존 파일을 계속 사용할 수 있다.
- 새 D/W/M 신고거래량은 기본 `share_adjusted`, 선택 `raw`다. 분봉은 raw이고 명시적인 share_adjusted 분봉 요청은 422다. 가격 조건 파라미터에는 수량 옵션을 추가하지 않았다.
- 가격은 기준일이 같은 공급자 수정 OHLC, 수량은 독립적으로 확인한 정수 비율, 금액은 공급자 실제 거래대금 또는 원주가 OHLC 평균 × 원본 거래량이다. 주·월 금액은 일별 합계다. 결과에 실제·추정·혼합 근거를 표시한다.
- 수량은 `Fraction`으로 비교한다. 현금 이벤트는 수량을 바꾸지 않고, 분할·병합·비례 배정은 효력일 전 일봉만 후보일 단위로 환산한다. 가격 이벤트 문자열을 수량 이벤트로 해석하지 않는다.
- 비교 창의 원본 누락·충돌, 가격 부족, 수량 이력 부족은 구분된 커버리지다. 미확인 수량을 raw 또는 1배로 바꾸지 않는다. 0만 있는 거래량 창은 신고가 아니다.

## 저장·수집

물리 경로는 `<data_dir>/screener/series_v2/`다.

```text
baseline.json                   최초 기준선 포인터
legacy/<hash>/                  기존 파일의 독립 복사본, 달력, 해시·행/종목 수·범위·코드 지문
objects/<sha256>.json            공급자 관측, 수량 증거, manifest, 보존 실행
current.json                    완성된 manifest 포인터
```

공급자 원래 행·가격 이벤트 원문 문자열·기준일·관측 시각·행별 위반을 함께 보존한다.
새 관측의 원본값이 baseline 또는 앞선 관측과 다르면 이전 값을 유지하고 충돌 날짜를 보류한다.
새 후보·부모 관측은 별도 불변 객체에 남는다. 같은 기준일의 페이지는 병합하며 새 기준일에는 가격 조각을 혼합하지 않는다.

객체와 manifest의 파일·디렉터리를 fsync한 후 포인터를 원자 교체한다. 기존 writer와 같은 파일 잠금을 사용하며 네트워크 중에는 잠그지 않는다. 실패한 포인터 공개·최초 복사 실패와 동시 페이지 병합을 검증했다. 자동 GC는 없다.

명시적 ‘새 기준 일봉 준비’는 기존 클라이언트·페이지별 background 거버너를 사용한다.
이미 완전한 동일 기준일 관측은 재사용한다. 추가 행 수는 기존 원본에 없던 완료 일자만 센다.
이 작업은 수량 사건을 추정하거나 기존 parquet/factors/saves/exclusions를 덮어쓰지 않는다.
원본 파싱에서 제외된 날짜도 보관하고, 그 날짜가 필요한 창만 보류한다.

## 검증된 수량 증거 등록

현재 구현은 **명시적인 검증 자료 import**를 제공한다. 공급자 수정률로 전국 종목의 수량 비율을 자동 생성하는 기능은 없다.
운영 전환에는 거래소·발행사 등에서 사건 종류·비율·효력일과 해당 구간의 완전성을 확인한 자료가 필요하다.
빈 events는 확인한 구간에 사건이 없다는 선언이며, 미조회 상태를 뜻하지 않는다.

아래는 형식 설명용 가상 예이며 실제 종목에 그대로 등록하는 자료가 아니다.

```json
{
  "code": "000001", "instrument_id": "stock:000001",
  "verified_from": "2020-01-01", "verified_to": "2020-12-31",
  "observed_at": "2026-10-24T12:00:00+09:00", "source": "검증 원문 출처",
  "events": [{"effective_date": "2020-05-04", "kind": "split",
    "numerator": 5, "denominator": 1, "source": "효력일·비율의 원문 출처"}]
}
```

```bash
python -m hoga.api.screener_series_cli import-evidence --data-dir /별도/데이터 --input 검증자료.json
```

동일 종목 정체성을 증명하지 못한 합병·코드 재사용은 자동 연결하지 않는다.
현재 원본 충돌은 검토 후보로 보존하며, 승인 없이 정정값을 채택하는 경로는 없다.
전 종목 수량 소스의 자동 검증·공급자 정정 승인 UI는 이번 변경의 완료 범위에 포함하지 않는다.

## 결과 보존과 정확 재실행

일반 조회·모니터링은 기존 30분 화면 캐시를 유지한다. 이를 영구 실행 기록이라고 표시하지 않는다.
‘이 스냅샷으로 확정 일봉 결과 보존’은 같은 스냅샷과 조건으로 **확정 D/W/M 결과를 다시 계산**해 입력과 답을 보존한다.
실제 종목 집합·종목 이름/분류·거래일 달력·발생 제외·평가 시각·코드/런타임 지문을 고정한다.
분봉·총잔량·장중 오버레이의 정확 재실행은 제공하지 않으며 보존 요청을 422로 거절한다.

- `POST /api/screener/executions`: 확정 D/W/M 실행 생성, 응답의 execution_id를 보관한다.
- `GET /api/screener/executions/{id}`: 당시 답 읽기.
- `POST /api/screener/executions/{id}/replay`: 동일 코드·환경일 때 고정 입력으로 재실행하고 결과를 대조한다.
- 코드나 환경이 바뀌면 재실행은 거절하지만 보존된 답은 계속 읽을 수 있다.
- CLI `read`/`replay --execution-id … --data-dir …`도 제공한다. 실행 목록 관리 UI는 추가하지 않았다.

새 결과에서 차트를 클릭해 열면 스냅샷 참조를 전달하고 해당 종목 창에 ‘현재 기준 차트’를 표시한다.
차트의 기존 메모리 데이터 경로를 보존하며 스크리너 당시 가격 버전을 재현한다고 표시하지 않는다.
원래 스냅샷이 없는 기존 결과를 과거 시점 백테스트로 승격하지 않는다.

## 기존·신규 비교

[진단 산출물](../diagnostics/2026-10-24-screener-bases/)에 입력 지문·결과·차이·검증 명령을 보관한다.
운영 파일은 공유 읽기 잠금 아래 독립 복사하고, 비교는 복사본에서만 실행했다.
원본에 미완료 공개 journal이 있으면 복사를 보류하며 복사 도구가 운영 복구를 실행하지 않는다.
비교용 종목 목록만 복사본에서 명시적으로 좁혀 두 정책에 같은 대상을 제공했다.

```bash
python -m hoga.api.screener_series_cli clone --source /원본/데이터 --data-dir /새/검증복사본
python -m hoga.api.screener_series_cli import-pair --data-dir /새/검증복사본 --input 관측쌍.json
python -m hoga.api.screener_series_cli compare --data-dir /새/검증복사본 --input 조건.json \
  --at 2026-10-20T16:00:00+09:00 --output 비교.json
```

실데이터에는 검증된 수량 구간을 임의로 등록하지 않았다. 따라서 share_adjusted가 미확인인 결과는 복구 성공이나 미충족으로 해석하지 않는다.
티앤엘의 raw/기존 차이는 해당 비교 창의 원본·기존 보정량으로 대조한다.
삼성전자 원본 충돌의 최초 출처·venue·정정 여부는 미확인이다. 새 관측을 정답으로 덮어쓰지 않는다.
작은 가격 이벤트·분할/병합·주/월 집계·정밀도·스냅샷 재현의 판정 차이는 검증 범위를 명시한 결정적 fixture로 별도 검증한다.

2026-10-21의 987건 전부를 당시 입력으로 재현하거나 운영에서 복구했다고 주장하지 않는다.
당시 전 종목 원응답이 없고, 현재 표본에는 이후 공급자 변경이 포함될 수 있다.
