# 사각형 그리기 — 캔들 중심 제한 해제

날짜: 2026-09-28  
상태: 구현 완료  
최종 요청: 자석 기능을 제거하고 기본으로 캔들 중심과 무관하게 사각형을 그린다.

## 1. 동작 규칙

- 사각형은 별도 설정이나 Ctrl/Cmd 없이 시작점과 끝점의 가로 위치를 연속적으로 따른다.
- 캔들 사이, 캔들 몸통 내부, 한 봉 너비보다 작은 영역에도 사각형을 생성한다.
- 생성 미리보기와 확정 위치가 같으며, 본체 이동과 모서리 크기 조절도 자유 좌표를 유지한다.
- 그리기 메뉴의 자석 토글과 자동 캔들·이웃 도형 스냅, 스냅 가이드·표시점을 제거한다.
- 예전에 저장된 `magnet: true`도 무시하므로 기존 사용 환경에서도 자유 그리기가 기본이다.
- 같은 봉 주기에서 확대·축소·스크롤·새로고침 후 봉 내부 위치를 유지한다.
- 기존 사각형은 초기 위치를 유지하고 잠금·우측 확장·복제·undo/redo를 지원한다.
- 명시적으로 누르는 정렬·분배와 Shift 각도 제한은 유지한다. 작업창 배치용 스냅은 이번 그리기 자석 제거와 별개다.

## 2. 좌표 모델

기존 `Rect.a`, `Rect.b`의 실제 Unix-ms 앵커와 가격을 유지하고 `Rect.subX?: { a: number; b: number }`에 각 모서리의 가로 잔차를 봉 너비 비율로 저장한다. 필드 부재는 보정 0이다.

투영식은 `x = realMsToCanvasX(realMs) + subX * barPx`이다. 기존 연필의 잔차 방식과 같은 정책을 사용하되 사각형 전용 `rectCoordinates.ts`에서 입력·투영·연속 열 변환·이동·확장을 공유한다. 미래 밴드에서 이미 연속 좌표로 표현된 부분은 재투영 후 남은 잔차만 저장하여 이중 보정을 방지한다.

본체 이동은 포인터 시작 시의 도형 스냅샷에 대한 연속 열 이동량을 두 모서리에 동일하게 적용한다. 봉 앵커로 변환할 때 버린 분수 부분은 잔차에 다시 담는다. 축 원점 제한도 보정된 좌표를 고려하여 도형 폭을 보존한다.

## 3. 호환성과 범위

- 저장 wrapper 버전과 종목×minute/D/W/M 저장 슬롯은 유지한다. 기존 저장 데이터를 폐기하지 않는다.
- 잘못된 잔차는 정규화하며 저장·로드·JSON 왕복·복제·undo/redo에서 보정값을 보존한다.
- 자석 설정만 제거하고 도형 스타일과 숨김 설정은 유지한다.
- 다른 종류의 도형에 봉 내부 보정을 추가하지는 않는다. 자석 제거는 그리기 도구 전체에 적용하지만 이번 자유 가로 좌표 확장은 사각형에 적용한다.
- 같은 주기의 줌·스크롤에서는 정확히 유지된다. 공유 minute 슬롯에서 1m↔30m처럼 봉 주기를 바꾸면 보정값은 보는 주기의 봉 너비로 재해석되며, 실제 시각의 주기 간 동일 보존은 보장하지 않는다.
- 주기 전환 때 저장 좌표를 다시 쓰지 않으므로 편집 없이 원래 주기로 돌아오면 원래 위치로 돌아온다.

## 4. 구현 항목

1. 사각형 좌표 모델과 좌표 왕복 테스트 추가.
2. 생성·draft·렌더·hit-test·마퀴·선택 핸들에 보정 좌표 연결.
3. 모서리·단독·그룹 이동과 클램프, 명시적 정렬·분배, 우측 확장·복제에 보정 연결.
4. 저장 정규화와 복제·undo/redo·잠금 회귀 검증.
5. 그리기 자석 UI·설정·입력 래퍼·자동 정렬 엔진·가이드 제거. 예전 설정 로드 호환성 검증.
6. 실제 브라우저에서 별도 설정 없이 자유 그리기와 편집·줌·재로드 검증.

좌표 정책은 [ADR-0173](../adr/0173-rectangle-sub-bar-coordinates.md)에 기록했다.

- 자석 메뉴 부재, 기존 자석 설정 무시, 스타일·숨김 설정 보존을 회귀 테스트로 고정했다.
- 좌표 왕복, 미래 밴드 이중 보정 방지, 세션 경계·캘린더 좌표, 기존 사각형 호환성 및 잠금·복제·undo/redo는 자동 테스트로 검증했다.
