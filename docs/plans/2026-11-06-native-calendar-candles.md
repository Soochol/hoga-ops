# 국내 Live 네이티브 주·월봉

## 동작과 소유

주·월봉의 긴 일봉 재조회 비용을 줄이기 위해 국내 종목 W/M은 키움
`ka10082/83`을 직접 사용한다. 일봉과 REST 우회 일봉 집계는 유지한다.
[ADR-0048 개정](../adr/0048-live-daily-direct-backfill.md#2026-11-06-개정--국내-종목-wm-네이티브-조회)이 계약 기준이다.

- `kiwoom_calendar_candles.py`: W/M TR, 기간 경계, 부호·금액 단위, 페이지 walk,
  유효 행·중복·절단 진단. 요청 기준일은 오늘, 수정주가는 1이다.
- `live_calendar_candle_backfill.py`: 주기·거래소·Code·수정 기준일 캐시, 현재 기간 TTL,
  초과 반환분 재사용, NXT/통합의 누락 기간 KRX 보완과 역사적 우단 컷오프.
- `/api/live/past-calendar-candles`: 날짜·주기·거래소 검증과 Pydantic wire 응답.
- 기존 FE 캘린더 query hook: D/W/M별 endpoint·key·placeholder 격리.
  `useLiveBundle`은 네이티브 봉을 그대로 사용하며 REST 우회만 일봉을 집계한다.

## 데이터 의미

네이티브 수정 거래량과 원 단위 거래대금은 벤더 W/M 값이다. 일봉의 거래량 합계 및
백만원 정밀도 금액 합계와 완전 동등하지 않다. 첫 봉은 `from`과 겹치는 온전한 기간이며
벤더 대표 거래일에 앵커하므로 `from`보다 앞설 수 있다. 과거 `to`가 기간 도중이면
그 기간만 일봉에서 `to`까지 집계한다. 현재 주·월은 네이티브 진행 봉과 기존 라이브
OHLC overlay를 사용하며 체결 버퍼를 누적 거래량·거래대금에 이중 가산하지 않는다.

## 검증

공식 응답 대표 행 fixture는 2026-11-05 조사 PR #2434의 공개 시세 예제다.
무자격 테스트는 실제 어댑터와 캐시를 실행하고 외부 전송만 MockTransport로 교체한다.
라우트 실제 호출, 일봉 회귀, 금액·수정 거래량, 초과 반환 재사용, TTL·날짜 전환,
venue, 오류 복구·취소·절단·중복 및 과거 컷오프를 확인한다.
브라우저 검사는 W/M endpoint 선택, 표시 가격, 실제 마우스 팬의 추가 로딩,
D 복귀와 M 새로고침 복원을 확인한다. 브라우저의 시세 응답 mock 경계를 명시한다.
실벤더 요청이나 운영 서버 재시작은 하지 않는다. 실벤더 응답·계정 풀 대기·운영 지연의
개선 배수와 모든 종목의 대표 날짜·수정 기준 의미는 이 검사로 보증하지 않는다.
