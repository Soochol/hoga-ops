# ADR-0173: 사각형은 봉 앵커와 봉 내부 가로 보정을 함께 저장한다

**Status:** Accepted  
**Date:** 2026-09-28

사각형의 가로 좌표를 캔들 중심에만 고정하던 제한을 해제한다. 기존 실제 Unix-ms 앵커와 저장 형식을 유지하면서 `Rect.subX?: { a, b }`에 각 모서리의 가로 잔차를 봉 너비 비율로 저장한다. 픽셀 저장은 줌·스크롤 때 위치를 잃고, 시간만 보간해 저장하면 현재 차트의 봉 단위 투영과 캘린더 축에서 다시 중심으로 붙으므로 기존 연필의 잔차 방식과 같은 정책을 채택한다.

렌더·선택·핸들과 명시적인 정렬·분배는 보정된 X를 공유한다. 이동은 시작 스냅샷에 대한 연속 열 이동량을 두 모서리에 동일하게 적용하고, 실제 봉 앵커로 변환하며 버려진 분수 부분을 다시 보정값에 담는다. 사용자 요청에 따라 그리기 자석 토글, 캔들/이웃 도형 자동 스냅, 스냅 가이드와 표시점을 제거했다. 사각형은 별도 키나 설정 없이 포인터 위치를 보존한다. 예전 저장 설정의 `magnet` 값은 로드할 때 무시하며, 다음 기본값 저장에서는 해당 필드를 쓰지 않는다. 명시적으로 누르는 정렬·분배 기능은 유지한다.

필드 부재는 보정 0이므로 기존 사각형의 초기 위치와 저장 wrapper 버전을 유지한다. 같은 봉 주기의 줌·스크롤·재로드에서는 봉 내부 위치가 유지된다. 공유 minute 슬롯에서 봉 주기를 바꾸면 보는 주기의 봉 너비로 보정을 해석하며, 실제 시각을 주기 간 동일하게 보존하지는 않는다. 다른 그리기 종류의 좌표 의미와 연필 저장 형식은 바꾸지 않는다.

검증: 사각형 생성/편집, 렌더·hit-test, 세션 경계·캘린더 좌표 왕복, 저장·복제·undo/redo 단위 테스트와 실제 Chromium 분봉/일봉 생성→이동→리사이즈→줌→재로드 테스트. 구현 계획 및 결과는 [개선 계획](../plans/2026-09-28-rectangle-free-position.md).


2026-09-30 보완: 사각형의 생성·모서리 조절·본체 이동은 시작 pane의 가격 축으로 포인터 Y를 해석하되 pane의 위아래 경계로 제한하지 않는다. 단독 이동, 사각형 그룹 이동 및 명시적 정렬에서 사각형의 가격 이동량도 가시 범위로 제한하지 않는다. 경계 밖 좌표는 저장되며 렌더링은 기존대로 소속 pane 안에서 잘린다. 다른 종류가 포함된 그룹은 해당 도형의 이동 한계에 따라 공통 이동량이 제한될 수 있다. 생성·이동·크기 조절의 위/아래 경계 초과와 사각형 그룹 이동을 회귀 테스트로 검증했다.
