# 0133 — 히트맵 보드 그룹 편집: 우클릭 메뉴 축소 + 그룹명 제자리 변경

**Status:** accepted (2026-07-31)

**Related:**
- ADR-0132 — 한 종목 다중 그룹 등록 + Ctrl 드래그 복제. 이 ADR이 거기서 만든 드래그를
  근거로 우클릭 메뉴의 '그룹으로 이동'을 걷어낸다.
- ADR-0112 — 그룹 삭제는 파괴적(멤버 종목 동반 삭제). 보드에도 같은 confirm 문법을 쓴다.
- ADR-0110 — 공용 ui/ 프리미티브 이관(ChevronIcon). `PencilIcon` 이 같은 근거로 올라간다.

## Context

`/heatmap` 보드의 그룹 편집 수단이 비대칭이었다:

- **행 우클릭 메뉴가 화면을 덮었다.** `HeatmapRowMenu` 는 `folders`/`onMove` 를 받으면
  현재 그룹을 제외한 **실폴더를 전부 세로로 나열**한다. 실사용 보드의 그룹은 38개였고,
  메뉴 높이가 뷰포트를 넘겼다. 우측 레일 드로어는 이 props 를 애초에 안 넘겨 2줄이었다.
- **그룹명을 바꿀 수 없었다.** 이름 변경은 드로어 ⋯ 메뉴에만 있었다. 보드에서 그룹을
  만들 수는 있는데(＋새 그룹) 이름은 못 고치는 비대칭.

## Decision

**1. 행 우클릭 메뉴에서 '그룹으로 이동' 섹션을 삭제한다.**
목록형 섹션은 그룹 수에 비례해 커지므로 컨텍스트 메뉴에 담을 수 없다. 그룹 간 이동은
ADR-0132 의 드래그앤드롭이 대신한다(다른 그룹 블록에 드롭=이동, Ctrl=복제). 남는 항목은
'히트맵에서 제거' + '지난 N일 수집' 둘. `folders`/`currentFolderId`/`onMove` props 는
호출자가 사라졌으므로 함께 삭제한다. 실측 메뉴 높이 뷰포트 초과 → **76px**.

**2. 그룹명 변경은 진입점을 둘 둔다 — 이름 더블클릭(빠른 길) + 헤더 우클릭 메뉴(발견 가능한 길).**
둘 다 같은 **제자리 입력**으로 도착한다(모달 아님). Enter 확정 / Escape 취소 / blur 확정,
마운트 시 전체 선택 — `StudyViewsDrawer` 의 저장뷰 이름 변경과 같은 계약이다.

- 더블클릭만 두면 화면에 아무 표시가 없어 아무도 모른다(`title` 툴팁이 유일한 힌트).
- 우클릭 메뉴만 두면 이름 하나 고치는 데 두 동작이 필요하다.
- **헤더에 ⋯ 버튼은 두지 않는다**: 보드 헤더는 이미 이름 + 당일 흐름 스파크라인 + 평균
  등락률 + ＋종목으로 빽빽하다. 드로어 헤더와 달리 여기선 컨트롤 하나가 밀도를 무너뜨린다.

커밋이 실패하면 **입력을 닫지 않고** 사유를 밑에 띄운다 — 조용히 닫으면 이름이 안 바뀐
이유를 알 길이 없다. 그래서 `onRenameFolder` 는 `Promise` 를 돌려주는 계약이다.

**3. 그룹 삭제도 같은 헤더 메뉴에 둔다.** 파괴적이므로 `tone: 'danger'`(error 색)이고,
confirm 은 **호출측(페이지)** 이 띄운다 — 종목 수를 세려면 필터 전 원본 `entries` 가
필요한데 그건 페이지가 갖고 있다(검색 중 `visibleGroups` 로 세면 실제 삭제량보다 적게 알린다).

## Consequences

- **메뉴 셸이 하나로 합쳐진다.** `HeatmapContextMenu`(clamp + dismiss + 항목 리스트)를
  행 메뉴와 그룹 메뉴가 공유한다 — 셋째 사본을 만드는 대신. 관심종목 `WatchlistRowMenu`
  와 같은 문법(아이콘 1열 + 라벨)이고, 목록형 섹션은 구조적으로 담을 수 없다.
- **`PencilIcon` 이 `ui/` 로 올라간다.** 히트맵 드로어·저장뷰·관심종목 드로어가 각자 같은
  path 를 복제해 갖고 있었다. 이번엔 넷째 사본을 만들지 않고 프리미티브를 세운다(기존
  사본 정리는 별건).
- **그룹 헤더의 우클릭이 소비된다.** 이전엔 브라우저 기본 메뉴가 떴다. 행 우클릭과 같은
  관용구라 학습 비용은 없다.
- 이름 편집 중에는 헤더 우클릭 메뉴를 막는다(입력 위에 메뉴가 겹치는 상태 방지).
