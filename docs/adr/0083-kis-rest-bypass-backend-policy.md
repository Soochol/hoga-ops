# 0083 - KIS REST Bypass is a backend policy over data requests

`KIS API 우회` is recorded as a persisted backend **KIS REST Bypass** setting, not a browser-local flag, because backend-owned REST producers such as `Rest30sRecorder`, `LiveRestPoller`, quotes, program-trade, screener, investor, and candle backfill can call KIS even when the frontend stops selected hooks. The setting blocks new KIS REST data requests at **KIS REST Access** and stops supervisor loops, while preserving **KIS WebSocket** live capture, **Storage Policy** intent, **Source Preference** fallback, and already-written `kis_api` artifacts. We accept this narrower REST-data scope over an all-KIS kill switch so a maintenance workaround does not silently disable WS capture or erase the user's saved live-storage policy; a separate all-KIS shutdown can be designed later if needed.
