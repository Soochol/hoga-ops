# 화이트보드

상단 **캡처 → 화이트보드**에서 연다. 좌측 목록으로 보드를 선택하고 헤더의
**새 보드** 또는 목록의 ＋로 만든다. 제목을 눌러 이름을 바꾸면 자동 저장된다.

## 편집

- 헤더 **메모**는 배경과 텍스트가 연결된 메모를 만든다. 두 번 눌러 내용을 편집한다.
- 캔버스 상단 도구에서 선택·사각형·타원·선·화살표·펜·텍스트·지우개를 고른다.
- 객체를 선택하면 속성 패널에서 색·두께·글꼴·순서 등을 변경할 수 있다.
- Shift와 함께 객체를 선택하거나 빈 영역을 드래그해 여러 개를 선택한다.
- Ctrl+D 복제, Ctrl+G 그룹, Ctrl+Shift+L 잠금, Ctrl+Z 실행 취소,
  Ctrl+Shift+Z 다시 실행을 사용한다. 텍스트 입력 중에는 글 편집을 따른다.
- 스페이스바를 누르고 드래그해 캔버스를 이동한다. 하단에서 확대/축소하고
  캔버스 메뉴의 **전체 보기**로 객체를 한 화면에 맞춘다.
- 좌측 목록은 헤더의 목록 버튼으로 접을 수 있다. 우측 패널은 기존 앱과 공유한다.

## 이미지와 차트

**이미지 추가**, 파일 드롭, Ctrl+V를 지원한다. PNG/JPEG/WebP, 한 장당 16MB 및
24메가픽셀까지 허용한다. 원본 픽셀은 보존하고 보드 위의 표시 크기만 조절한다.
여러 장을 선택했을 때 이미지 처리 취소는 아직 추가하지 않은 파일부터 멈춘다.
이미 추가한 항목은 실행 취소로 되돌린다. 파일별 실패는 별도로 안내한다.

라이브 차트의 **차트를 보드에 추가**에서 목적 보드를 고르면 현재 보이는 차트와
보조지표를 PNG로 추가한다. 종목·봉 주기·캡처 시각·종목 복귀 링크를 함께 담는다.
보드 이미지는 당시 모습으로 유지되며 시세에 따라 자동 갱신하지 않는다.
종목 복귀 링크는 같은 기간·지표 상태의 복원을 보장하지 않는다.

## 저장과 복구

보드는 접속한 서버의 데이터 폴더 `whiteboards/`에 저장된다. 같은 서버를 사용하는
브라우저와 Electron에서 함께 열 수 있다. 서버가 다르면 보드도 별개다.

편집 후 약 750ms 뒤 자동 저장하며 연속 편집 중에도 최대 5초 간격으로 저장을
시도한다. **저장됨**은 서버 응답으로 확인한 상태다. 변경·저장 중·실패·다른 창과의
충돌을 구분한다. 이미지 업로드가 완료되어야 문서를 확정 저장한다.

저장 전 편집은 브라우저 IndexedDB에 초안으로 보관한다. 새로고침·앱 재열기에서
복구 가능한 초안을 찾으면 안내한다. 네트워크가 돌아오면 저장을 다시 시도한다.
저장소 용량 부족 등으로 로컬 초안을 쓰지 못하면 별도로 알린다. 서버나 로컬 저장에
아직 도달하지 않은 마지막 입력은 프로세스 강제 종료 시 유실될 수 있다.

다른 창이 먼저 저장하면 현재 내용을 자동 덮어쓰지 않는다. **내 편집을 새 보드로 저장**
또는 **초안 보관 후 최신본 열기**로 해결한다. 후자는 내 편집을 서버의 별도 복구 보드에
먼저 저장하고 성공을 확인한 뒤 원래 보드의 최신본을 연다. 보관에 실패하면 현재
편집을 유지한다. 편집 파일 내보내기로 별도 파일 백업을 만들 수도 있다.

보드 삭제는 휴지통 이동이다. 휴지통에서 다시 복원할 수 있다. 이미지 파일은 복제본과
삭제 복원을 위해 유지한다. 현재 버전에는 자동 영구 삭제/이미지 청소가 없다.

## 내보내기와 가져오기

**내보내기**에서 전체 또는 선택 객체의 PNG를 저장한다. 배경 포함 여부를 고를 수 있으며
최대 변 길이는 4096px이다. **편집 파일로 저장**은 이미지 데이터가 포함된
`.whiteboard.json` 파일을 만든다. 보드 목록 하단 **보드 가져오기**로 새 보드로 복원한다.
기존 보드를 덮어쓰지 않는다. 편집 파일은 최대 128MB/이미지 100장이다.

Electron 다운로드는 기존 네이티브 저장 대화상자를 사용한다. 다운로드 취소·OS 쓰기 실패는
대화상자의 결과를 확인해야 한다. 웹 화면의 “파일을 만들었습니다”는 파일 생성 완료를 뜻하며
OS의 저장 완료를 별도로 보장하지 않는다.

외부 페이지 임베드·온라인 소재 검색·공동 편집·영상/PDF 편집은 지원하지 않는다.
편집기 폰트는 앱 서버에서 제공하므로 로컬 서버에 연결되어 있으면 외부 CDN 없이 편집한다.
