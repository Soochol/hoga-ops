# 창별 설정

창의 표시·동작 설정을 추가할 때 적용한다. 차트 표시 설정은 첫 소비자다.
지표의 봉별 프로필은 ADR-0152, 프리셋 전달은 ADR-0159의 기존 경로를 유지한다.

## 소유권과 저장

- 정본은 `state/windowSettings.ts`의 `byWindow[windowId]`다. `hoga.window.settings.v1`
  localStorage에 즉시 저장한다. 값은 창별이며 종목·봉·링크 그룹에 따라 갈리지 않는다.
- 설정은 종류별 section으로 나눈다. `chart` section은 `CHART_DISPLAY_TOGGLES`에
  등록된 boolean과 거래량 오버레이·고저 가격선 스타일의 완전한 값이다.
  새 종류는 `WINDOW_SETTINGS_REGISTRY`에 창 kind와 순수 정규화 함수를 등록한다.
  `WindowSettings` 타입은 레지스트리에서 파생된다. UI에 별도 저장 사본을 만들지 않는다.
- `candleLogScale`·`candleInvertScale`은 기본값이 false이며 분·일·주·월에서 함께 쓴다.
  캔들 시리즈의 현재 가격축에만 적용한다. 차트 전체 `rightPriceScale`에 적용하면
  거래량·하단 지표까지 바뀐다. 고저 라벨은 화면상 위·아래와 최고·최저의 의미를 구분한다.
- `candleInvertColors`는 기본값이 true인 반전 전용 하위 옵션이다. 반전과 이 옵션이
  모두 켜진 창의 캔들·거래량 색상만 교환한다. 원본 OHLC·수량과 동시호가 회색은
  보존한다. 과거 봉 투영 캐시는 이 값이 바뀔 때 함께 무효화해야 한다.
- `depthHeatmapAboveCandles`는 기본값이 false이며 켜면 잔량 히트맵을 캔들 앞에
  그린다. 히트맵·캔들 사이에는 `candleAlwaysOnTop`보다 이 값이 우선한다.
  크로스헤어 아래의 normal primitive 레이어를 사용하며 불투명도는 유지한다.
- `volumeOverlayEnabled`는 기본 false다. `volumeOverlayTransparency`는 정수 0~100(기본 65),
  `volumeOverlayHeight`는 정수 10~40(기본 25)이며 색상 두 값은 빈 문자열(테마 추종) 또는
  6자리 hex다. 잘못된 값은 기본값으로 정규화한다. 스타일은 창 설정 store에만 쓴다.
  겹치기는 기본 거래량의 표시·숨김을 따르며, 별도 volume pane을 렌더에서 제거하되
  공용 pane 배치를 수정하지 않는다. 그림의 volume paneId는 보존하고 표시만 숨긴다.
- `highLowLabelsEnabled`와 네 가격선 토글·색상·두께는 창 소유다. 토글은
  `useChartPrefActions`, 스타일은 `useChartLineStyleActions`로 같은 chart section에 쓴다.
  `CHART_DISPLAY_LINE_STYLES`가 스타일 기본값·검증의 원본이며 색은 빈 문자열(테마 추종)
  또는 6자리 hex, 두께는 1~4다. 구 창 설정을 읽을 때 누락된 고저 필드만 전역
  `hoga.chart.prefs.v1`에서 이관한다. 명시적인 false·빈 색·두께는 덮지 않는다.
  구 설정 백업은 그 파일에 함께 담긴 전역값으로 누락 필드를 채운다.
- 기존 호가 주문·체결 창의 저장 구조는 이번에 이전하지 않았다. 이후 이전 시 기존
  저장값을 읽는 이관 절차와 하위호환 테스트를 함께 추가한다.
- 탭별 sessionStorage 워크스페이스에는 설정 내용을 넣지 않는다. 같은 창 id는
  다른 브라우저 탭에서도 같은 설정을 읽고, `crossTabSync`가 변경을 수신한다.
  이는 ADR-0152의 창별 지표와 같은 공유 범위다.

## 생성과 해제

- `windowSettingsLifecycle.ts`에서 종류별 기본값·이관·캡처·복원을 조립한다.
  차트의 옛 전역값은 최초 seed에만 사용한다. seed는 이미 있는 section을 덮지 않는다.
- 새 차트는 포커스 차트의 설정을 깊은 복사한다. 이후 편집은 독립적이다.
  초기 워크스페이스 로드·프리셋 적용·차트 마운트에서도 seed를 보장한다.
- 새 창 종류가 원본 창의 설정을 상속해야 한다면 `workspace.addWindow`에서 같은 종류의
  원본 id를 seed에 전달한다. 다른 종류의 section을 복사하지 않는다.
- 닫힌 창과 워크스페이스 교체로 사라진 창만 정리한다. 페이지 언마운트나 로드 때
  전체 창 목록과 비교해 지우지 않는다. 다른 탭의 살아 있는 창을 지울 수 있다.
  같은 id를 공유하는 탭에서 한쪽이 닫을 때 생기는 회수 한계는 ADR-0152와 같다.

## 읽기와 편집

- 차트 내부는 `useActivePrefs`/`useScopedChartPrefs`가 창 설정을 덮어 읽는다.
  MA·볼린저·슈퍼트렌드의 자동 축척도 이 경로를 사용한다.
- 차트 밖에 있는 헤더 팝오버는 `WindowSettingsScope`로 대상 창 id를 명시한다.
  쓰기는 `useChartPrefActions` → 창 설정 store의 검증된 `patch`를 사용한다.
- 되돌리기의 snapshot·구독·복원은 같은 창의 해당 section에만 연결한다.
  다른 편집기가 동일한 필드를 바꾸면 기존 undo를 무효화한다.
- 연결된 호가창의 동시호가 마스크는 `GroupChartLink.windowId`가 지정한 차트의 값을
  구독한다. 임의의 마지막 차트나 전역 활성 창을 기준으로 읽지 않는다.

## 헤더 UI

- 공통 톱니바퀴·제목·적용 범위·닫기·앵커 배치는 `WindowSettingsPopover`를 사용한다.
  본문은 `WindowSettingsEditor`·`WindowSettingsGroup`의 컴팩트 속성표를 사용한다.
  차트·주문·체결·주요 지수에 동일한 왼쪽 그룹명·최소 24px 행·36px 헤더·28px 고정
  푸터를 적용하고 본문만 스크롤한다. `CompactSettingsContext`는 이 편집기 안에서만
  26×15px 토글을 선택한다. 앱 설정·보조지표 편집기의 기존 행 크기는 유지한다.
  토글 이름은 네이티브 label로 버튼과 연결하고 별도 액션·입력은 중복 토글하지 않는다.
  차트의 종속 옵션은 부모 행에서 펼치며 가격선 스타일은 표시·색상·자동색·두께를
  함께 조절한다. 자동색은 빈 문자열을 저장해 테마를 따르며 별도 상태 사본을 두지 않는다.
- 캔들 차트 제목 헤더의 `ChartWindowSettings`는 같은 창의 로그·반전 값을 직접 구독한다.
  활성 배지는 차트 설정을 열며 별도 상태 사본을 만들지 않는다. 240px 이하에서는
  배지를 접고 설정 아이콘의 강조와 툴팁으로 상태를 유지한다.
- 주문 설정처럼 본문의 처리 상태와 연결된 액션은 `WindowHeaderAction`으로 프레임의
  슬롯에 포털 렌더한다. 프레임별 Context이므로 다른 창의 슬롯을 쓰지 않으며 상태나
  콜백을 전역 store에 복제하지 않는다. 프레임 없는 단독 미리보기에서는 제자리 렌더한다.
- 외부 상태로 열림을 관리할 때는 `open`과 `onOpenChange`를 함께 넘긴다. 주문 처리·
  드래그 중 `disabled`와 본문의 주문 차단을 유지하고, 종목 변경/언마운트 시 함께 닫는다.

## 워크스페이스 프리셋과 백업

- 프리셋 창 원소에 `windowSettings`를 넣는다. 캡처는 정본의 깊은 사본을 만든다.
  명시적인 false와 기본값도 저장해, 다른 환경에서 복원해도 값이 바뀌지 않게 한다.
- 적용은 먼저 워크스페이스 창을 검증·교체하고, 실제로 수용된 창에만 설정을 복원한다.
  설정은 현재 창 kind에 허용된 section만 복원한다. 저장값이 있으면 현재 값을 덮는다.
- 옛 프리셋에서 section이 없으면 살아남은 창의 값을 유지한다. 새 창은 seed로 채운다.
  알 수 없는 section과 필드는 버리고, 잘못된 값은 정규화 함수의 기본값을 사용한다.
- payload의 `windows`는 기존 자유 구조를 사용하므로 백엔드 모델·버전은 바꾸지 않는다.
  설정 파일 내보내기·가져오기도 새 저장 키를 검증하고 포함한다.

## 검증

같은 종목·그룹의 두 창에서 독립 변경, 종목·봉 변경 후 유지, 새 창의 복사 후 독립,
새로고침·새 탭 복원, 프리셋 A→B→A 및 같은 프리셋 재적용, 옛 프리셋, 잘못된 payload,
창 닫기, 설정 백업, 창별 undo를 확인한다. 표시 토글은 store 값뿐 아니라 실제 차트
옵션·시리즈·툴팁이 해당 창에서만 바뀌는 것도 검증한다.
