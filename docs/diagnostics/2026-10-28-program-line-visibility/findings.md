# 프로그램 창 선 표시 조사 — 2026-10-28

## 사용자 증상

종목 변경 또는 새로고침 후 종가선과 프로그램 순매수 선이 잠깐 안 보이다가 나타남.
최종 확인된 조건은 실시간 무조작 상태나 마우스 이동이 아니다.

## 확인된 원인과 재현

프로그램 카드에서 데이터 도착 순서에 따라 선을 숨기는 표시 문제를 재현했다.

1. 종목 교체 시 `key={code}`로 카드를 새로 만들고, 이전 종목의 그룹 링크는 코드 일치 가드로 제외한다. 이 분리는 올바르지만 새 종목의 로딩 상태가 카드에 전달되지 않는다.
2. `useLiveSidecars`의 프로그램 이력과 캔들 조회는 별도 경로다. `ProgramWindow`는 도착한 캔들을 종가선 입력으로 전달한다.
3. `ProgramTradeSummaryCard.tsx:103`은 프로그램의 latest와 cursor point가 모두 없으면 차트 전체 대신 **프로그램 순매수 데이터 없음**을 표시한다. 종가 데이터가 있어도 이 분기로 숨겨진다.
4. 같은 파일의 geometry는 유효한 순매수 점이 2개 미만이면 null이다. 순매수 1점과 종가 2점이 있어도 두 선 모두 사라진다.
5. 프로그램 이력까지 준비되면 별도 조작 없이 두 선이 다시 나온다. 반대 순서로 도착한 카드 입력은 순매수선이 먼저, 종가선이 나중에 나온다. 분봉 파이프라인은 캔들이 없는 날짜의 저장 순매수 점도 `filterProgramTradeForCandles`로 제거하므로 실제 경로에서는 프로그램 이력이 먼저 와도 캔들을 추가로 기다릴 수 있다.

따라서 두 선을 함께 숨기는 렌더 조건과 로딩/실제 데이터 없음의 구분 누락은 확인됐다. 실제 사용 화면의 HTTP 응답 시간을 측정하지 않았으므로 특정 API의 지연 시간, 서버 장애, 저장 데이터 손실을 확인한 것은 아니다.

## 검증

- 기준 커밋: `e8fd26d8f1fce93c1d4a84602ed8c57f385a4695` (PR #2307 머지 후).
- 실제 `DataWindow` 및 `ProgramTradeSummaryCard`를 RTL/jsdom에서 렌더. API 훅/그룹 링크 입력을 통제하는 진단 테스트 6개 통과.
- 핵심 시나리오: 종목 변경 → 새 종목 빈 응답 상태 → 캔들 먼저 준비 → 프로그램 준비 → 두 선 복원. 반대 입력 순서도 확인.
- 추가 진단 4개: 유효 점 수 감소, 일봉의 종가 1점, 관측 없는 날짜 커서, 과거일 로컬 호버 고착. 이들은 별도 문제이며 이번 사용자 증상의 직접 원인으로 단정하지 않는다.
- 실행: `cd frontend && npx vitest run src/live/workspace/DataWindow.test.tsx src/sidebar/ProgramTradeSummaryCard.test.tsx -t 'diagnostic:'`.
- 도구: Node 24.13.1, npm 11.8.0, Vitest 4.1.7. 운영 서버 변경/재시작 없음.
- 재현 소스는 `card-probes.test.tsx.txt`를 `ProgramTradeSummaryCard.test.tsx` 끝에, `window-probes.test.tsx.txt`를 `DataWindow.test.tsx` 끝에 붙여 실행한다. 진단 후 기존 테스트 파일은 바이트 단위로 복원했다. 진단은 현재 결함 동작을 확인하는 단언이므로 영구 회귀 테스트로 쓰려면 수정된 기대 동작으로 바꿔야 한다.

## 개선 방향

- 종가선과 순매수선의 표시 가능 여부를 독립적으로 계산해 준비된 선을 먼저 표시한다.
- 프로그램 전용 로딩·오류·정상 빈 응답 상태를 그룹 링크/카드에 전달한다. 형제 지표 전체의 로딩 상태로 대신하면 불필요한 대기가 다시 생길 수 있다.
- 최초 조회 중에는 데이터 없음 대신 불러오는 중을 표시한다.
- 같은 종목·날짜·거래소의 재조회에서는 이미 표시한 유효 데이터를 유지한다. 종목 변경 시 이전 종목 선을 새 종목에 남기지 않는다.
- 두 API의 응답 순서, 0/1/2점, 종목 전환, 새로고침, 조회 실패/재시도를 회귀 검증한다.

위 내용은 최초 조사 시점의 기록이며, 당시 제품 동작은 변경하지 않았다.


## 후속 구현 및 검증

사용자 승인에 따라 준비된 종가선·프로그램 순매수선을 독립적으로 표시하도록 구현했다.
프로그램 창에는 캔들 날짜 필터 이전의 프로그램 이력과 조회 상태를 전달하며, 기존 차트 패널의 날짜 필터는 유지한다.
각 계열의 불러오는 중·데이터 없음·조회 실패를 구분하고, 점이 하나뿐이면 추가 관측 대기를 표시한다.
실시간 초기 조회가 진행 중이면 빈 이력 응답만으로 데이터 없음으로 판정하지 않는다.
같은 종목의 재조회 실패에도 받은 점은 표시하며, 종목 교체 시 이전 종목 데이터가 섞이지 않게 한다.

최종 전체 타입 검사, 관련 단위 테스트 357개, 프로덕션 빌드 및 응답 순서를 제어한 브라우저 회귀 테스트를 통과했다.
종목 변경·새로고침·조회 실패·빈 응답과 기존 시간축/호버 동작을 검증했다.
명령·입력 지문·환경·결과 재사용 근거는 `implementation-verification.json`에 기록했다.
