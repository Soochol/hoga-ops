   공급자 마지막 가격(`provider_last_price`)으로 기록한다. 15:30 정규장 종가로 간주하지 않는다.

## 증거 파일과 재검증

`comparison.json.gz`, `full-universe-legacy-comparison.json.gz`, `conflict-review.json.gz`는
원 JSON을 손실 없이 gzip 압축한 것이다. 두 표본의 공급자 원 응답은 운영의 불변 관측 객체에
있고, 이 디렉터리에는 각 객체 id·표본 지문·수신 시각을 기록했다. 장기 재실행의 운영 객체는
진단 보고서를 지웠다는 이유로 지우지 않는다.

```sh
PYTHONPATH=. .venv/bin/python docs/diagnostics/2026-10-24-screener-confirmed-pilot/verify.py
```

이 검사는 기록 파일 해시, 승인 근거 483개, 25개 확인 관측 메타데이터, 충돌 수,
전후 기존 결과와 정확 재실행 성공 기록을 검사한다. 새로 공급자를 조회하거나 전체 스캔을
다시 실행하는 명령은 아니다. 원 자료와 로그의 해시는 `artifact-inputs.json`에 있다.
