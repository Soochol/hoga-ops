## 초기 격리 실험

[진단 메모](diagnosis.json)는 관심종목 선택 뒤 날짜 위치가 어긋난 관측과 원인 가설을
담는다. [초기 스크립트](prepend.spec.ts.txt)는 합성 봉을 실제 차트 라이브러리에
넣어 native와 WindowedChart를 비교한다. [native 결과](native.json)와
[WindowedChart 결과](windowed.json), [native 화면](native.png)과
[WindowedChart 화면](windowed.png)이 그 비교 자료다.

진단 메모의 `cause`와 테스트 통과 문구는 당시 격리 실험의 해석이다. 이 비교만으로
전체 React 앱에서 사용자의 관심종목 선택·드래그 순서를 재현했다고 볼 수 없다.

## 후속 격리 비교와 별도 구현 기록

[후속 스크립트](review.spec.ts.txt)와 [검토 요약](review-summary.json)은 prepend,
시각 합집합 변경, append, 최신 복귀를 비교한다. `review-native-*.json`과
`review-windowed-*.json` 8개는 각 시나리오의 측정값이다. native 최신 복귀가
2,500ms 안에 목표에 도달하지 않아 최신 복귀의 대조 결론은 미확정이다. 요약의
80개 테스트 통과는 당시 기록이며 이번 보관 작업의 실행 결과가 아니다.

같은 디렉터리에 이미 있던 [구현 검증 기록](implementation-validation.md)은 이후
수정과 앱 통합 검증을 다룬다. 초기 격리 비교와 검증 시점·대상이 다르다. 이번 추가는
그 제품 수정이나 새로운 통합 검증을 포함하지 않는다.
