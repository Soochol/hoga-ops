## 재현 검증 중 병행 코드 변경

운영 HTTP 재실행 도중 기본 체크아웃의 `hoga/live/api.py`와
`hoga/live/us_index_daily_transfer.py`가 병행 변경됐다. 전체 앱 소스를 묶은 버전 지문이
달라져 세 번째 반영 전 실행의 온라인 replay가 **422 코드/환경 변경 가드로 중단**됐다.
가드를 완화하거나 그 변경을 덮어쓰지 않았다. 온라인 replay 9개가 전부 성공했다고 주장하지 않는다.

운영에서 실제 보존한 **9개 실행 전부를 기록 당시와 동일한 코드/환경의 워크트리 프로세스에서
고정 운영 입력을 읽기 전용으로 사용해 정확 재현**했다. 행·커버리지·계산 메타데이터와 근거
시각을 포함해 일치했다. 실행할 때 달라지는 최상위 `scanned_at_ms`만 응답 비교에서 제외했다.
현재 서버의 HTTP GET으로도 **9/9 보존 응답이 동일**한 것을 확인했다.

병행 변경 후 서버에도 원거래량 진단을 다시 요청해 **4종목 평가 가능 상태와 의미상 전체
응답이 동일**한 것을 확인했다. 그 확인 실행은 별도로 보존했다. 해당 시점의 서버 지문은
`c2f26fb1a9fab4281be7a6c00ae432781fac7aca29f96b3fd7a6d482ae63eadd`였다.
서버 버전 변경은 앞으로의 정확 replay와 계획 재개에도 같은 가드로 적용된다.
