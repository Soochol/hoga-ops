# 자동 갱신 첫 운영 실행의 후속 수정·재검증

2026-10-24 사용자 요청. 기존 일봉·수정주가·계수·저장 조건을 보존하며, 첫 자동 실행의
500종목 실패를 검증 오류와 일봉 제공 범위로 분리한다.

## 원인과 변경

- 새 원본 검증이 종목코드를 숫자 6자리로 제한했다. 기존 복구 계약과 동일한
  ASCII 대문자·숫자 6자리로 수정하고 앞자리 0·문자·원래 식별자를 그대로 보존한다.
  소문자·전각 문자·구분자·개행·길이가 다른 값은 계속 거절한다.
- 나머지 86종목 중 50종목은 기존 출처 자료에 상장폐지일이 있고, 3종목은
  2026-10-21 신규 상장이므로 10월 19·20일 봉을 요구할 이유가 없다.
- 나머지 33종목의 요청 구간 응답은 비어 있다. 최신 마스터에 없는 31종목과,
  마스터에는 남은 삼성 ETN 2종목을 구분한다. 마스터 부재만으로 폐지를 확정하지 않는다.
- 처리 예외(`failed_codes`), 정상 수집 대상 외 날짜(`excluded_dates`),
  정상 응답이지만 자료가 없는 종목(`unavailable_codes`)을 별도로 표시한다.
  미제공 응답도 기존 30분 간격·하루 2회 예산으로 재시도하며 빈 체크포인트를 재사용하지 않는다.
- 정상 제외는 출처가 있는 상장일·폐지일·정지 구간만 적용한다. 첫 저장 봉이나
  빈 응답으로 상장일·거래정지를 추정하지 않는다. 출처·빠진 날짜·응답 해시는 새 원장에 기록한다.
- 기존 `history_evidence.json`은 읽기만 하며 원본 파일·조건을 수정하지 않는다.
  공급자 응답이 없는 날짜에 0거래량 봉을 만들거나 값을 자동 정정하지 않는다.
