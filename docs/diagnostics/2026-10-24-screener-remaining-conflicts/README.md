현재 규칙은 사건 전 **가격이 같아야 하는 반올림** 또는 사건 후 **잘못된 역산**만

위 독립 사건·실제 적용일·기존 계수 1·전체 OHLCV 등식·확인 관측·baseline/후보 버전

## 보존·비교 검증
