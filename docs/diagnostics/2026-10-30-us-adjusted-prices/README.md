# 미국주식 USD 수정주가 — 2026-10-30

사용자 요청: 미국주식을 수정주가로 표시하고, 과거 구간을 이어 붙여도 가격 기준을 일치시킨다.
2026-10-18의 원주가 임시 정책을 대체한다. ADR-0136의 키움 공급자와 메모리 보관 결정은 유지한다.

## 구현

- 일봉(`usa06012`)·분봉(`usa06011`)은 `upd_stkpc_tp=1`, `exrt_appl_tp=0`이다.
  W/M은 검증된 같은 기준 일봉을 집계한다. 공급자 응답 거래량을 임의 변환하지 않는다.
- 뉴욕 당일을 `adjusted_as_of`로 고정한다. 과거 화면의 종료일은 반환 범위 필터이며
  공급자의 `strt_dt`를 바꾸지 않는다. 모든 과거 페이지는 그 기준일의 연속 커서로 읽는다.
- 일봉은 기준일·거래소·종목별 LRU 128개, 키당 최대 512개 커서 체크포인트를 유지한다.
  8페이지/15초 제한에 걸리면 완료하지 않은 구간을 명시하고 다음 요청이 이어 읽는다.
  수정주가의 자동 부분 조회는 최대 32회이며 기존 지수의 8회 제한은 유지한다.
- 일봉 OHLCV·완료 구간·진행 중 요청 키와 분봉 최신/과거 캐시는 수정 기준일을 포함한다.
  날짜가 바뀌면 과거 전체가 새 기준 캐시로 조회되며 이전 기준 자료로 폴백하지 않는다.
  예전 분봉 커서는 거절하고 최신 폴링이 새로운 기준과 커서를 제공한다.
- 프런트 쿼리는 USD 수정주가를 식별한다. 분봉 보관·과거 쿼리 키·응답 병합에서
  가격 기준·통화·기준일을 비교한다. 이전 날짜의 진행 중 요청도 새 기준 결과에 섞이지 않는다.
  당일 실시간 관측은 같은 기준일의 REST 차트에만 덮는다.
- 과거 일봉 조회는 당일 임시 봉을 게시하지 않는다. 실제 GOOGL 장전 응답에서 당일 종가가
  저가보다 낮은 불완전 OHLC를 확인했다. 해당 당일 행을 완료 이력의 OHLC 검증에서 제외하고
  날짜·페이지 진행은 검증한다. 당일 봉 자체를 요청하면 기존처럼 잘못된 OHLC를 거절한다.

## 실측

[공개 시세 응답 기록](live-probe.json). 기존 미만료 토큰 캐시를 읽기만 하고,
발급·갱신·토큰 파일 쓰기·주문·WS 연결 없이 `/api/us/chart`만 호출했다.
별도 probe의 직렬 HTTP 호출 간격은 1.1초이며 요청은 총 43회다.
수정 기준일은 모든 아래 일봉·최근 분봉에서 `20261030`이다.
기존 서버 `/health`는 검증 전후 모두 `ok`, version `0.16.6.0`, commit `8c4a58bfa`였다.

| 종목 | 분할 전 거래일 종가(수정) | 분할 후 거래일 종가(수정) | 서로 다른 범위의 겹친 거래일 |
|---|---|---|---|
| GOOGL | 2022-07-15: 111.7775 | 2022-07-18: 109.03 | 10일 OHLCV 완전 일치 |
| NVDA | 2024-06-07: 120.888 | 2024-06-10: 121.79 | 8일 OHLCV 완전 일치 |
| AAPL | 2020-08-28: 124.8075 | 2020-08-31: 129.04 | 6일 OHLCV 완전 일치 |

GOOGL의 2022-07-15 원주가 실응답은 2235.55이고 수정주가는 정확히 1/20이다.
AAPL의 깊은 과거 조회는 제한된 여러 요청에서 같은 기준일의 체크포인트를 이어 사용했다.
GOOGL 60분봉 최신 2페이지/200봉에서도 수정주가 요청과 동일 기준일의 연속조회를 확인했다.
2022-07-20 분봉 직접 조회는 공급자가 빈 결과를 반환했다. 오래된 분봉 전체 제공이나
실제 분할 전 분봉의 실측을 완료했다고 주장하지 않는다. 분봉의 분할 기준일 전환·캐시 및
진행 중 페이지 격리는 결정적인 회귀 테스트로 검증했다.

## 검증

세부 실행 환경·대상·결과·입력 SHA-256은 `verification.json`에 기록한다.
테스트는 이 워크트리의 Python 3.14.7·별도 의존성과 무자격 환경으로 실행했다.
브라우저 테스트는 단일 워커·격리 포트 20359/21359 및 데이터 경로를 사용했다.
실행 중 사용자 서버와 데스크톱 앱 배포는 변경하지 않았다.
