## 독립 공시와 새 정정 규칙

535개 모두 기존 legacy 계수는 정확히 1이고 기존 원본 전체 OHLCV가 현재 공급자 수정
OHLCV와 같았다. 공시에서 따로 확인한 수량 비율 `r = 신주 / 구주`에 대해 모든 날짜가
`기존 OHLC = 확인 원OHLC / r`, `기존 거래량 = round(확인 원거래량 × r)`를 만족했다.
가격비율로 수량 사건을 추정하지 않았으며 유리수 등식에 추가 허용오차를 두지 않았다.
정수 반올림으로 같은 값이 되는 수량은 등식이 허용하는 범위이며 별도 근사 오차가 아니다.

- 대신정보통신: [병합 결정](https://kind.krx.co.kr/common/disclsviewer.do?method=search&acptno=20260529000449)의
  구주 38,428,915주 → 신주 7,685,783주, 액면 500원 → 2,500원으로 **r=1/5**를 확인했다.
  [거래소 기준가격 안내](https://kind.krx.co.kr/common/disclsviewer.do?method=search&acptno=20260818000517)의
  실제 적용일 **2026-08-19**를 사용했다. 법적 효력일 7월 29일과 구별했다.
- 레드캡투어: [무상증자 결정](https://kind.krx.co.kr/common/disclsviewer.do?method=search&acptno=20241108000104)의
  구주 1주당 신주 1주, 총 8,360,411주 → 16,720,822주로 **r=2**를 확인했다.
  [거래소 권리락 공시](https://kind.krx.co.kr/common/disclsviewer.do?method=search&acptno=20241121000397)의
  실제 적용일 **2024-11-22**를 사용했다. 배정기준일 11월 25일·상장 예정일 12월 13일과 구별했다.

`legacy_pre_event_adjusted_basis`는 기존 역산·분봉 누적 규칙과 분리했다. 결정 공시와 실제
거래 단위 적용 공시의 원문·SHA256을 각각 보존하며 종목·적용일 연결을 검사한다. 사건은
관측 수정 기준일 이내여야 하고 정정 날짜는 사건 이전이어야 한다. 위 계수·전체 OHLCV·가격·
수량 검사를 모두 통과한 확인 관측만 선택한다. 공시 사실은 사람의 검토로 확인한 입력이며,
HTML을 자동 해석해 사실 자체를 인증하는 기능은 아니다.

현금 이벤트·단위비율 1·근거 변조·빈 결정 공시·경계 공시 누락/다른 종목/다른 날짜·기준일 이후
사건·사건 당일 이후 날짜·계수 불일치·가격/수량 등식 불일치·수정 OHLCV 불일치는 거절한다.
묶음 중 한 날짜라도 거절되면 검토 계획 사전 검사에서 전체 공개를 중단한다. 독립 사건 하나를
확인한 사실로 전체 수량 이력을 인증하거나 추가 사건의 복구를 자동 승인하지 않는다.

공시 본문은 이미 수집한 [이전 원문 보관 자료](../2026-10-24-screener-remaining-conflicts/README.md)를
재사용했다. 원래 CRLF를 포함한 UTF-8 바이트를 유지해 네 본문의 체크섬을 다시 대조했다.
