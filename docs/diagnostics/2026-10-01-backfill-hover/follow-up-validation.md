# 후속 캔들 좌표·커서 인덱스 최적화 검증

PR #1917 머지 후 남은 전체 이력 계산 비용을 조사했다. CPU 샘플링에서 `drawnCandleIndex`와 MA의 별도 좌표 준비가 큰 비중을 차지했다. 동일 화면 반영에서 전체 타임스탬프 해시맵 두 개와 별도 MA 좌표 객체를 만들던 일을 줄였다.

정렬·유일 키는 보관한 숫자 시각 배열에 이진 탐색을 적용한다. 툴팁·범례의 `get`, `has`, 크기와 읽기용 반복 인터페이스를 유지한다. 비정렬·중복 키는 기존 Map의 마지막 값 우선·삽입 순서 의미를 유지한다. MA는 그려진 캔들과 가상 시각 배열을 함께 사용하며 전체 원본의 SMA 연산 순서는 그대로다. 가격 정정은 캔들 객체만 갱신하고 동일 시각 격자를 재사용한다. 키 조회가 과거 가격 객체 전체를 붙잡지 않도록 숫자 키 배열만 보관한다.

## 최종 코드 반복 측정

제품 빌드, 시스템 Chrome, CPU 감속 없음, 기본 4 MA, 창 하나, 120일 1분봉에 10일 추가. 별도 포트 5198, API 픽스처 응답 지연 600ms. 일반 배율의 전체 35,814 슬롯을 유지하고 실제 차트 입력은 약 555 슬롯이다. 단위·E2E 검사와 성능 측정을 병행하지 않았다.

| 조건 | 반복 | 최대 프레임 간격 | 응답 주변 긴 작업 | 실제 시리즈 교체 합계 |
| --- | --- | --- | --- | --- |
| #1917 코드, 툴팁 OFF | 5 | 66.7–100ms | 67–97ms | 2.0–3.2ms |
| 최종 후속 코드, 툴팁 OFF | 5 | 50.0–66.6ms | 없음 또는 55–59ms | 2.4–4.9ms |
| 최종 후속 코드, 툴팁 ON | 5 | 49.9–83.4ms | 없음 또는 55–88ms | 2.0–5.1ms |
| 최종 후속 코드, 툴팁 ON·캐시 내 실제 팬 | 3 | 16.8ms | 없음 | 교체 없음 |

초기 최적화 단계의 툴팁 OFF 5회는 33.4–50ms였지만, 반복과 조건을 늘린 최종 결과는 위와 같다. 가장 좋은 실행만으로 50ms가 항상 달성된다고 표현하지 않는다. 툴팁 OFF 최대 프레임 간격의 중앙값은 머지된 코드 66.7ms에서 후속 코드 50ms로 줄었다. 최초 조사 코드의 동일 OFF 조건은 383.3–433.4ms였다.

캐시 팬은 가시 범위가 실제로 움직였는지 단언했고 3회 모두 추가 과거봉 요청 0회였다. 각 90회 포인터 이동에서 핸들러 시작부터 다음 rAF 콜백까지의 경과를 별도로 기록했다. 이는 이벤트 전달 전 대기와 paint를 포함하지 않으며 직접 입력 지연/INP라고 부르지 않는다. 원시 기록은 `final-default.json`, `final-tooltip.json`, `final-pan.json`이며 제품 파일 해시를 포함한다.

## 확장 조건과 한계

`lookup-matrix.json`의 36조건은 30/120/240일 이력에 약 10일 추가(최대 약250일), 1/3창, 1/5/30분봉, 보통 배율/전체 이력 줌아웃을 조합한 단일 실행이다. 세 창 조건에서는 첫 창만 확장하고 나머지는 커서 동기화에 참여한다. 동시 세 창 백필이나 실제 벤더 응답·공휴일 달력 검증을 뜻하지 않는다. 숫자 키만 보관하는 마지막 메모리 참조 정리 전의 같은 공유 격자 구현으로 측정했다.

| 분봉 | 보통 배율 최대 프레임 | 전체 이력 줌아웃 최대 프레임 |
| --- | --- | --- |
| 1분 | 66.7ms | 116.6ms |
| 5분 | 33.3ms | 66.6ms |
| 30분 | 33.4ms | 33.3ms |

약250일 1분봉 보통 배율은 66.6–66.7ms였고, 큰 줌아웃에서는 실제 가시 점이 늘어 전체 렌더러를 사용한다. 모든 확대율·구성에서 50ms 이하를 보장하지 않는다. 전체 원본 계산·SMA 결과를 유지하므로 긴 이력의 원본 계산 비용은 남는다. Worker와 별도의 가시 영역 계산 엔진을 추가하지 않았다. 이번 후속은 커서 인덱스와 공유 좌표의 중복 작업을 줄이고 그 한계를 확인한 변경이다.

## 정확도와 전체 검사

정렬 격자의 첫/중간/끝/없는 키, 읽기용 반복, 중복·비정렬 키의 값과 순서, 달력 격자의 중복 시각을 단위 테스트로 검사한다. 기존 가격 정정·prepend·삭제·축 전환과 모든 MA 계산의 값/순서 일치 검증을 유지한다. 툴팁·범례·MA 대상 단위 테스트 118개가 통과했다.

최종 전체 TypeScript, Vitest 600파일·7,698개, 제품 빌드와 전체 Playwright 148개(4.1분)가 모두 통과했다. 제품 빌드의 기존 큰 번들 경고는 유지한다. 반복자의 종료부를 `return undefined`로 명시해 프로젝트의 ReadonlyMap 반복자 타입과 맞췄으며 전체 검사는 이 수정까지 포함한다. 성능 기록에 있는 종료부의 암묵적 반환과 런타임 값은 같다.

최종 전체 E2E는 단일 워커·시스템 Chrome·빈 벤더 자격증명, 작업 트리 전용20124·21124, 새 데이터·dist를 사용했다. 사용자 서버5173·8000을 재시작하지 않았다. 검사 커밋과 제품 파일 해시는 `follow-up-checks.json`에 있다.
