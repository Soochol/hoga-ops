# 정제된 공통 아이콘 적용 검증

사용자가 승인한 라인 스타일을 창 헤더·차트 도구줄·우측 레일·그리기 도구와
공통 메뉴/검색/닫기/정렬 액션에 적용했다. 현재 입력 지문과 명령별 결과는
[verification.json](verification.json)에 기록했다.

- 브라우저 61개 선택 사례를 확인했다. 좁은 창, 글자 확대, 창 조작, 관심 그룹,
  패널 선택/정렬/저장/삭제, 지표 독립 상태, 그리기 색상/잠금/삭제/실행 취소를 포함한다.
- 하트 팝업의 저장 진행 중 포커스 유실 뒤 Escape도 트리거로 복귀하도록 보완했다.
- 전체 단위 검사는 9,515개 통과, 3개 실패다. 실패 3건은 변경 전 main
  `a40f128156c5fe13e34f600fa5e83c39034813fa`의 독립 소스 사본에서도 동일하게
  재현했다. 관련 원문은 [baseline-failures.txt](baseline-failures.txt)를 참조한다.
- 별도 재검사한 최종 팝오버·수집 메뉴 관련 단위 검사 36개는 모두 통과했다.
