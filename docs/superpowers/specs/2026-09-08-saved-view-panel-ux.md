# 저장뷰 우측 패널 조작 개선

## 범위와 도메인

관심종목·히트맵 패널의 드래그 목적지 안내, 정렬 취소, 선택 삭제 UX를 저장뷰에도 적용한다.
저장뷰의 그룹은 Code별 표시 묶음이다. 폴더 소속과 달리 다른 종목으로 저장뷰를 이동하거나 복사하지 않는다.
저장뷰 열기는 기존 `/live` 저장 구간 슬롯을 사용하며 ADR-0157의 `/study` 폐기 결정을 유지한다.
수동 순서는 기존과 같이 브라우저 localStorage에 저장한다. 서버 동기화는 이번 범위에 포함하지 않는다.

## 기대 동작

- 검색 중에는 일치하는 저장뷰의 그룹을 임시로 펼친다. 검색을 지우면 원래 접힘 상태를 복원한다.
  검색 중 접기 버튼을 비활성화하여 임시 펼침과 사용자의 설정이 섞이지 않도록 한다.
- 그룹 헤더 접기 버튼과 그룹 이동 핸들을 분리한다. 행도 이동 핸들로만 드래그하며 클릭·이름 수정·메뉴와 구분한다.
- 같은 Code 안에서 대상 행의 위/아래에 삽입한다. 종목·뷰 이름·기간·삽입 방향을 문구와 선으로 표시한다.
  다른 Code 위, 패널 밖, Escape는 순서를 변경하지 않는다.
- 기본 정렬에서만 재정렬한다. 검색 및 이름 정렬에서는 제한 이유를 표시하고 이름 정렬에서는 수동 정렬 전환 버튼을 제공한다.
- 완료 안내와 마지막 순서 변경 되돌리기를 제공한다. 저장 공간 오류는 기존 순서를 유지하며 안내한다.
  되돌리기 전 저장된 순서가 달라졌으면 덮어쓰지 않는다.
- 처음 목록을 불러오는 동안에는 기존 순서·접힘 설정을 빈 목록으로 덮어쓰지 않는다.
- 가장자리에 가까울수록 빠르게 자동 스크롤하고 방향을 표시한다. 드래그가 끝나면 스크롤도 종료한다.
- 선택 모드에서 체크한 같은 Code의 저장뷰를 원래 순서를 유지한 묶음으로 옮긴다. 여러 Code 선택은 재정렬을 제한하고 이유를 표시한다.
- 선택 삭제는 여러 Code에 걸쳐 사용할 수 있다. 행에 포커스한 상태에서 Delete를 누르면 해당 행,
  선택된 행이면 선택 묶음을 삭제 대기 상태로 전환한다. 입력창·메뉴 버튼의 Delete와 Backspace는 무시한다.
  삭제 행에 있던 포커스는 다음 행, 이전 행, 검색창 순으로 옮긴다. 삭제 대상의 편집 상태도 정리하여 수정 실패가 드래그를 계속 잠그지 않도록 한다.

## 삭제 대기와 실패

삭제 요청마다 독립적인 5초 유예를 준다. 행은 즉시 숨기되 순서 모델에는 남겨 실행 취소 시 같은 위치로 복귀한다.
앱 공통 토스트에서 남은 시간과 실행 취소를 제공한다. 연속 삭제 안내는 높이를 화면의 절반으로 제한한 스크롤 목록에 최신 요청부터 표시한다. 다음 삭제나 패널 전환·닫기는 먼저 요청한 삭제를 확정하지 않는다.
유예가 끝나면 서버 DELETE를 실행하고 진행 중에는 취소 버튼을 제거한다. 브라우저 전체 새로고침·종료는
아직 전송하지 않은 메모리 내 대기 요청을 취소한다. 전송을 시작한 요청은 서버 결과를 따른다.

일괄 요청은 한 묶음당 최대 4개를 동시에 처리한다. 성공한 행만 쿼리 캐시에서 제외하고 실패한 행은 복원한다.
다른 창에서 이미 삭제한 404는 성공으로 처리한다. 성공/실패 개수와 실패한 뷰 이름을 안내하고 실패한 항목만 재시도할 수 있다.
재시도에도 새로운 5초 유예를 부여하며 해당 행의 이름·메모 편집 상태를 정리한다. 성공 안내는 잠시 후 닫히며 실패 안내는 사용자가 닫거나 재시도할 때까지 유지한다.
활성 저장뷰 삭제가 성공한 경우에만 저장 구간 슬롯을 해제하고 현재 종목은 유지한다.

## 검증

- 상태/컴포넌트 단위 테스트: 검색 임시 펼침, 저장 오류, 묶음 삽입 및 되돌리기, 로딩 중 설정 보존,
  요청별 유예·중복 방지·전송 중 취소 제한, 부분 실패·재시도·캐시·활성 구간, Delete 입력 보호 및 포커스.
- 실제 포인터 E2E: 행 위아래 삽입·기간 안내·새로고침, 그룹 핸들, 외부/다른 Code 취소,
  묶음 재정렬·다른 Code 선택 제한, 검색/정렬, 가장자리 스크롤·Escape,
  패널 밖 실행 취소, 연속 삭제, 부분 실패 재시도.
- E2E의 저장뷰 목록과 DELETE는 테스트 전용 응답으로 대체한다. 사용자 저장뷰는 변경하지 않는다.
