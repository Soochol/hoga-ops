# 우측 패널 → 히트맵 페이지 그룹 추가

관심종목·히트맵·스크리너·순위 패널의 단일 종목을 `/heatmap` 보드 그룹에
드롭하면 해당 그룹에 추가한다. 원본 패널의 등록은 유지하며 Ctrl 여부와 무관하다.
패널 내부의 이동·복제·재정렬과 차트 드롭은 기존 규칙을 따른다.
다중 선택과 그룹 자체의 외부 드롭은 지원하지 않는다.

- 그룹 헤더·행·빈 그룹 모두 대상으로 삼는다. 그룹 밖이나 가려진 카드는 제외한다.
- 대상 그룹을 강조하고 그룹 이름과 추가 동작을 표시한다.
- 외부 드래그 중 시세에 따른 보드 그룹·행 순서를 동결한다.
- 같은 그룹의 중복 등록은 안내만 표시한다. 저장 중 추가 드롭은 소비하되 중복 요청하지 않는다.
- 성공·실패를 안내하고 히트맵 및 관련 조회를 갱신한다. Esc는 저장 없이 취소한다.

기존 `POST /api/heatmap/folders/{folder_id}/members`를 사용한다. 서버의 그룹별
멱등 추가와 다중 그룹 등록 계약(ADR-0132)을 유지한다. 패널·보드의 독립적인
dnd-kit 컨텍스트는 유지하며, 마운트된 보드가 좌표 판정과 저장을 담당한다.
스크롤과 최종 드롭 시 실제 포인터 위치의 최상단 요소를 다시 확인한다.

이 문서는 `2026-09-08-heatmap-panel-transfer.md`의 패널 내부 편집 범위에
페이지로의 단일 종목 추가를 별도로 확장한다. 보드 내부 드래그의 이동 규칙은 변경하지 않는다.

검증: 추가·중복·저장 지연/실패·스크롤/가림·언마운트 단위 테스트와 네 패널의
실제 포인터 추가, 원본 보존, Esc·그룹 밖 취소 E2E 테스트.
