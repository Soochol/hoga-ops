# 히트맵 우측 패널 이동·복제 UX

사용자 승인 범위: 관심종목 패널과 같은 정확한 위치 이동, 목적지 안내, 결과·되돌리기,
임시 펼침, 가장자리 스크롤, 전용 핸들, 다중 선택. 기존 Ctrl 복제·차트 드롭·그룹 내 Delete를 유지한다.
전체 페이지 보드의 드래그 UX는 이번 변경 범위 밖이다.

## 조작

- 종목·그룹 왼쪽 ⠿ 핸들에서만 드래그를 시작한다. 행 클릭은 차트 열기다.
- 기본 정렬·비검색 상태에서 행의 위/아래 절반으로 삽입 위치를 선택한다.
  헤더·빈 그룹에 놓으면 끝에 넣는다. 스크롤 후 고정된 헤더는 실제 DOM 위치로 판정한다.
- 패널 밖은 취소한다. 단일 등록을 차트에 놓으면 기존 창별 종목 변경을 수행한다.
  여러 등록을 선택한 드래그는 차트를 변경하지 않는다.
- Ctrl을 누르면 복제, 떼면 이동이다. 고스트·하단 문구·저장 동작이 같은 수정키 상태를 쓴다.
  복제는 원본을 유지하고 목적지에 이미 있는 코드는 그 위치를 유지한다.
  이동은 선택한 출발 소속만 없애고, 목적지 중복은 합친다. 선택하지 않은 다른 소속은 보존한다.
- 선택 버튼으로 체크박스를 켠다. 선택한 행의 핸들을 잡으면 화면 순서로 선택된 등록을
  묶어 이동·복제한다. 미선택 행의 핸들은 그 행만 대상으로 한다. 고스트는 고유 종목 수다.
- 등락률 정렬·검색 중에는 다른 그룹으로만 이동·복제하며 대상의 저장 순서를 보존한다.
  새 종목은 저장 순서 끝에 추가하고 표시 순서는 현재 정렬을 따른다.
- 접힌 그룹에 600ms 머무르면 임시 펼친다. 완료·취소 후 저장된 접힘 상태로 복귀한다.
- 가장자리 48px 안에서 거리에 따라 최대 650px/s로 스크롤하고 방향을 표시한다.
  패널 밖·중앙·드래그 종료에서 멈춘다. 실제 포인터 좌표를 써 스크롤 누적 오차를 피한다.
- 드래그 중 그룹과 행 정렬 시세를 동결하여 폴링 때문에 목적지가 바뀌지 않게 한다.
- Delete는 포커스된 행의 현재 그룹 소속만 해제한다. 중첩 버튼·입력과 Backspace는 제외한다.
  인접 행으로 포커스를 이동하고 실패 시 안내한다. Delete 자체의 되돌리기는 이번 범위 밖이다.

## 저장과 되돌리기

`PUT /api/heatmap/entries/transaction`은 `HeatmapEntriesTransactionRequest`를 받는다.
`changes` 각 원소는 `folder_id`, `before: string[]`, `after: string[]`이다.
드래그 시작 시의 목록을 기준으로 계산한다. 변경이 없는 출발/대상 그룹도 검증 대상에 포함한다.

서버는 히트맵의 단일 잠금 안에서 모든 before를 최신 저장 순서와 대조하고 한 번만 저장한다.
그룹/코드 중복·미등록 코드·영향 그룹의 코드 집합 유실/생성은 거절한다. 변경할 그룹이
사라졌으면 404, 목록이 달라졌으면 409다. 영향받지 않은 그룹과 캡처 마커를 보존한다.
코드 합집합이 유지되어 저장 대상 WS 재등록은 필요 없다. 기존 mutation broadcast로 다른 창에 알린다.

성공한 종목 이동·복제·재정렬의 역변경을 패널이 열린 동안 보관한다.
되돌리기도 같은 비교·저장 API를 사용하므로 그 사이의 편집을 덮어쓰지 않는다.
새 유효 저장 요청, 행 삭제, 그룹 드래그 재정렬은 이전 종목 이동의 되돌리기 기록을 지운다. 취소·no-op·차트 드롭은 유지한다.
저장 중 추가 드래그·되돌리기·행 Delete를 막는다. 오류 후 최신 목록을 다시 조회한다.
그룹 순서 변경은 기존 API를 사용하며 결과·실패를 안내한다.

프런트와 백엔드를 함께 배포해야 한다. 기존 move/reorder API와 전체 페이지 보드는 유지한다.

## 검증

- HTTP/store: 이동·복제·역변경, 별도 소속·캡처 마커 보존, 잘못된 요청의 원자적 거절, 후속 편집 충돌.
- Vitest: 삽입 순서·중복·복제·역변경과 패널/차트 이벤트 배선.
- Playwright: 실제 포인터로 삽입, 헤더·빈 그룹·스크롤된 헤더, 다중 이동·Ctrl 복제,
  임시 펼침 취소, 자동 스크롤, 정렬, 패널 밖 취소, 결과·되돌리기·실패·저장 지연, Delete 범위.
