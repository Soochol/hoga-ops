## 7. 적용 방식 (백엔드 API, :8000)
순서가 중요 — Live Set(표시순서 상위 13×계좌수) 보호 + 멱등성:

1. **폴더 리네임** 4건: `PATCH /api/watchlist/folders/{id}` (기존 폴더 id 유지).
2. **신규 폴더 생성** 11건: `POST /api/watchlist/folders {name}` — 항상 맨 끝(order=len) append.
   레버리지/인버스를 **마지막**에 생성(라이브셋 비대상화).
3. **신규 종목 추가**: `POST /api/watchlist {code}` — 미분류(맨끝) 진입. **이미 있으면 409→skip(dedup)**.
4. **폴더 배치**: `POST /api/watchlist/move {codes, folder_id}` — 대상 폴더 멤버 뒤에 호출순서 보존 append.
   - 신규 종목 + 재배치 12종(SKC 1 · 한미약품 1 · 증권 6 · 화장품 3 · 주성엔지니어링 미분류→전공정 1)을 **주도주 순서**로 이동.
5. **폴더 내 순서 확정**(필요시): `PUT /api/watchlist/reorder {folder_id, ordered_codes}` — 기존+신규 통합 주도주순.

### 멱등성·중복
- 재실행 안전: add는 409 skip, move는 멱등. 폴더 생성은 **이름 존재 확인 후** 호출(중복 생성 방지).
- 교차중복 1차 배정: 대한전선→AI전력/케이블, 우리로→양자기술(각각 다른 폴더 picks에서 제거).

### Live Set 영향 (CONTEXT.md / live_session.py)
- 라이브 캡처 = 표시순서 상위 `13×계좌수`로 **하드캡**. 종목 대량 추가는 등록 한도를 초과하지 않음(순서만이 레버).
- 신규 폴더는 끝에 append, 신규 종목은 미분류(끝) 경유 → **현재 라이브셋(반도체 위주) 기본 안정**.
- 단, **앞쪽 반도체 폴더 보강 추가**는 표시순서를 뒤로 밀어 라이브 경계(26/39번째)를 미세 이동시킬 수 있음.
  특정 26-set 고정이 필요하면 폴더/종목 순서를 별도 핀(out of scope, 본 큐레이션 후 검토).
