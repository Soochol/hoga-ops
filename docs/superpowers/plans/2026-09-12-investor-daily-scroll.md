# 일별 투자자 과거 스크롤

## 결정
- 5·20·60거래일 고정 모드를 유지하고 전체(0)를 기본값으로 추가한다. 기존 저장 선택은 존중한다.
- 전체는 최근 60행으로 시작한다. 하단 스크롤 또는 더 보기로 60행씩 확장한다.
- 최근 130달력일 조회와 정규장 폴링은 유지한다. 과거는 겹치지 않는 130달력일 구간으로 필요할 때만 조회한다.
- 종목·수량/금액·최근 구간별 캐시를 분리한다. 종목/축/기간 변경 시 표시 깊이를 초기화한다.
- 기존 행과 스크롤 위치를 유지하고 날짜별 중복을 제거한다. 누적은 표시 행 기준이다.
- 경고/실패는 커서를 넘기지 않고 재시도한다. 빈 구간은 자동 조회를 멈추고 수동으로 더 과거를 조회할 수 있다(거래정지 구간을 전체 이력의 끝으로 오판하지 않는다).

## 구현 및 검증
1. 전체 기간 선택과 과거 전용 조회 훅, 스크롤 연결.
2. 기간/축 격리, 구간 경계, 실패 재시도 및 빈 구간 테스트.
3. 타입 검사, Vitest, 빌드 및 Playwright E2E.

백엔드 API 계약 변경은 없다. 장기 조회 방향은 ADR-0055와 일치한다.

## 구현 결과
- 전체 모드, 표시 범위/누적 거래일 수, 스크롤 및 수동 추가 조회 구현.
- 최근 데이터가 비어 있어도 과거 조회 가능. 축 전환 중 다른 단위의 과거 행 혼합 방지.
- 타입 검사 통과, 전체 Vitest 569파일/7,411테스트 통과 후 보완 4개를 포함한 창 테스트 21개 통과.
- Vite 프로덕션 빌드 통과. 실제 마우스 스크롤을 포함한 전체 Playwright E2E 121개 통과(3.3분).
- 실자격증명 없이 워크트리 전용 포트(20010/21010)와 데이터로 검증. 운영 배포는 이 작업에 포함하지 않음.
