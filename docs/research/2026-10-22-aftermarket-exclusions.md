# 장후 거래 제외 사유 조사와 표시 정책

조사일: 2026-10-22 KST. 사용자가 제보한 서산(079650)·ETF의 장후 호가 지연 안내를
실제 거래 대상 제외 안내로 바꾸기 위한 조사다.

## 규정에서 확인한 범위

[KRX 코스피 제도 안내](https://regulation.krx.co.kr/contents/RGL/03/03010301/RGL03010301.jsp)와
[KRX 코스닥 제도 안내](https://regulation.krx.co.kr/contents/RGL/03/03020302/RGL03020302.jsp)는
애프터마켓의 호가접수·매매시간을 16~20시로 안내한다. 거래 대상에는 시장관리 조치에
따른 예외가 있다. 일반 투자주의, 지정 예고와 실제 투자경고 지정을 섞으면 안 된다.
이번 확인에서 직접 페이지 열기는 403이었지만 검색엔진에 수집된 공식 본문은 확인했다.

[KB증권 시행 공지](https://www.kbsec.com/go.able?idt=20260904&linkcd=s060901010000&seq=10010298)는
ETF·ETN의 애프터마켓 제외도 명시한다. 이는 장후의 모든 거래가 금지된다는 뜻이 아니다.
거래소 안내상 15:40~16:00의 시간외종가매매는 별도 제도이므로, 그 시간이나 정규장에
이 제외 문구를 표시하지 않는다.

서산은 [10월 13일 거래소 재지정 공시](https://kind.krx.co.kr/external/2026/10/13/000515/20261013001278/72049.htm)에
따라 10월 14일 투자경고종목으로 재지정됐다. 최초 해제 판단 예정일은 10월 27일이다.
종목코드나 이 예정일을 제품에 고정해 놓으면 이후 해제를 놓치므로 런타임 판단에 쓰지 않는다.

## 사유별 표현과 판단 근거

| 확인한 사유 | 화면의 사유 이름 | 사용 근거 |
| --- | --- | --- |
| ETF / ETN | ETF / ETN | 기존 종목 마스터 상품 분류, 누락 시 최신 종목정보의 상품 분류 |
| 투자경고 / 투자위험 | 투자경고종목 / 투자위험종목 | 최신 `orderWarning` 또는 정확히 일치하는 상태 이름 |
| 관리 | 관리종목 | 최신 `state` / `auditInfo`의 실제 지정 상태 |
| 정리매매 | 정리매매종목 | 최신 정리매매 지정; 30분 단위매매 종목은 장후 대상 제외 |
| 단기과열 | 단기과열종목 | 최신 단기과열 지정; 예고는 제외 |
| 투자주의환기 | 투자주의환기종목 | 최신 환기 지정; 일반 투자주의와 구분 |
| 초저유동 / 이상급등 | 초저유동종목 / 이상급등종목 | 공급자가 해당 이름을 명시한 경우에만 사용 |
| 투자유의 | 투자유의종목 | 코스피에서 해당 이름이 명시된 경우에만 사용 |

단기과열의 30분 매매·애프터마켓 제외는
[KRX 단기과열 안내](https://regulation.krx.co.kr/contents/RGL/03/03010408/RGL03010408.jsp)에서도
확인했다. 한 종목에서 여러 근거가 확인되면 모두 표시한다.

## 자료원과 최신성

[키움 공식 종목정보 예제](https://github.com/Kiwoom-Securities/Kiwoom-REST-API/blob/main/examples/%EA%B5%AD%EB%82%B4%EC%A3%BC%EC%8B%9D/%EC%A2%85%EB%AA%A9%EC%A0%95%EB%B3%B4/list_domestic_stocks.py) 및
[공식 JSON 명세](https://github.com/Kiwoom-Securities/Kiwoom-REST-API/blob/main/kiwoom/_data/kiwoom_api_spec.json)의
`ka10100`은 단일 종목의 `code`, `marketCode`, `state`, `auditInfo`, `orderWarning`을 제공한다.
`orderWarning`은 2 정리매매, 3 단기과열, 4 투자위험, 5 투자경고로 해석한다.
공개 명세의 5번 설명에는 ‘투자경과’라는 오기가 있다. 투자경고로의 해석은 해당
필드의 경보 분류와 거래소 용어에 따른 것이며, 이번 작업에서 실계좌 원본 5번 응답을
새로 조회해 대조한 것은 아니다. 1번은 ETF 투자주의 표시이며 일반주 투자경고가 아니다.

기존 마스터는 명시적 갱신 중심이라 시장조치의 최신성을 보장하지 못한다. 동적 지정은
열람 중인 종목만 `ka10100`으로 조회한다. 기존 키움 거버너를 통과하고 같은 종목·날짜는
두 호가창과 여러 요청이 공유한다. 메모리 캐시는 최대 256개·60초이며 날짜별로 분리한다.
실패 시 이전 지정 사유를 계속 현재 사실로 표시하지 않는다. FE도 코드·날짜·확인시각과
실패 상태를 검사하고 2분 이상 지난 결과는 표시하지 않는다. 지정 정보는 디스크에 저장하지 않는다.

## 표시 및 범위

- 중립 안내로 `KRX 장후 거래 제외 · ETF`, `KRX 장후 거래 제외 · 투자경고종목` 등을 표시한다.
- 다음 줄에는 `16:00~20:00 KRX 애프터마켓 거래 대상이 아닙니다.`를 표시한다.
- 남아 있는 호가에는 마지막 호가 시각을 보존한다. 연결 복구 버튼이나 지연 경고를 함께 표시하지 않는다.
- 실제로 거래할 수 없는 시간의 안내이므로, 과거 커서·NXT·통합 실효시장에는 KRX 규칙을 덮지 않는다.
  NXT 미상장 종목의 통합 선택은 기존 실효시장 해석에 따라 KRX에 해당한다.
- 서버는 거래일 달력으로 휴장일을 제외하며, 달력 범위 밖은 확인 불가로 남긴다.

## 확정하지 않는 경우

정규장 거래 미형성, 정규장 종료 시점의 거래정지 등도 거래소의 제외 대상이다.
그러나 `ka10100`의 현재 상태만으로는 **15:30 종료 당시**의 상태나 정규장 체결 유무를
증명할 수 없다. 단순 현재 거래정지나 거래량 0, 오래된 호가, NXT 미상장을 이유로
해당 사유를 생성하지 않는다. 명세에 없는 숫자·새 상태, 미설정·실패·이전 날짜 응답도
제외 증거로 사용하지 않는다. 따라서 사유 목록이 비어 있어도 거래 가능 판정은 아니다.

정규장 호가 지연과 기존 주문 신선도·계좌·증권사 검증은 유지한다. 이 안내는
완전한 주문 가능 종목 판정이나 주문 허용의 근거가 아니다.
