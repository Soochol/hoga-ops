## 실측 (2026-10-11 22:54 KST)

| 종목 | HTTP / rt_cd | 반환 행 | 제공 코드가 조회 종목과 일치 |
|---|---|---:|---:|
| 삼성전자 005930 | 200 / 0 | 40 | 31 |
| SK하이닉스 000660 | 200 / 0 | 40 | 12 |
| 현대차 005380 | 200 / 0 | 40 | 23 |

각 조회의 기사 ID는 40개 모두 고유했다. 최신 배치는 세 종목 모두 2026-10-08 기사였다.
조회일은 일요일이고 10-09는 휴장일이다. 삼성전자 제목에 종목명이 있어도 제공 코드가
삼성화재인 행이 있었고, 현대차 코드가 연결된 타 회사 기사가 있었다.
따라서 제공 코드가 일치해도 본문의 관련성·정확성을 보증할 수 없다.

응답 최상위 키: `output`, `rt_cd`, `msg_cd`, `msg1`.
행 키: `cntt_usiq_srno`, `news_ofer_entp_code`, `data_dt`, `data_tm`,
`hts_pbnt_titl_cntt`, `news_lrdv_code`, `dorg`, `iscd1`…`iscd10`,
`kor_isnm1`…`kor_isnm10`. 공식 샘플의 5개 슬롯과 달리 실응답은 10개다.
원문 URL·본문·요약은 없었다. `tr_cont`도 없어 다음 페이지 기능은 만들지 않는다.

삼성전자 날짜 조회: `FID_INPUT_DATE_1=0020261007`,
`FID_INPUT_HOUR_1=0000235959` → 정상 40행, 모두 2026-10-07, 제공 코드 일치 34행.
다른 날짜가 섞일 가능성을 고려해 서버에서 선택일과 다른 행을 제외한다.
종목·날짜당 전체 기사 수나 과거 보유 기간은 검증하지 않았다.

## 구현 범위

- `/live` 창 추가 → 종목 뉴스. 기존 그룹 연동·고정·이동·크기 조절·레이아웃 저장을 사용한다.
- 제목·언론사·한국 시각 표시. 행 선택 시 제공 종목코드와 제목만 제공된다는 안내를 펼친다.
- `종목코드 연결` / `제목에 종목명` / `조회 결과`를 구분한다. `종목 연결만`은 앞의 두 범주를 표시한다.
- 최신 또는 선택일 최대 40건. 전체 기사 조회나 날짜별 완결성을 약속하지 않는다.
- 최신 모드는 60초 간격 조회. 숨겨진 브라우저 탭에서는 자동 조회하지 않는다.
  새 ID는 알림 버튼에 쌓고 사용자가 수용할 때 목록을 바꾼다.
- FE query key와 BE 60초 캐시로 같은 종목·날짜 조회를 공유한다. 실패도 60초간 캐시한다.
  서버 캐시는 최대 128개 키이며 디스크에 기사 데이터를 저장하지 않는다.
- 누락 설정 / 조회 실패 / 정상 빈 결과를 구분한다. 실패 시 이전 성공의 기사·시각을 보존한다.
- `/api/news/stock?code=005930&date=20261007`의 응답은 명시 모델로 직렬화한다.
  `date` 생략은 최신이다. `status`, `items`, `fetched_at_ms`, `limit`와 요청 종목·날짜를 반환한다.
- 실제 원문 링크가 없어 링크를 추정하거나 검색 결과 URL을 원문으로 표시하지 않는다.
- DART API·인증키·탭은 구현하지 않는다.
