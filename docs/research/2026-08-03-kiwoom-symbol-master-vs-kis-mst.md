# 키움 종목 마스터(`ka10099`) vs KIS `.mst` — 전수 대조

- 티켓: [#1009](https://github.com/Soochol/hoga-ops/issues/1009) (지도 [#1005](https://github.com/Soochol/hoga-ops/issues/1005))
- 조사일: 2026-08-03 · 실계좌 프로브(`scripts/probe_kiwoom_rest_tr.py`) + `.mst` 실다운로드
- 성격: 실측. **소스 결정은 [#1014](https://github.com/Soochol/hoga-ops/issues/1014) 소관** — 여기서는 대조 결과만 확정한다.

## 한 줄 결론

**ETF/ETN 판별은 실질 100% 일치한다** — 코드 표기 차이(`Q` 접두)를 정규화하면 **4,248건 대조에서 불일치 0**. 다만 **무자격 접근은 불가**하다(`1513: authorization 필드가 설정되어 있어야 합니다`).

즉 [#1014](https://github.com/Soochol/hoga-ops/issues/1014) 의 판정 기준 셋 중 **품질 우려는 해소**됐고, 남은 것은 **dev 무자격 검색을 어떻게 할 것인가** 하나다.

---

## 1. ETF/ETN 판별 — 판별 필드는 `marketCode`

`ka10099` 응답에서 종목 종류를 가르는 것은 `marketCode`/`marketName` 이다:

| `marketCode` | `marketName` | 건수(`mrkt_tp=0`) |
|---|---|---|
| `0` | 거래소 | 917 |
| **`8`** | **ETF** | **1,155** |
| **`60`** | **ETN** | **367** |
| `6` | 리츠 | 23 |
| **`90`** | **ETN(변동성)** | **8** |
| `2` | 인프라투자금융 | 2 |
| — | ETN(손실제한) | 1 |

**`companyClassName` 은 2,474행 전부 빈 값이다** — 이름만 보고 판별 필드로 고르면 안 된다.

`kind` 는 `A`(2,098) / `Q`(376) 두 값인데 `Q` 수가 ETN 계열 합계(376)와 일치한다 — 보조 신호로 쓸 수 있으나 `marketCode` 가 더 직접적이다.

## 2. 전수 대조 결과

```
.mst      4,249행   stock 2,718 · etf 1,155 · etn 376
ka10099   4,295행   mrkt_tp=0 (2,474) + mrkt_tp=10 (1,821)
```

매핑 가설: `marketCode` `8`→etf, `60`/`90`→etn, `0`·코스닥→stock.

| 항목 | 결과 |
|---|---|
| 코드 교집합 | **3,872건 — 불일치 0** |
| ETN(코드 정규화 후) | **376 / 376 완전 매칭** (이름도 376/376) |
| **총 대조** | **4,248건 · 불일치 0** |

### ETN 코드 체계가 다르다 — 데이터가 없는 게 아니다

첫 조인에서 `.mst` 에만 377건, 키움에만 423건이 남았는데 **대부분이 같은 ETN 이었다**:

```
.mst   Q500061, Q500063, Q500067, …   (Q 접두)
키움    500061,  500063,  500067, …   (접두 없음)

[가설] Q 접두 제거 → 적중 376 / 실패 0
[대조] 이름 일치  → 376 / 376
```

**`.mst` etn 376 = 키움 ETN 계열 376**(60:367 + 90:8 + 손실제한:1). 개수까지 정확히 같다. 코드 정규화 규칙 하나(`Q` 접두 제거)면 해소된다.

### 남는 유니버스 차이 — 정책 차이지 오류가 아니다

| 방향 | 건수 | 정체 |
|---|---|---|
| 키움에만 | 19 | **외국주**(`950170 JTC` · `900340 윙입푸드` · `900250 크리스탈신소재` 등 `9xxxxx` 코드). `.mst` 파서가 `FS`(외국주)를 의도적으로 드롭한다(`kis_master._classify`) |
| 키움에만 | 26 | 리츠 23 · 인프라투자금융 2 · 뮤추얼펀드 1 — 역시 `.mst` 가 `RT`/`IF`/`MF` 로 드롭 |
| `.mst` 에만 | **1** | `467930 IBKS제23호스팩` — 신규 스팩. 타이밍 차이로 보인다 |

**즉 키움이 더 넓다.** 현재 SPEC 범위(보통주+ETF+ETN)에 맞추려면 키움 쪽에서 필터링하면 되고, 그 필터는 `marketCode` 로 정확히 표현된다.

## 3. 필드 커버리지

`.mst` 파서가 산출하는 `MasterRow` 는 4필드다: `code` · `name` · `market`(KOSPI/KOSDAQ) · `security_type`(stock/etf/etn).

| `.mst` 필드 | 키움 대응 | 비고 |
|---|---|---|
| `code` | `code` | ETN 은 `Q` 접두 정규화 필요 |
| `name` | `name` | 376/376 대조 일치 |
| `market` | **요청 파라미터 `mrkt_tp`** | 응답 필드가 아니다 — 아래 참조 |
| `security_type` | `marketCode` | `8`=etf, `60`/`90`=etn, 나머지=stock |

**`market` 은 응답이 아니라 요청이 결정한다.** `.mst` 실측 분포를 보면 자연스럽다:

```
KOSPI  stock 915 · etf 1,155 · etn 376
KOSDAQ stock 1,803
```

**ETF·ETN 은 전부 KOSPI 소속**이다. 그래서 `mrkt_tp=0`(코스피) 응답에 ETF/ETN 이 섞여 오고, `mrkt_tp=10` 은 전부 코스닥 주식이다. 두 번 호출해 각각 시장을 태깅하면 `.mst` 와 동일한 정보를 얻는다.

키움은 그 밖에 11개 필드를 더 준다(`upName`·`upSizeName`·`listCount`·`auditInfo`·`state`·`orderWarning`·`nxtEnable` 등). 현재 소비자가 쓰지 않지만 `nxtEnable`(NXT 거래 가능 여부)은 venue 라우팅에서 쓸모가 있을 수 있다.

## 4. 무자격 접근 — **불가 확정**

```
토큰 없이 POST /api/dostk/stkinfo (api-id: ka10099)
→ HTTP 200, return_code: 2
  "입력 값 오류입니다[1513:Http Header에 authorization 필드가 설정되어 있어야 합니다]"
```

`.mst` 는 인증 없는 정적 zip 다운로드다(`kis_master._MARKETS`: `https://new.real.download.dws.co.kr/common/master/*.mst.zip`). 키움 마스터로 갈아타면 **ADR-0134 의 "dev 무자격 프로필에서 종목 검색이 동작한다" 는 계약이 깨진다.**

키움이 제공하는 무인증 정적 마스터 파일은 확인하지 못했다.

## [#1014](https://github.com/Soochol/hoga-ops/issues/1014) 판정 기준에 대한 답

티켓이 세운 기준 셋에 실측으로 답한다:

| 기준 | 실측 답 |
|---|---|
| ① **ETF/ETN 판별 정확도** — 키움이 `.mst` 보다 나쁘면 동기 ②(데이터 일관성)에 반한다 | ✅ **동등**. 4,248건 불일치 0. 오히려 키움이 외국주·리츠까지 더 넓게 준다 |
| ② **dev 무자격 검색** — 계약이 깨지는가 | ❌ **깨진다.** 토큰 필수(`1513`) |
| ③ **동기 ①(단일화)의 실이득** — `.mst` 는 토큰·유량·계정 관리가 애초에 0 | ⚠️ 실이득은 **"도메인에 KIS 라는 단어가 남지 않는 것"** 에 가깝다. 다만 `.mst` 는 KIS 도메인 호스트(`dws.co.kr`)에 대한 런타임 의존이므로 "KIS 흔적 0" 을 원하면 남길 수 없다 |

**보상 설계가 필요한 것은 ② 하나뿐이다.** 티켓의 선택지 C(스냅샷 이원화 — 마스터를 주기적으로 데이터/리포에 커밋)가 ②를 해소하면서 양쪽 벤더 의존을 동시에 없앤다는 점을 실측이 뒷받침한다: 마스터는 **4,295행 / 15필드**로 작고, 갱신 빈도도 낮다.

`is_etf` SSOT 를 어디에 둘지는 여전히 #1014 의 결정이다(메모리 `etf-exclude-two-truth-sources`: 진실 소스 2벌로 127건 누수 전력).

## 미측정 · 유의

- **하루치 스냅샷만 대조했다.** 신규 상장·상장폐지 타이밍에서 두 소스가 갈리는지는 여러 날 관측해야 안다. `.mst` 에만 있던 스팩 1건이 그 신호일 수 있다.
- **`mrkt_tp` 값 전수 미확인.** `0`(코스피) · `10`(코스닥) · `3`(ELW, 2,870행)만 확인했다. 코넥스 등 다른 시장 코드가 있을 수 있다.
- **`Q` 접두 규칙의 일반성 미확인.** 376건 전부에서 성립했지만 KIS 측 코드 체계 문서로 뒷받침한 것은 아니다.
- **키움 무인증 정적 마스터 존재 여부** 미확인 — 없다고 단정하지 않는다.
- `kind` `A`/`Q` 의 정확한 의미 미확인(ETN 수와 일치한다는 관측만).
