## 1. ka10064 — 장중투자자별매매차트 (종목 전용, 시장 불가)

```
/api/dostk/chart  api-id: ka10064
body {"stk_cd":"005930","amt_qty_tp":"1","trde_tp":"0","mrkt_tp":"0"}
→ return_code 0, 래퍼 opmr_invsr_trde_chart, 3행, 9필드, 49ms, cont-yn=N
필드: tm, frgnr_invsr, orgn, invtrt, insrnc, bank, penfnd_etc, etc_corp, natn
```

**스코프 실측 (3안 전부 시도):**

| 시도 | 결과 |
|---|---|
| `stk_cd:"005930"` | 정상, 3행 |
| `stk_cd:"001"` (코스피 지수 코드) | `return_code 0` 이지만 **`opmr_invsr_trde_chart` 가 빈 값** — 지수 코드를 안 받는다 |
| `stk_cd:""` + `mrkt_tp:"001"` | `return_code 2` — `1511:필수 입력 값에 값이 존재하지 않습니다. 필수입력 파라미터=stk_cd` |

`stk_cd` 는 우회 불가한 필수값이고 지수 코드도 받지 않는다. **시장 전체 장중 투자자
시계열을 이 TR 로 만들 수 없다.**

**두 번째 결손: 개인이 없다.** 필드에 개인(`ind_*`)이 아예 없다 — 외국인·기관계와
기관 세부(투신·보험·은행·연기금)·기타법인·국가뿐이다. 프로토타입의 3주체(개인·외국인·
기관) 구성은 이 TR 로는 2주체가 된다.

**세 번째: 슬롯이 불규칙하다.** 10:33 시점 실측 3행 —

```
tm 090000  frgnr_invsr 0       orgn 0
tm 092000  frgnr_invsr 73709   orgn 0
tm 095700  frgnr_invsr 96974   orgn -52807  invtrt -35815  penfnd_etc -16645
```

30분 고정 격자가 아니라 **벤더 갱신 시점마다** 행이 붙는다(09:00 → 09:20 → 09:57).
값은 **누적**이다(외국인 73709 → 96974). 차트의 x축을 고정 격자로 가정하면 안 된다.

경로 탐색 실측 — 벤더가 `1504` 로 알려 준다(`해당 URI에서는 지원하는 API ID가 아닙니다`):

cntr_tm 103859  dfrt +20885  ndiffpro +321741  all +342625  kospi200 +103644  basis 2.56

## 2-b. ka10051 단위 확정 (2026-08-05 11:26~11:32 추가 실측, #1117)

**결론**

| `amt_qty_tp` | 축 | 단위 |
|---|---|---|
| `"0"` | **금액** | **억원** |
| `"1"` = `"2"` | **수량** | **천주** |

`trde_qty` 는 `amt_qty_tp` 와 무관하게 고정 단위 **천주**. `cur_prc`·`flu_rt` 는 **×100 정수**
(`660733` = 6607.33, `349` = 3.49%).

**⚠ ka10064 의 코드표가 여기 통하지 않는다.** 이 리포는 `kiwoom_investor.py:9-12` 에
`ka10064` 를 "① `amt_qty_tp` 는 이름 순서가 직관과 반대다 — 2=수량(주), 1=금액(백만원)" 로
실측 기록해 뒀는데, **`ka10051` 은 표가 다르다**: `1` 과 `2` 가 같은 값을 주고(둘 다 수량),
금액은 `0` 이다. 단위도 다르다(백만원 vs 억원). TR 별 코드표를 따로 확인해야 한다.

**판별 방법 — 두 시장 교차 대조.** 한 시장만 보면 두 가설이 모두 그럴듯해서 갈리지 않는다.
금액/수량 비율은 곧 **함의 평균 체결단가**이므로, 코스피(비싼 종목)와 코스닥(싼 종목)에서
방향이 뒤집히는지 보면 단위 가정 없이도 판정된다.

| | tp0 | tp1 | 가설 A(tp0=수량) 함의단가 | 가설 B(tp0=금액) 함의단가 |
|---|---|---|---|---|
| KOSPI 외국인 | 8,871 | 4,974 | 56,070원 | **178,350원** |
| KOSDAQ 외국인 | 3,610 | 5,677 | 157,258원 | **63,590원** |

가설 A 는 **코스닥이 코스피보다 비싸다**는 불가능한 결론을 낳는다. 가설 B 만 방향이 맞는다.
절대값도 맞는다 — 코스피 순매수 평균 178k(삼성전자 248k·SK하이닉스 264k 대역), 코스닥
63.6k(알테오젠 412k·에코프로비엠 148k·셀트리온제약 84k 대역).

**규모 교차검증.** ka20003 의 `trde_prica` 는 **백만원**이다(코스피 `13,485,976` = 13.5조,
`trde_prica/trde_qty × 1000` = 시장 평균 체결단가 66,046원 — 코스닥은 10,680원). ka10051 의
외국인 순매수를 백만원으로 읽으면 88.7억(회전율의 0.07%)이라 상승장에서 불가능하고,
억원으로 읽으면 8,871억(13.5조 회전의 6.6%)으로 타당하다.

**⚠ 같은 `sect` 계열 안에서도 금액 단위가 다르다** — `ka20003.trde_prica` 는 백만원,
`ka10051.*_netprps` 는 억원. `ka90005`/`ka90010` 의 `kospi200` 스케일 차이(§4)와 같은 부류의
함정이다. **필드 이름에 단위를 박는다**(`_amt_eok` / `_qty_kshares`).

  업종 커버리지를 비교해 판단할 것.
- ~~ka10051 금액 단위~~ → **§2-b 에서 확정**(#1117). `ka90005`/`ka90010` 금액 단위와
  `kospi200` 스케일 차이는 미확정으로 남는다 — 배선(#1101)에서 확인.
- **기존 코드의 단위 오표기 발견** — `InvestorNetPoint.foreign_net` 주석이 "순매수 수량" 인데
  `ka10051` 경로(`/api/live/index-investor-net`)는 `amt_qty_tp="0"` = **금액(억원)** 을 담는다.
  같은 모델을 쓰는 `ka10059` 경로(`/api/live/past-investor-net`)는 `AMT_QTY_QUANTITY="2"` 라
  실제로 수량이다 — **두 경로가 같은 모델에 다른 물리량을 넣고 있다.** 별도 이슈로 분리했다.
