# ETF 탐색: 검색과 상세 선택 연결

`/etfs`에서 정확한 ETF 이름이나 코드를 입력해도 이전 ETF 상세가 남아 혼동하던 동작을
개선했다. 목록의 현재 필터 안에서 정확히 일치하는 ETF 하나만 자동으로 연다. 이름·코드
검색은 NFKC 정규화, 대소문자·공백 차이를 허용한다. 운용 방식·운용사 필터는 그대로
존중하며 구성종목 역검색이나 부분 검색 결과 하나를 자동 선택으로 오인하지 않는다.

- 정확한 이름·코드로 상세를 자동 갱신하되 검색 입력의 포커스·스크롤을 유지한다.
- 한글 IME 조합 중에는 자동 선택과 Enter 선택을 보류하고 조합 완료 후 적용한다.
- 검색창의 ↑↓로 결과에 진입하고 결과의 ↑↓·Home·End로 페이지를 넘나들 수 있다.
  Enter/Space 또는 클릭으로 선택하면 상세로 스크롤하고 제목에 포커스를 옮긴다.
  Escape는 검색 입력으로 돌아온다. 제목 강조는 기존 테마 토큰·400ms이며 동작 감소
  설정에서는 애니메이션을 끈다.
- 결과가 없으면 적용한 운용 방식·운용사를 표시한다. 필터 초기화는 검색어와 비교
  목록을 유지하며 필터만 해제한다. 필터가 없으면 조사한 119개 내 검색임을 안내한다.
- 정확한 검색·선택 상태는 기존 저장 키로 복원하며 ETF 점수·구성·겹침 계산은 유지한다.

검증: 전체 프론트 타입 검사, 해당 폴더 ESLint(오류·경고 0), 모델 단위 테스트 9개,
ETF 탐색 브라우저 테스트 8개 및 Vite production build 통과. 기존 역검색·겹침·상태 복원·
오류/재시도·1440/960/600px 두 테마 검사도 포함했다. `selected-etf.png`는 실제 프로젝트
브라우저 테스트에서 키보드로 ACE ETF를 연 화면이다. 입력 지문·명령은 `verification.json`.
