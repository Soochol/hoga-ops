# 거래일 달력을 키움 지수 일봉에서 역산 — KIS 휴장일 API 대체

- 티켓: [#1013](https://github.com/Soochol/hoga-ops/issues/1013) (지도 [#1005](https://github.com/Soochol/hoga-ops/issues/1005))
- 조사일: 2026-08-03 · 실계좌 프로브 + KIS `chk-holiday` 직접 대조
- 대체 대상: `hoga/api/kis_holidays.py` (`CTCA0903R`)

## 한 줄 결론

**키움 지수 일봉(`ka20006`)이 반환한 날짜 집합 = KIS 거래일 집합.** 8개월 대조에서 **불일치 0**. 벤더를 추가하지 않고 갭을 메울 수 있다.

## 왜 성립하는가

`ka20006`(업종일봉, `inds_cd=001` 종합지수)은 **거래일에만 행이 존재**한다. 휴장일은 지수가 산출되지 않으므로 행 자체가 없다. 즉 반환된 `dt` 목록이 곧 거래일 달력이다.

## 검증 1 — 주말·공휴일 배제

```
base_dt=20260803 → 600행, 20240214 ~ 20260803
주말 포함: 0건
2026-01 평일 22일 중 미반환: 1건 → 20260101 (신정)
```

## 검증 2 — KIS `chk-holiday` 와 직접 대조

`hoga.api.kis_holidays.fetch_month_trading_days(y, m)` 결과와 대칭차를 계산했다:

| 월 | KIS | 키움 역산 | 불일치 |
|---|---|---|---|
| 2025-09 | 22 | 22 | **0** |
| 2025-10 | 18 | 18 | **0** |
| 2025-12 | 21 | 21 | **0** |
| 2026-01 | 21 | 21 | **0** |
| 2026-03 | 21 | 21 | **0** |
| 2026-05 | 18 | 18 | **0** |
| 2026-06 | 21 | 21 | **0** |
| 2026-07 | 22 | 22 | **0** |
| **합계** | | | **0** |

추석(2025-10, 18일)·연말(2025-12)·신정(2026-01)·석가탄신 등 연휴가 낀 달을 의도적으로 골랐다.

## 검증 3 — 보유 깊이

```
base_dt=20180101 → 600행, 20171228 ~ 20150722
base_dt=20100101 → 600행, 20091230 ~ 20070803
```

**2007년까지** 도달한다. 인벤토리 달력 소급에 충분하다. 페이지당 600행 ≈ 2.4년이고 `base_dt` 로 랜덤 액세스가 되므로(#1008) 임의 과거 월을 직접 조회할 수 있다.

## 미래 거래일은 필요 없다 — 실측

`ka20006` 은 미래를 주지 못한다. 그것이 문제가 되는지 소비자를 전수 확인했다:

| 소비자 | 범위 |
|---|---|
| `hoga/api/scheduler.py:168` | `daily_run_allowed_by_calendar(..., today)` — **오늘** |
| `hoga/api/scheduler.py:249-252` | `if start > today: return` 뒤 `trading_days_for_enqueue(start, today)` — **명시적 today 상한** |
| `hoga/api/captures.py:1372` | `_expand_trading_days_with_fallback(start, end)` — 사용자가 고른 **과거** 범위 |
| `is_trading_session_today` (5곳) | **오늘** |

**미래 거래일을 요구하는 소비자가 없다.** `calendar.py` 주석이 "current/future month 는 staleness 를 수용" 이라고 적은 것은 `/api/inventory/calendar` 가 미래 달을 조회할 수 있다는 뜻인데, 그 달은 데이터가 없어 어차피 빈 달로 표시된다.

## 결정 — 역산 결과를 **리포에 커밋**한다 (사용자 확정 2026-08-03)

런타임에 키움을 직접 조회하지 않고, 역산한 거래일 달력을 **정적 파일로 커밋**한다.

**근거:**
- **런타임 벤더 의존 0** — 키움 장애가 나도 달력은 살아있다. 지도 fog 의 "키움 단일 벤더 장애 정책의 확장"(키움 장애 = 실시간+백필+달력 동시 정지)을 이 표면에서만큼은 회피한다.
- **dev 무자격에서 동작** — ADR-0134 의 무자격 프로필에서 달력이 살아있다. 키움 마스터(`ka10099`)가 토큰을 요구해 검색 계약이 깨지는 것(#1009)과 대비된다.
- **갱신이 값싸다** — 새 거래일은 하루에 하나씩만 늘어난다. 스케줄러가 자동 갱신할 수 있다.

**구현 시 정할 것**(→ [#1016](https://github.com/Soochol/hoga-ops/issues/1016)):
- 파일 형식·위치(리포 커밋 vs `HOGA_DATA_DIR` 산출물)와 그에 따른 배포 경로
- 갱신 주체(스케줄러 편승 vs 별도 잡)와 실패 시 거동
- `calendar.py` 의 월 캐시(`_month_cache`)·음성 캐시·`TradingDayUnavailableError` 계약을 어떻게 유지할지 — 정적 소스에서는 "일시 장애" 라는 상태가 사라진다
- 초기 시드 범위(2007년부터 전량 vs 최근 N년)
- #976 이 확립한 "영구 결여(자격증명 없음)는 평일 폴백 · 일시 장애는 fail-fast" 구분이 정적 소스에서 어떻게 바뀌는가 — **폴백 자체가 불필요해질 가능성이 크다**

## 대안과 기각 사유

| 대안 | 기각 사유 |
|---|---|
| 런타임에 키움 직접 조회 | 키움 장애 = 달력 정지 · dev 무자격에서 달력 사망 |
| 정적 달력 **수동** 커밋 | 연 1회 사람이 갱신 → 잊으면 **다음 해 1월에 캡처 enqueue 가 조용히 틀린다** |
| KRX 공개 데이터 | 제3 벤더 추가 — 지도의 동기(브로커 단일화)와 정면 충돌 |

## 미측정 · 유의

- **`ka20006` 이 거래일에만 행을 준다는 것은 8개월 + 600행 구간에서만 확인**했다. 반나절 장(과거 연말 단축장 등)이나 임시 휴장이 섞인 특수 구간은 별도 확인이 필요하다.
- 지수 종목(`inds_cd=001` 코스피 종합)만 썼다. 코스닥(`101`?)과 거래일이 갈리는 날이 있는지는 미확인 — KRX 는 통상 동일하지만 검증하지 않았다.
- KIS `chk-holiday` 는 `opnd_yn` 로 개장일을 판정하는데, **결제일(`sttl_day_yn`)·영업일(`bzdy_yn`) 같은 다른 축은 이 대체가 제공하지 않는다.** 현재 소비자가 `opnd_yn` 만 쓰는지 확인했고(`kis_holidays.py` docstring: "trading day ⇔ opnd_yn == Y") 다른 축의 소비자는 없다.
