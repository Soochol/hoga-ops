# KRX 애프터마켓 공식 출처 조사

조사 기준: 2026-09-11 KST. 시행 전 공개 공지를 확인한 결과이며, 실제 개장 후 API 응답은 검증하지 않았다. 코드 영향 분석과 구분하여 제도·공급자 공지 사실만 기록한다.

## 확인한 사실

- 금융위원회 2026-06-24 정책자료는 KRX 애프터마켓 신설을 9월 14일, 프리마켓 신설 목표를 2027년 말로 명시한다. 이번에 KRX 프리마켓까지 열리는 것으로 해석하면 안 된다. [금융위원회 정책자료](https://www.fsc.go.kr/no040101?cnId=3287&curPage=18&pastPage=18&srchKey=&srchText=)
- KB증권 2026-09-04 시행 공지는 **2026-09-14부터 16:00~20:00 KRX 애프터마켓 신설, 기존 16:00~18:00 시간외단일가 폐지**를 명시한다. 매매는 접속매매이며 VI 때는 단일가로 전환한다. 지정가·최우선지정가·최유리지정가와 IOC/FOK를 안내한다. 거래 대상은 주권·외국주권·DR·REITs 등이다. ETF·ETN 외에도 당일 정규장 미거래, 투자경고·위험, 이상급등, 관리, 초저유동 종목 등이 제외된다. 따라서 모든 주식에 거래 가능 상태를 부여하면 안 된다. [KB증권 공지](https://www.kbsec.com/go.able?idt=20260904&linkcd=s060901010000&seq=10010298)
- 같은 KB 공지는 NXT에도 정적 VI 신설, VI 때 2분 단일가, 거래중단 후 30초 단일가가 적용됨을 명시한다. 이 변경은 실시간 체결이 잠시 없는 상태를 단순 장애로 해석하는 로직에 영향을 줄 수 있다. [KB증권 공지](https://www.kbsec.com/go.able?idt=20260904&linkcd=s060901010000&seq=10010298)
- 카카오페이증권은 정규장 09:00~15:30 유지, 정규장 미체결 주문의 애프터마켓 비승계, 당일 종가의 15:30 정규장 기준 유지를 안내한다. 현재가가 20시까지 변한다고 일봉 공식 종가·평가 기준을 함께 덮어쓰면 안 된다. [카카오페이증권 2026-09-03 공지](https://www.kakaopaysec.com/customer/notice/dynamicBoardPageDetail.do?id=7452)

## KIS Open API 공지에서 확인한 변경

[KIS Developers](https://apiportal.koreainvestment.com/intro)의 2026-09-09 「[중요] KRX 애프터마켓 도입 및 NXT 제도 변경에 따른 안내」를 확인했다. 사이트는 공지를 팝업으로 제공하며 게시물 ID는 `26dfe350-eb72-48e5-8175-34eb27970f3e`이다. 정상 메인 URL의 정적 본문에는 제목만 나타나기도 하므로 서비스 공지사항에서 해당 제목을 열어야 한다.

| API | 공지된 변경 |
| --- | --- |
| `H0STCNT0`, `H0UNCNT0`, `H0NXCNT0` 실시간 체결 | `MARKET_CLS_CODE` 추가: 1 프리, 2 정규, 3 애프터, 5 종가 |
| `H0STASP0` KRX 실시간 호가 | 동일한 `MARKET_CLS_CODE` 추가 |
| `H0UNASP0` 통합 실시간 호가 | `ANTC_EXCH_CLS_CODE` 추가: 1 KRX, 2 NXT |
| 현금·신용·정정취소 주문 `ORD_DVSN` | KRX 애프터 지정가 계열 41~47 추가 |
| 동일 주문 필드 | NXT 프리 전용 GTP 27~29 추가; 미체결은 08:50 취소 |

KIS는 애프터마켓 ETP 거래 불가도 명시한다. 이 공지를 **키움 API 필드 변경의 증거로 사용하면 안 된다**. 현재 프로젝트는 실시간 시세를 키움에서 처리하고 KIS WS 계층을 삭제했다고 확인되므로, KIS WS 파서 수정은 직접 변경 항목이 아니다. 향후 KIS WS를 다시 도입할 경우 최신 필드 순서·레코드 길이 확인이 필요하다.

## 최초 조사 한계 (아래 키움 추가 조사로 일부 해소)

1. KRX의 개정 업무규정·시행세칙 최종 원문 및 기술 통보서 직접 링크는 확보하지 못했다. 위 시행 사실은 금융위 정책자료와 참여 증권사 공식 공지로 교차 확인했다.
2. 사용자 제시 **기준가 ±30%**는 여러 최신 보도에서 일치하지만, 이번에 읽은 공식 본문에서 직접 확인하지 못했다. 구현 시 당일 정규장 종가에 새로 ±30%를 계산하지 말고, 공급자가 제공하는 당일 기준가·상하한가 필드와 최종 규정을 확인해야 한다.
3. 키움 REST API/실시간 WebSocket의 9월 14일 변경 공지는 공개 검색에서 확보하지 못했다. 검색된 키움 NXT 안내 PDF는 2025년 자료이므로 새 KRX 세션에 대한 근거로 사용하지 않았다. 키움의 `0B`/`0D`/`0J`, 통합 `_AL` 심볼, 시장운영 상태 FID, KRX 애프터 거래 가능 종목 플래그, 차트·현재가 REST 집계 범위가 그대로인지 별도 확인해야 한다.
4. NXT 애프터 시작 시각 변경은 확정하지 못했다. 유안타 안내에는 16:00~20:00으로 표시되어 있으나 같은 페이지에 폐지 예정 KRX 시간외단일가 표도 함께 남아 있어, 이것만으로 현재 프로젝트의 15:40 경계를 바꾸면 안 된다. [유안타 거래시장 안내](https://www.myasset.com/myasset/static/trading/TR_1608001_T1.jsp)
5. KIS 공지의 추가 필드 위치, 키움 거래량·거래대금의 세션별 초기화 여부, 공식 일봉 OHLC와 통합 현재가의 세션 범위는 실응답/최신 명세 확인이 필요하다.

## 개장 전후 검증 과제

- 키움 공식 API 공지와 최신 명세에서 애프터 세션 구독 방법 및 종목별 가능 여부 필드를 확인한다.
- 15:30, 15:40, 16:00, 20:00 경계에서 KRX만 가능한 주식, 양시장 주식, ETF, 거래제한 종목을 구분해 실제 시세 및 시장상태를 확인한다.
- 정규장 종가 스냅샷과 애프터 최신가를 별도 비교하고, 애프터 거래량·거래대금이 누적값인지 확인한다.
- VI 단일가 구간과 실제 연결 장애의 판정 차이를 확인한다.

위 과제는 구현 검토 항목이며 실제 거래 주문을 실행한 결과가 아니다.


## 추가 조사: 키움 공식 공지 및 최신 공개 JSON 확인

[공식 운영시간 이미지](https://bbn.kiwoom.com/bbs/VBbsNoticeImageView?apndnm=260909174128446O3AU.png)를 직접 열어 **NXT 애프터 15:40~20:00 유지**도 확인했다. 이로써 유안타 페이지의 16시 표기에 대한 불확실성은 해소되었다.

### 2026-09-10 오픈API 변경 공지 (seqid=60)

[키움 공식 API 공지](https://openapi.kiwoom.com/board/Board0101View?seqid=60)는 **API 변경 적용을 2026-09-12 토요일 21시**로 안내한다. [변경사항 표 이미지](https://bbn.kiwoom.com/bbs/VBbsNoticeImageView?apndnm=260910084701282YFH7.png)를 직접 판독했다.

- 시간외단일가 등락률 순위 `ka10098`, 시간외단일가 요청 `ka10087` 삭제.
- 매수/매도 시간외단일가 주문유형 `62` 삭제.
- 주문체결 `00`의 시간외단일가 현재가 FID `10010` 삭제.
- NXT 프리마켓 전용 GTP: 보통 `40`, 최유리 `46`, 최우선 `47` 추가.
- VI 발동/해제 `1h`의 VI 발동구분 FID `9068`에 **`4`: VI 연장** 추가. 기존 값은 `1`: 정적 VI, `2`: 동적 VI, `3`: 동적+정적 VI.

이 공지는 `0B`와 `0D`의 타입 교체나 새로운 KRX 애프터 구독 코드를 명시하지 않는다. 이것만으로 개장 후 응답이 완전히 동일함을 보장할 수는 없다.

본문은 iframe에서 동적으로 로드된다. 확인 경로: 공식 페이지 소스의 `bbn.kiwoom.com/bbs/SBbsNoticeNOPAZListAjax` → 상세 `SBbsNoticeNOPAZDetailAjax`의 `seqid=59/60`. 검색엔진의 정적 추출 실패와 공지 부재는 구분해야 한다.

### 공개 API 명세에서 확인한 범위와 잔여 한계

[키움 공식 홈페이지](https://openapi.kiwoom.com/main/home)가 링크하는 [공식 GitHub](https://github.com/Kiwoom-Securities/Kiwoom-REST-API)의 조사 시점 커밋은 `234560d213acd8871ae344b5481aecd2f30287fa`이다. [고정 버전 JSON 명세](https://github.com/Kiwoom-Securities/Kiwoom-REST-API/blob/234560d213acd8871ae344b5481aecd2f30287fa/kiwoom/_data/kiwoom_api_spec.json)와 홈페이지 문서 다운로드 기능이 조회하는 `/guide/getApiInfoListAjax` 공개 응답을 비교했다.

- `0B`/`0D` 구독은 KRX 기본 종목코드, NXT `_NX`, SOR `_AL` 형식을 제공한다. KRX 애프터 전용 suffix는 확인되지 않았다.
- 웹사이트 최신 `0B` 명세는 `290`을 장구분(1 장전 시간외, 2 장중, 3 장후 시간외), `9081`을 거래소구분 **`KRX`, `NXT` 문자열**로 설명한다. GitHub JSON의 `9081` 예시는 숫자 `1`이어서 사이트와 차이가 있다. KRX 애프터의 `290` 실제 값은 별도 보장되지 않는다.
- `0s`의 `215` 문서에는 여전히 시간외단일가 `c`/`d`, 18시 이후 전체장마감 `9`가 남아 있다. 이를 새 세션의 검증된 상태 매핑으로 사용하면 안 된다. 최신 공지는 새 KRX 애프터 시작·종료 상태 코드를 제공하지 않는다.
- `ka10099`/`ka10100`에서 확인한 가능 여부는 **`nxtEnable`(NXT가능여부, Y 가능)**이다. 이를 KRX 애프터 가능 여부로 재사용할 근거는 없다. `0g` 포함 검토한 명세에서 **KRX 애프터 전용 대상종목 플래그는 확보하지 못했다**.
- 일반 명세에 없는 새 상태·필드를 임의로 만들지 말고, 종목 eligibility는 미확인을 허용하며 공급자 공지·실응답으로 보강해야 한다.

제품 코드의 실제 변경 범위는 별도의 코드 영향 분석과 테스트 결과를 따른다.
