## 1. 문제 정의

### 1.1 이벤트

종목 `c`, 거래일 `D` 에서

```
bid_peak(c, D) ≥ 1.5 × max{ bid_peak(c, d) : d ∈ 직전 10 코퍼스 거래일, D 제외 }
그리고 close(c, D) < SMA20(c, D)            # 사용자 정의: MA20 아래의 peak 만 유효
```

`bid_peak` 는 이 리포의 `screener/depth_daily.parquet` 가 (code, date) 마다 저장하는 **당일 매수 총잔량 최댓값**이다 — `hoga.tables.snapshots.query_daily_depth_peak` 의 정의 그대로, 연속거래 호가창(10단계 전부 노출) 이면서 정규장 구간(`session_open ≤ t ≤ session_close`) 인 스냅샷에서 `SUM(bid_q1..bid_q10)` 의 최댓값이다. 동시호가·VI 단일가 구간은 술어로 빠진다(ADR-0062 v3). 즉 첫 줄은 `/screener` 의 **`bid_depth_new_high` (lookback=10, threshold_pct=150)** 조건과 정의가 같고, 둘째 줄이 사용자가 추가한 유효 조건이다.

MA20 조건은 이벤트·기준군을 가르기 **전에** 판정 가능한 (code, D) 전체에 건다. MA20 위의 peak 는 이벤트가 아닐 뿐 아니라 비교 대상(같은 국면의 평범한 날)도 아니다 — 비교는 같은 국면끼리 해야 한다.

기준선 창은 캡처가 있는 날이 아니라 **코퍼스 거래일** 10일이다. 캡처가 빠진 날은 기준선에서 조용히 빠져 기준선을 낮추므로(2026-08-11 실측 사고, `depth_daily.py` docstring), 아래 가드로 막는다.

### 1.4 "주도주" 의 조작적 정의

두 벌을 쓴다. 둘 다 D 시점까지의 정보만 쓴다.

1. **RS 상위 20%** — 비ETF · 20일 평균 거래대금 ≥ 50억 원 유니버스 안에서 120거래일 수익률 백분위 ≥ 80%. 이벤트 170건 중 **29건**. 유니버스 밖(거래대금 미달 또는 120일 이력 부족) 16건은 따로 묶는다.
2. **사용자 큐레이션** — `watchlist.json` 의 「주도주 공부」 폴더 46종목. 이벤트 **43건**.

MA20 아래에서 RS 상위 20% 인 종목은 "크게 올랐다가 조정 중인 주도주" 다.

### 1.5 결과 변수

| 이름 | 정의 |
|---|---|
| `fwd h` | close(D+h) / close(D) − 1, h ∈ {1, 3, 5, 10, 20} |
| `xs h` | `fwd h` − 같은 시장 지수의 같은 지평 수익률 |
| `fwd h (시가)` | close(D+h) / open(D+1) − 1 — 다음날 시가 진입 |
| MFE / MAE | D+1..D+10 최고가 / 최저가 대비 close(D) |
| **지지 유지** | min(low, D+1..D+10) ≥ low(D). 종가 기준 변형: min(close) ≥ low(D) |
| **저항 돌파** | max(high, D+1..D+10) > max(high, D−20..D−1) |
| 이평 상태 | close(D) vs SMA5/60/120; 정배열 = MA5>MA20>MA60 |
| 지수 캔들 | 지수 D 일 등락 부호 · 몸통(종가 vs 시가) |
| 지수 흐름 | 지수 close(D) vs 지수 MA20 · 직전 5일 지수 수익률 |

### 1.6 통계

효과는 항상 **이벤트 평균 − 기준군 평균**으로 보고하고, 95% 구간은 **종목 단위 클러스터 부트스트랩**(종목을 재표집, 2,000회)으로 잰다. 같은 종목의 이벤트·기준일이 상관돼 있으므로 이벤트 단위 부트스트랩은 구간을 과소평가한다. 조건부 표는 조건이 10개 이상이므로 **5% 유의는 우연으로도 한두 개 나온다** — 방향이 일관되고 구간이 좁은 것만 결론으로 올린다. 170건은 416건 사양의 40% 라 구간이 그만큼 넓다.

## 10. 한계

1. **캡처 유니버스가 큐레이션이다.** 377 종목은 사용자의 관심종목∪히트맵이고, 종목이 "재미있어진 뒤" 편입됐다. 결론은 그 유니버스 안에서만 성립한다.
2. **기간이 짧고 한 국면이다.** MA20 아래 이벤트의 58% 가 2026년 6~8월, KOSPI 가 8,476 에서 6,600 으로 되밀린 조정기다. 다른 국면에서 재검증 전까지 일반화하지 말 것.
3. **8월 절단.** 8월 이벤트 37건은 +20일 열에 없다.
4. **표본이 170건이다.** 조건부 표는 n 이 12~119 이고 10개 축 × 7개 지표라 명목 유의는 우연으로도 나온다. §7.1 의 주도주·비주도주 대비는 416건 사양과 방향이 같아 그나마 믿을 만하다.
5. **총잔량은 10단계 합이다.** KIS `total_bid_qty` (전체 호가장) 가 아니다.
6. **hogaplay 표본 밀도**에 결과가 묶여 있다. 소스를 섞지 않았고, hogaplay 가 빠진 날은 표본에서 사라졌다.
7. **지수 일봉은 사용자 dev 서버에서 1회 GET 한 스냅샷**이다. 독립 검증하지 않았다.
8. 수익률은 종가 기준이고 거래비용·호가 스프레드를 반영하지 않았다.
