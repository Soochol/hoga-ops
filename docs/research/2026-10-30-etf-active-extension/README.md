# ETF별 비교와 국내 주식 액티브 ETF 확장

2026-10-30 조사. 비교 단위는 **개별 ETF**다. 기존 패시브 38개에 국내 주식 액티브
81개를 추가해 **119개 비교 목록**을 만들었다. 이번 결과는 조사 산출물과 미리보기이며,
운영 앱의 화면·API·수집 스케줄에는 아직 배포하지 않았다.

## 정정: 415종목은 일반 일봉 저장소에 이미 있다

사용자 지적 후 실제 일반 일봉 저장소와 전 종목 수집 명단을 읽기 전용으로 대조했다.
**415종목 모두 수집 명단에 있으며, 원주가와 기존 수정주가도 모두 2026-10-29까지 저장돼 있다.**
각 일봉 파일에서 이 415종목의 행은 1,237,004개다. 최근 125거래일 중 상장 이후 기대
거래일 누락은 전 종목 0개다. 최신 120거래일의 유효 종가가 모두 있는 종목은 405개이고,
나머지 10개는 상장 후 120거래일 미만이다. 원주가·기존 수정주가 양쪽의 결과가 같다.

이전의 “415종목 가격 데이터 수집 필요” 설명은 부정확했다. `reuse_confirmed_prices.py`는
이번 연구에 고정한 **별도 v2 확정 수정주가 스냅샷의 observations**만 검사했다.
일반 일봉 parquet를 검색하지 않았고, 그 스냅샷에 관측이 없다는 사실을 일반 저장소의
가격 부재처럼 표현했다. 415종목은 해당 스냅샷의 observations에 없지만 일반 저장소에는 있다.

따라서 **415종목 전체를 처음부터 다시 수집해야 한다고 결론 내리지 않는다.** 기존 일봉의
출처·수정 기준·확정 근거를 우선 연결·검증하고, 필요한 근거나 호환되지 않는 구간만 보완한다.
일반 수정주가 파일이 존재하는 사실만으로 2026-10-30 기준의 별도 공급자 확정 수정 OHLC
계약까지 충족했다고 간주하지 않는다. 최근 원주가 자동 확인과 전체 과거 수정 OHLC 확인은 다르다.

초기 산출물과 당시 미리보기의 `price_capture_required`·`missing_price_codes`·“가격 수집 필요”는
**선택한 확정 계산 입력에 미연결**이라는 뜻으로 정정한다. 기존 검증 산출물의 재현을 위해 당시
키와 숫자는 보존하며, 실제 신규 수집 대상 목록으로 그대로 사용하면 안 된다.
[price-presence-audit.json](price-presence-audit.json)에 종목별 일봉 존재·최근 구간 검사와
파일 해시를 기록했다. `audit_price_presence.py`로 재현할 수 있고 운영 저장소는 변경하지 않는다.

[네이버 전체 ETF 목록](https://finance.naver.com/api/sise/etfItemList.nhn)을 새로 캡처했다.

이름에 액티브가 없는 상품을 독립적인 법적 분류 자료로 전수 식별한 결과는 아니다.

국내 후보 92개에서 커버드콜 7개, 은행채 1개, 리츠·부동산·인프라 전문 2개,
글로벌 주식 1개를 제외했다. 특히 `0060H0 TIGER 토탈월드스탁액티브`는 제공자의 국내
분류에 있어도 설명과 미국 편입 종목으로 해외 포트폴리오임을 확인해 제외했다.
최초 패시브 선정에서 이름만으로 제외했던 액티브 82개를 그대로 복구한 방식이 아니다.

[KoAct 바이오헬스케어](https://www.samsungactive.co.kr/etf/view.do?id=2ETFJ9)에서 확인했다.

## 편입 자료의 확인 범위

81개 모두 공개 구성 API의 기준일·행 수·주식 식별자를 검사했다.
액티브 주식 편입 행은 4,180개, 고유 주식은 815개, 기존 집합과의 교집합은 396개다.
공통 경로는 `https://stock.naver.com/api/domestic/detail/{code}/ETFComponent`이며,
설명 자료는 `https://m.stock.naver.com/api/stock/{code}/integration`이다.
URL·시각·인코딩·HTTP 상태·SHA-256을 [public-captures.json](public-captures.json)에 보존했다.
전체 목록 응답 원본은 EUC-KR이고 파생 JSON은 UTF-8이다.

**액티브 9개만 운용사 전체 원본과 종목 코드·CU 수량까지 일치 확인했다.**
KODEX 8개와 SOL 444200이다. 나머지 72개는 공통 구성 자료 검사까지 완료했으며,
운용사 전체 원본 대조는 남아 있다. [issuer-sample-comparison.json](issuer-sample-comparison.json) 참조.

KODEX 상세 API의 `pdf.list`는 상위 30개로 잘릴 수 있어 그것만으로 완전성을 판정하지 않았다.
[공식 상품 목록 API](https://m.samsungfund.com/api/v1/kodex/product.do?ordrColm=NAV&ordrSort=DESC&pageNo=1)의
11페이지에서 `stkTicker`와 `fId`를 연결하고 상세 응답의 실제 `pdfExcelDownloadUrl`을 사용했다.
전체 행 수·기준일을 확인한 뒤 코드와 수량을 비교했다. XLS 7개와 URL·해시는
[issuer-xls-captures.json](issuer-xls-captures.json)에 있다. SOL은
[공식 구성 API](https://www.soletf.com/api/fund/pdfList?fund_cd=210940&work_dt=20261030)를 대조했다.

제외 상품 `0199C0 ACE 고배당주Plus커버드콜액티브`는 공통 응답의 실제 25행과 선언된
23행이 불일치했다. 실패 기록을 보존하고 선택 대상에 포함하지 않았다.
공개 PDF 바스켓의 일치를 실제 운용 포트폴리오 전체의 인증으로 해석하지 않는다.

## 점수와 자산 범위

각 ETF의 직접 편입 주식마다 `종가 > SMA20/60/120`을 판단하고, 각 비율의 산술평균을
0–100점으로 표시한다. 주식과 기간은 동일 가중이며 편입 비중은 쓰지 않는다.
어느 기간에 필요한 종목·거래일이 빠지면 해당 비율은 `null`, 종합도 `null`이다.
미확보 종목을 분모에서 빼거나 0점으로 바꾸지 않는다. 같은 가격은 위에 있는 종목에 넣지 않는다.

주식은 캡처한 키움 마스터의 KOSPI/KOSDAQ `security_type=stock`과 양수 CU 수량으로 판단한다.
`KR7` ISIN 접두사만 강제하지 않는다. 예를 들어 `950260 인제니아테라퓨틱스(Reg.S)`는
마스터상 상장 주식이지만 120일 이력은 부족하다. 현금·파생상품·다른 ETF는 제외하며
다른 ETF를 재귀적으로 펼치지 않는다. 맥쿼리인프라·KB발해인프라·롯데리츠는 공식 자료를
근거로 비주식 펀드 예외를 기록했다. 출처는 policy의 `nonstock_overrides`에 있다.

액티브 5개에는 다른 비현금 자산이 있다. 예컨대 `442260 마이티 다이나믹퀀트액티브`의
다른 ETF 비중은 17.27%다. 따라서 이 점수는 직접 편입 주식의 가격 브레스이며,
전체 순자산의 추세나 ETF 수익률을 나타내지 않는다. 제외 자산은
[excluded-active-assets.json](excluded-active-assets.json)에 남겼다.

기존 38개 ETF 점수와 **477종목 전체 점수 15.6533892382949**는 재계산하여 보존했다.
액티브를 추가했다고 기존 전체 점수의 분모를 896개로 바꾸지 않았다.
확장 896개 전체 지수는 확정 입력 연결 전 계산하지 않았다. 과거 상·하위 색상 구간 작업은 보류 상태다.

## 재현과 검증

기존 확정 스냅샷 `300236397f6302d295ee094ca825d12dc63e2fa4dfdb88900f154ba7f30015f9`을
읽기 전용으로 해석하여 추가 4종목 `000020/000430/001530/013030`의 확정 가격 4,812행을
재사용했다. 별도 증권사 클라이언트·토큰·API 요청이나 운영 저장소 쓰기는 없었다.
확정 계산 입력에 아직 연결되지 않은 415종목은 [price-worklist.json](price-worklist.json)에 있다.
일반 일봉은 전부 존재하므로 이 파일을 그대로 신규 수집 대상으로 간주하지 않는다.
그중 10종목은 상장 후 거래일 수 자체가 120 미만이다. 상세는 확장 주식 목록에 있다.

저장소 루트에서 파생 결과를 재계산한다. 기존 확정 가격 산출물과 작업 환경의 의존성이 필요하다.

```sh
uv run python docs/research/2026-10-30-etf-active-extension/build_comparison.py
uv run python docs/research/2026-10-30-etf-active-extension/validate_comparison.py
uv run --extra dev ruff check docs/research/2026-10-30-etf-active-extension
```

`collect_active.py`는 공개 응답 해시를 검사해 재사용하고 새 요청 시작 사이 최소 0.5초를 둔다.
`verify_issuer_samples.py`는 XLS 판독용 `xlrd 2.0.2`가 필요하다. 이 조사에서는 시스템 Python의
설치를 사용했으며 프로젝트 의존성 파일은 변경하지 않았다. `reuse_confirmed_prices.py`는
고정 스냅샷 resolver가 있는 기본 체크아웃의 Python으로 해당 체크아웃에서 실행했다.
운영 서버를 시작하거나 실자격증명을 워크트리에 복사하지 않는다.

[validation.json](validation.json)에서 원본 해시·기존 ETF 코드 집합·119개 현재 점수의
별도 Python 산술 계산·257,516개 일자별 결측 마스크·8개 파생 출력의 바이트 동일 재생을
검증했다. Python 3.14.7, Polars 1.41.0이며 검사 스크립트 지문도 함께 보존했다.
검증 전 최신 `origin/main=6edace3090fdb9914675b38bd83f8482c506a070`을 fetch하여
현재 HEAD `5feb03bfea8f065af7a6e8565b14a72b03f39bfb` 대비 이 계산 모듈과
`pyproject.toml/uv.lock`에 차이가 없음을 확인했다. 운영 서버 배포 버전과 별개다.
