# 미국 개별주식 일봉·분봉 실시간 반영 검토

검토일: 2026-10-24 KST. 대상 코드: `815ba125269d047244cfe19773377e3db95c823a`.
아래 본문은 최초 조사 당시의 검토다. 후속 사용자 요청으로 새 수신 시험을 수행했다.
**최신 결론과 실측은 [실측 후 설계안](../plans/2026-10-24-us-stock-realtime-candles.md)을 우선한다.**
특히 동일 토큰의 국내·미국 소켓 충돌을 2회 확인했으므로 계정 소유권 분리가 필요하다.
서버 재시작이나 제품 적용은 하지 않았다.

## 결론

**키움 FE 실시간 시세를 진행 중 봉에 반영하고, 기존 REST를 초기 이력·누락 보정에
사용하는 안을 권장한다.** API 지원뿐 아니라 AAPL 실제 데이터 수신 근거가 있다.
현재 정지는 공급자의 지원 부재가 아니라 앱의 미국주식 실시간 경로 미연결 때문이다.
다만 기존 기록만으로 정확한 분봉 경계·전체 세션 OHLC·거래량 정합까지 검증됐다고
볼 수는 없다. 아래 실측 관문을 통과한 뒤 제품 적용을 확정한다.

## 확인된 사실과 근거의 범위

| 항목 | 확인 결과 | 한계 |
|---|---|---|
| 공식 실시간 경로 | 키움 FE, 미국 전용 WS 경로 | 국내 WS 경로에 FE만 추가하는 방식은 검증되지 않음 |
| AAPL 실수신 | 2026-10-22 약 180초 동안 634개 REAL 데이터 레코드 | 개별 거래소 체결 634건이라는 뜻은 아님 |
| 가격 변화 | 보존된 첫/마지막 표본의 가격이 다름 | 거래소 대비 지연 시간은 측정하지 않음 |
| 일중 OHLC | 공식 FE 명세에 현재가·시고저·거래일·현지시각 필드가 있음 | 기존 실측 요약은 시고저·거래량 원본을 보존하지 않아 값의 정합은 미확인 |
| 현재 일봉 | 서버가 뉴욕 오늘을 제외, FE는 최신 범위 5분 재조회 | 조회 주기만 줄여도 오늘 봉은 생기지 않음 |
| 현재 분봉 | 키움 원본 7개 주기, 최근 창 60초 갱신 | 현재 차트에는 FE 오버레이 없음 |

실수신 근거는 [기존 지수 조사 원본](2026-10-22-us-index-live-probe.json)의
`kiwoom_ws` 대조군이다. 시작은 `2026-10-22T14:59:19.061792Z`, 종료는
`15:02:22.771105Z`이며 NASDAQ AAPL만 634개 레코드가 집계됐다.
첫 보존 가격은 344.4050, 마지막은 344.5300이다. 같은 실험의 미국 지수 데이터
0건과 미국 개별주식 수신 성공을 구분해야 한다. 등록 ACK만으로 성공을 판정할 수 없다.

주의할 점은 AAPL 표본의 두 시각 필드가 모두 `105900`, 마지막은 `110200`이었다는
것이다. 가격은 변했지만 초가 00으로 표시된다. 이는 고정 지연의 증거도, 초 단위
개별 체결 시각의 증거도 아니다. 분 경계 식별에 쓸 수 있는지 REST 대조가 필요하다.

## 최신 공식 자료

- [키움 FE 공식 예제](https://github.com/Kiwoom-Securities/Kiwoom-REST-API/blob/953e5dbff123f437ab4d11a78a95191a685eb51f/examples/미국주식/실시간시세/subscribe_overseas_trade_price_async.py):
  미국 전용 `/api/us/websocket`을 사용한다. 등록은 거래소와 티커를 함께 보내며,
  응답에서도 거래소를 보존해야 한다. 국내 문자열 종목코드 등록과 구조가 다르다.
- [키움 공식 명세](https://github.com/Kiwoom-Securities/Kiwoom-REST-API/blob/953e5dbff123f437ab4d11a78a95191a685eb51f/kiwoom/_data/kiwoom_api_spec.json):
  개인 고객에게 나스닥 토탈뷰 무료 실시간 시세를 제공한다고 안내한다. 유료 시세
  가입 여부와 별개로 API는 무료 시세 기준이다. 이를 미국 전 거래소 통합 체결과
  같은 범위라고 해석하거나 REST 거래량과 무조건 합산해서는 안 된다.
- [공식 이용안내](https://openapi2.kiwoom.com/intro?dummyVal=0): 계좌·토큰별 세션과
  실시간 등록 상한, 미국 조회 유량 제한이 있다. 국내/미국 소켓의 동시 사용 시 세션
  제한 적용 범위는 별도 확인이 필요하다. 경로가 다르다는 사실만으로 독립 한도를 가정하지 않는다.

공식 저장소 revision은 `953e5dbff123f437ab4d11a78a95191a685eb51f`이며,
명세 SHA256은 `42a7b3912c9d9588c83bdc2db7779c8d2e038703a2b5562e54ef46ae905cba79`다.
이번 조사에서 공개 명세·예제만 다운로드했고 예제는 실행하지 않았다.

   미국 야간·한국 토요일 새벽을 이 게이트로 처리하면 정상 시세가 막힌다.
5. [useLiveChartData.ts](../../frontend/src/live/useLiveChartData.ts)의 미국 bundle은 REST만
   소비하며 거래량을 표시용으로 0 처리한다. 미국 시세 구독·오버레이를 연결하되
   이번 가격 갱신 작업을 거래량 패널 활성화 완료로 보고하지 않는다.

## 권장 구성

### 미국 전용 수신 수명과 화면 전달

- 미국 차트에서 열람 중인 고유 `(exchange, symbol)`마다 하나의 FE 구독을 공유한다.
  일봉·분봉 창, 핀, 링크 그룹, 복수 브라우저는 참조만 늘린다. 마지막 참조 해제 후
  짧은 유예를 두고 해제한다. 관심목록 전체를 새 상시 수집 대상으로 삼지 않는다.
- 미국 전용 소켓 관리자와 계정별 연결 소유권을 둔다. 국내/미국 동시 접속이 가능한지
  확인한 후 계정 배정을 확정한다. 같은 앱키의 임의 두 번째 연결이나 토큰 재발급으로
  운영 연결을 시험하지 않는다. 별도 계정이 필요하다면 빈 계정을 자동 가정하지 않는다.
- 한국 거래일·국내 장시간 게이트에서 독립시킨다. 초기에는 실제 열람 수요에 따라
  연결하고, 휴일·장외 무수신을 오류로 단정하지 않는다. 장구분과 실제 수신 상태를
  별도로 관리한다. 정규장/프리/애프터/야간의 지원 범위는 실측 결과로 제한한다.
- 서버에서 관측 중 OHLC를 누적하고 기존 브라우저 이벤트 경로로 묶어 전달한다.
  초기 권장 화면 목표는 수신 후 약 1초 이내 반영이다. 묶음 전송 전에 고저를 누적해
  중간 가격의 극값을 보존한다. 이 목표는 거래소 대비 1초 지연 보장이 아니다.
- 연결 세대·수신 순서·관측 시각·공급자 시각·마지막 정상값을 구분한다. 재연결 후에는
  기존 값을 유지하면서 REST 보정을 요청한다. 등록 성공과 실제 수신 성공도 구분한다.

### 일봉

- 완료 일봉 이력 위에 별도 진행 중 당일 봉을 덧씌운다. 장중 늦게 앱을 열어도
  전체 당일 시고저를 보여주려면 FE의 일중 시고저 또는 당일 REST 일봉을 검증해서
  기준으로 사용한다. 최근 800분이나 연결 이후 가격만으로 전체 일봉을 만들지 않는다.
- 날짜와 세션 범위가 일치하고 `low <= open/close <= high` 등 검사를 통과한 봉만
  채택한다. 0·빈 시고저는 시가/고저로 쓰지 않는다. 검증된 당일 기준 봉이 없으면
  이전 완료 일봉은 유지하며 현재가만 별도로 표시한다.
- 진행 중 봉을 완료 캐시·완료 조회 구간에 넣지 않는다. 뉴욕 거래일이 바뀌었다는
  사실만으로 야간 포함 세션의 완료를 단정하지 않는다. 완료 REST 봉과 동일 날짜의
  관계 및 장후 수정 반영은 세션 대조 결과로 결정한다.
- 과거 전용 조회에는 최신 관측을 섞지 않는다. W/M도 확장할 경우 검증된 완료 일봉과
  같은 임시 당일 봉을 공유하되 미조회 날짜를 완전한 주·월로 채우지 않는다.

### 분봉

- 원본 REST 1/3/5/10/15/30/60분봉을 기준으로 유지하고 진행 중 버킷에 더 새로운
  가격 관측의 고저종만 적용한다. 원본 시가·거래량은 보존한다. 새 관측 버킷은
  관측 가격으로만 임시 표시하고 누락된 분을 채우지 않는다.
- 버킷 시작/끝과 3·5·60분 경계를 원본 REST와 대조한다. 국내 09시 또는 지수
  09:30 정렬을 그대로 가져오거나 현지시각을 무조건 UTC 나눗셈으로 버킷화하지 않는다.
- 공급자 영업일, 실제 뉴욕 달력일, UTC epoch, KST 표시일을 분리한다. 기존 분봉의
  24~47시 표기와 DST 처리를 보존하고 FE에도 같은 표기가 오는지는 별도 검증한다.
- 늦게 도착한 REST 응답이 최신 FE 종가를 덮지 않도록 요청 시작 시점/관측 순서를
  보존해 다시 적용한다. 정정된 과거 고저는 이후 REST가 보정할 수 있게 한다.
- 최초/과거 조회와 별도로 최근 보정만 저빈도로 조회한다. 60초 보정을 출발점으로
  하고 재연결에는 즉시 합류 조회한다. 최신 갱신은 이미 붙인 과거 페이지와 커서를
  유지한다. FE 수량의 단순 합 또는 일 누적량 차이를 분봉 거래량에 더하지 않는다.

## 대안 검토

| 방식 | 판단 |
|---|---|
| 키움 FE + 키움 REST 보정 | 우선 권장. 개별주식 실수신 근거가 있고 기존 공급자 정책과 맞음 |
| 키움 REST 최근 1페이지 빠른 조회 | WS 적용 전 중간 개선 후보. 장중 실제 값 변화·다중 창 예산 실측 필요. 실시간 스트리밍과 구분 |
| 현재 최대 8페이지를 매 2초 재조회 | 비권장. 동일 이력 반복과 미국 공유 예산 초과 |
| KIS HDFSCNT0로 대체 | 기존 AAPL 프레임 수신 근거는 있으나 공급자 정책 예외 확대와 기준 시세 대조가 필요해 우선 채택하지 않음 |

`usa20100` 현재가 조회도 후보지만 원본에 영업일/체결시각 필드가 없고 공식 예제의
당일 시고저가 빈 문자열이므로, 이것 하나로 당일 봉을 날짜까지 확정하는 안은 부족하다.

## 구현 전에 통과할 실측 관문

| 검증 | 확인할 내용 | 통과 기준 |
|---|---|---|
| 국내/미국 공존 | 같은 계정의 두 경로 허용 범위와 실제 등록 한도 | 운영 세션을 건드리지 않는 시험 환경에서 공존 또는 분리 배정 근거 확보 |
| 거래소/티커 | NASDAQ AAPL·NVDA, NYSE KO·BRKb, AMEX 마스터의 유효 종목 | 거래소·대소문자 보존, 실제 가격 수신, 잘못된 종목 ACK와 구분 |
| 분 경계 | FE 전체 필드 + 수신 시각, 동시 REST 1/3/5/60분 | 적어도 여러 분 전환과 60분 경계에서 같은 버킷과 가격을 식별 |
| 당일 봉 | 늦게 연결한 FE 일중 OHLC와 당일 REST 일봉 | 가격 기준·세션 범위가 일치하고 값이 유효함 |
| 장외/날짜 | 프리→정규→애프터·야간, 뉴욕 자정·영업일 경계 | 장구분 의미, 누적량 리셋, 일봉 귀속일 확인. 미관측 구간은 미확인 유지 |
| 재연결 | 누락·중복·동일 분 역순·REST 응답 중 최신 수신 | 최신 가격 역행 방지, REST 보정, 수량 중복 합산 없음 |

새 실측은 prod 수신 소유권 안의 진단 기능 또는 기존 연결과 겹치지 않는 자격증명으로
수행한다. 기존 기록에서 시험한 계정이 현재도 유휴라고 가정하지 않는다.
이번 조사에서는 새 실측을 수행하지 않았으므로 위 관문은 미완료다.

구현 후에는 고정 표본/가상 시계로 DST·KST 자정·24시 이상 표기·세대 교체·같은 분
복수 가격·역순·잘못된 OHLC·거래소 혼입·당일/과거 격리·누락 보정·캐시 상한을 검사한다.
BE/FE wire 계약과 다중 창 구독 공유, 일봉 및 각 분봉 페인트, 과거 스크롤 보존을
무자격 E2E로 검증한다. 수신 후 화면 지연과 거래소 대비 지연의 검증 결과는 구분한다.

## 정책과 작업 순서

[ADR-0136](../adr/0136-kis-removal-kiwoom-full-replacement.md)의 미국 개별주식
60초 분봉·완료 일봉 유지 결정 및 신규 WS를 추가하지 않는 범위를 **개정하는 제안**이다.
이번 검토에서는 accepted ADR과 도메인 정의를 변경하지 않았다.
키움 우선은 ADR-0118의 WS 특화와 맞는다. 국내 KRX 저장 한정 ADR-0125를 해외
영속 저장 허가로 확장하지 않고, 미국 관측은 우선 표시용 메모리 범위로 둔다.

작업 순서는 ① 세션 공존 및 분/일봉 의미 실측 ② 미국 전용 수신·참조 관리
③ 진행 중 일봉·분봉 오버레이와 REST 보정 ④ wire/브라우저 검증 및 ADR 개정이다.
완료 판정은 최신 가격 반영뿐 아니라 당일 봉 생성, 새 분 전환, 뒤늦은 조회의
고저 보정, 국내 시세 공존, 과거 범위 보존을 함께 확인하는 것이다.
