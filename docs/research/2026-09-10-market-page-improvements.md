## 우선순위

- 영향: 시장 전체 하루 흐름을 보는 카드에서 오전 수급과 오후 전환을 비교할 수 없다. 표본 범위는 작은 글씨로 안내하므로 당일 전체 차트로 오해하기 쉽다.
- 제안: API 연속 조회 또는 장중 저장 자료를 이용해 세션 전체를 제공한다. 지원 전에는 제목 가까이에 `최근 100개 · 오전 구간 없음`을 명확히 표시한다. 누락 구간을 보간하지 않는다.
- 후속 확인: 서버가 실제로 보유한 범위와 공급사 연속 조회 지원 여부. 이번 조사는 UI 관찰이므로 제한 원인을 서버로 단정하지 않는다.
- 완료 기준: 오전 표본부터 최신 표본까지 탐색하거나, 제한된 관측 범위를 제목에서 즉시 알 수 있다.

### 2. 투자자 수급 카드의 시간축 잘림 — 높음

- 관찰: 당일 차트의 하단 시간축 글자가 잘린다. 본문 clientHeight 272px, scrollHeight 281px로 9px 초과했다. 당일→일별→당일로 다시 전환해도 재현했다. 대화에 전체 화면과 카드 확대 스크린샷을 첨부했다.
- 영향: 최신 데이터와 시간축을 함께 보기 위해 카드 내부를 추가로 스크롤해야 한다. 페이지 스크롤과 카드 스크롤이 겹친다.
- 제안: 상태·선택기·차트의 높이를 함께 계산하고, 기본 상태에서는 차트와 시간축을 모두 노출한다. 수집 이력을 펼칠 때만 상세 영역에 별도 공간을 준다.
- 완료 기준: 초기 진입과 당일/일별/상품 전환 후 시간축이 내부 스크롤 없이 보인다.

### 3. 투자자 수급 차트의 시점별 숫자 탐색 — 중간

- 관찰: 현재는 최신 개인·외국인·기관 수치와 선만 제공한다. 투자자 카드의 DOM에는 선택기 그룹 두 개만 있고 차트 상세 탐색 그룹이나 키보드 포커스 대상이 없다. 프로그램·주변 자금·거래대금 차트에는 `좌우 방향키로 표본 탐색, Home/End` 안내가 있다.
- 영향: 급격한 변화가 언제 발생했고 당시 세 주체가 각각 얼마였는지 정확하게 확인하기 어렵다.
- 제안: 공통 상세 탐색 기능을 투자자 차트에도 적용한다. 시각·세 주체 누적값을 함께 표시하고, 공백에서는 실제 표본이 없다는 안내를 준다. 다음 단계로 5분/30분 변화량을 고려할 수 있다.
- 완료 기준: 키보드 및 포인터로 동일한 표본의 시각과 값을 확인한다. 공백을 실제 관측값처럼 표시하지 않는다.

### 4. 업종 온도의 분류와 노출 범위 — 중간

- 관찰: 상승순에서 `비금속`, `전기/전자`와 함께 `F-KOSDAQ150`, `KOSDAQ 150`, `KOSDAQ 100`, `코스닥 중견기업`, `코스피고배당50`이 표시된다. 기본순과 상승순을 왕복해도 재현했다. 기본순은 시장별 12개만 보여 전체 분류를 한 번에 확인하기 어렵다.
- 영향: 업종·규모·대표/스타일 지수가 한 순위에 섞여 업종 강약을 비교하기 어렵다.
- 제안: `업종 / 규모·대표지수`를 나누거나 유형 필터를 제공하고, 표시 개수·전체 보기 기능을 둔다. 분류 기준은 공식 메타데이터를 확인해 정한다.
- 완료 기준: 업종만 비교할 수 있고, 현재 목록이 전체인지 일부인지 명확하다.

### 5. 기준일·최신성·세션 안내 통일 — 중간

- 관찰: 지수·프로그램 당일·연속 매매·업종 온도·랭킹은 `기준일 미제공`과 조회 시각을 함께 표시한다. 투자자 수급에는 마지막 정상 수신, 주변 자금에는 09/08 기준, 프로그램 일별에는 오늘 잠정이 표시된다. VKOSPI에는 별도의 기준 시각이 보이지 않는다.
- 영향: 사용자가 각 카드의 오래됨과 정상적인 공시 지연을 같은 기준으로 판단하기 어렵다. 다만 기준일을 모른다고 명시하는 현재 동작 자체를 잘못된 데이터로 판정하지는 않는다.

- 완료 기준: 오래된 데이터·정상 지연·미확인·장 종료를 구별한다. 모든 카드를 무조건 10초마다 조회하는 방식은 피한다.

## 구현 결과

- 프로그램 당일 조회는 기존 공급사 커서를 사용해 최대 12페이지(시장별)까지 수집한다. 모든 페이지가 기존 background 요청 제한을 통과하며 20초 캐시를 유지한다. 중복 시각은 최신 페이지 값을 유지한다. API의 `truncated`에 시장별 상한 도달 여부를 싣고 화면에서 제공 시간 범위·상한·장 초반 미포함을 표시한다. 프로그램 일별은 기존 한 페이지를 유지한다.

- 투자자 현물·파생 차트에 공통 포인터/방향키 탐색을 연결했다. 시각은 초까지 표시하고 파생 계약/억원 단위를 보존한다. 확인된 실패 구간 위의 포인터에는 인접 표본을 대신 보여주지 않고 관측값 없음으로 안내한다.

실제 벤더를 새로 호출하거나 사용자 서버를 재시작하지 않고, 무자격 로컬 테스트로 검증한다. 프로그램 연속 조회의 실제 운영 호출량과 공급 범위는 적용 후 관찰 대상이다. 최신성 표시 통일은 알려진 기준일·조회 시각·브라우저 API 실패에 한정하며, 공급사가 제공하지 않은 수신 시각이나 카드별 정상 지연 임계값을 임의로 만들지 않았다.
