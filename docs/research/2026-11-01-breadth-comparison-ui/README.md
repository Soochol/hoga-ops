# ETF 비교 그래프와 회복 지속성 정렬

사용자 승인에 따라 `/breadth`의 선택 ETF 비교를 선택 수와 관계없이 하나의 0–100점
그래프로 표시한다. 계산 가능한 42개를 모두 선택할 수 있다. 기존 기간·커서와 전체
477종목 비교선 선택을 유지한다. 구성·가격·점수 데이터와 계산식은 변경하지 않았다.

- ETF 코드순 전체 계산 가능 목록에서 색/선 모양을 배정한다. 선택 해제·재선택과
  표 정렬로 바뀌지 않는다. 기존 테마의 7개 MA 색과 6개 선 모양으로 42개를 구분한다.
- 범례의 버튼 또는 표 행에 호버하면 해당 선을 강조한다. 범례와 ETF 이름 버튼의
  키보드 포커스도 같은 동작이며 강조한 선은 다른 선 위에 그린다.
- 회복 지속성의 6개 헤더 모두 `오름차순 → 내림차순 → 기본`으로 순환한다.
  다른 열은 오름차순으로 시작한다. 기본은 기존 연속 개선 내림차순이다.
- 원자료의 숫자를 정렬하고, 이름은 한국어 순서로 비교한다. 동점은 ETF 코드순,
  결측은 양방향 모두 마지막이다. `최소 N일` 표시는 그대로 보존한다.
- 기존 정렬 드롭다운과 4개 이상일 때의 별도 그래프를 제거했다.

검증: 타입 검사, 단위 테스트 9개, 브라우저 테스트 5개 및 최종 강조 화면 캡처 테스트.
브라우저에서는 42개 시리즈와 기준선이 한 SVG에 있는지, 기준선 OFF, 선택 저장·전체
해제, 6개 열의 마우스/Enter/Space 정렬 순환, 색/선 모양 유지, 강조/해제,
1440·960·600px의 두 테마에서 페이지 콘텐츠 넘침을 확인했다.
ESLint 오류 0개이며 기존 종목 기여 목록 초기화 effect 경고 1개는 유지했다.

`verification.json`에 기준 커밋·입력 지문·명령·결과를 기록했다.
`comparison.png`는 실제 프로젝트의 전체 ETF 비교 그래프 캡처다.
