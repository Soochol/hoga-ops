## 보고 기한과 API 공개 시각은 별개다

[금투협 시행세칙 제56조](https://law.kofia.or.kr/service/law/lawFullScreenContent.do?historySeq=1815&seq=137)는
신용공여 상황을 익일 12시까지 제출하도록 정한다. 이 기한은 증권사의 제출 기한이며,
FreeSIS 또는 공공데이터 API의 반영 완료 시각을 보장하지 않는다.
기존 8월 5일의 T+2 실측도 고정 공개 주기를 뜻하지 않는다.

## 갱신 정책 변경

- 서버 캐시를 6시간에서 **30초**로 줄이고 여러 화면의 요청을 단일비행으로 공유한다.
- 화면은 장중·장외 구분 없이 **30초마다** 확인한다. 숨긴 탭의 폴링은 멈추고,
  자료가 오래됐으면 포커스 복귀·네트워크 재연결 시 다시 확인한다.
- API가 새 날짜를 반환하면 기존 조회 기간을 유지하면서 최신 잔고·차트·기간 증감을 갱신한다.
  화면 표시 중 정상 통신에서는 캐시와 화면 확인 시점에 따라 **최대 약 1분 + 요청 처리 시간**이
  걸릴 수 있다. API 미반영·통신 장애 상태에서는 이 시간을 보장하지 않는다.
- 빈 응답도 30초 동안 캐시해 실패 요청 폭주를 막는다. 일부 계열 실패·이전 날짜 응답은
  이미 관측한 값을 지우지 않으며, 새 날짜의 미관측 값을 과거 값으로 채우지 않는다.
  보존 이력은 최근 200일 행으로 제한한다.
- 관측된 `basDt`를 유지하며 22일 자료를 23일 자료로 날짜 이동하거나 추정 생성하지 않는다.
- 이 변경은 공공데이터 API가 제공하는 자료의 반영 지연을 줄인다. FreeSIS의 자료를
  별도로 수집하는 대체 소스는 추가하지 않는다.
