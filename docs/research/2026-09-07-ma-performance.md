# 이동평균선 갱신 비용 개선

기존 일반 SMA 및 일봉 SMA 수식은 유지한다. 불변 Candle 참조와 축 참조로 좌표를 재사용하고, 일반 SMA는 처음 변경된 봉부터 원본과 같은 순서로 이동합을 이어 계산한다. 과거 수정·prepend·기간/소스 변경도 정확히 반영한다. 일봉 SMA는 날짜별 값이 변경된 날짜의 점을 다시 만들므로 오늘 값이 바뀌면 오늘 분봉 전체가 바뀐다.

차트 반영은 기존 syncSeriesData를 사용한다. 과거 prefix가 동일한 마지막 점 변경/단일 append만 update이며, 다른 변경은 setData다. 새 차트는 독립적으로 전체 데이터를 받는다.

## 측정

합성 데이터, 세션당 390봉, 6개 선(5/10/20/60/120/240), 워밍업 2회 후 11회 중앙값. 매번 마지막 Candle을 새 객체로 바꾼다. 원본과 변경 후 출력의 정확한 동등성을 확인했다. React·Canvas·차트 API 비용은 제외한다.

| 거래일 | 봉 수 | 일반 이전→이후(ms) | 일봉 이전→이후(ms) |
|---|---:|---:|---:|
| 5 | 1,950 | 0.896 → 0.136 | 0.888 → 0.608 |
| 30 | 11,700 | 4.866 → 0.715 | 5.252 → 1.710 |
| 90 | 35,100 | 18.227 → 2.377 | 17.658 → 5.796 |

재현 코드는 인접 benchmark.test.ts.txt, 원시 결과는 JSON에 보존했다. 캐시는 불변 입력을 전제로 하며 전체 prefix 참조 비교·출력 배열 복사 비용은 여전히 O(N)이다. 일봉 당일 전체 변경은 setData가 필요하므로 이 수치를 화면 전체 가속률로 해석하면 안 된다.

## 실제 차트 확인

별도 Vite(5189)에서 실제 React MovingAverageOverlay와 lightweight-charts를 사용한 합성 30거래일·6개 선을 확인했다. 최초 setData 6회 이후 마지막 봉 종가 +10 변경은 update 6회, 추가 setData 0회였다. 각 마지막 값은 109/105.5/105/104.66666666666667/104.58333333333333/104.54166666666667로 기대 SMA와 일치했고 콘솔 오류는 없었다. 임시 페이지는 제거했다. 일봉 MA의 당일 전체 점 변경 및 과거 수정·prepend는 회귀 테스트로 검증한다.
