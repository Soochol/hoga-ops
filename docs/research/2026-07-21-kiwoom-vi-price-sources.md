# 키움 VI 가격 소스 조사 + `1h` legend 실측 확정 (2026-07-21)

10호가 요약 패널의 상승VI/하강VI 행에 쓸 "VI 가격"을 키움 API/WS 로 받아올 수
있는지 조사. 결론: **예상 발동가는 어디에도 없고(계산 필수), 발동 정보·기준가는
WS `1h` + REST `ka10054` 로 수신 가능**. 부수 성과로 `1h` 의 미해독 legend 3종을
실이벤트 60건(2026-07-21 정규장, PR #774 채록)으로 전건 무모순 확정했다.

## 1. "VI 예상 발동가"를 주는 API/FID 는 없다

- REST 전 문서(시세·종목정보·순위정보·차트) 및 실시간시세 전 타입의 FID 를 훑어도
  "예상 VI가" 성격의 필드는 부재. `0D` 의 예상체결가(23/24)와는 다른 개념.
- HTS 가 호가창에 보여주는 예상 발동가도 자체 계산이다:
  **정적VI 예상가 = 정적기준가 × (1±0.10) → 호가단위 반올림**.
  정적기준가 = 당일 시가(시가 전엔 기준가), VI 발동 후엔 해당 단일가 체결가로 갱신.
- 우리 보유 입력값: 시가 = 0B FID 16(실시간 수신 중) · 기준가 = ka10001
  `base_pric`(#772 배선). **발동 후 기준가 갱신값만** 아래 `1h`/`ka10054` 필요.

## 2. REST `ka10054` 변동성완화장치발동종목요청 — 실호출 확정

- URL `/api/dostk/stkinfo`, `api-id: ka10054`. **문서 미기재 필수 파라미터
  `motn_drc`(발동방향) 존재** — 빠뜨리면 rc=2 (1511). `stex_tp` 도 필요.
- 실호출 파라미터(2026-07-21 성공):
  `mrkt_tp=000 · bf_mkrt_tp=0 · motn_tp=0 · motn_drc=0 · skip_stk=000000000 ·
  trde_qty_tp/min/max=0 · trde_prica_tp/min/max=0 · stex_tp=1`
- 응답 `motn_stk[]` 필드(실측): `stk_cd·stk_nm·acc_trde_qty·motn_pric(발동가)·
  trde_cntr_proc_time(발동시각)·virelis_time(해제시각)·viaplc_tp(적용구분 한글:
  정적/동적/동적+정적)·static_stdpc/dynm_stdpc(정적/동적 기준가)·
  static_dispty_rt/dynm_dispty_rt(괴리율, 부호=방향)·open_pric_pre_flu_rt·
  vimotn_cnt(발동횟수)·stex_tp`
- 성격: **당일 발동 이력 조회**(폴링 가능). 미발동 종목의 예상가는 없다.
- `motn_pric` 은 임계가가 아니라 **발동을 일으킨 실체결가**다(괴리율이 ±10% 를
  넘는 값으로 관측됨 — 예: +10.60%).

## 3. WS `1h` legend — 실이벤트 60건으로 확정

채록: `data/research/kiwoom_vi_events/YYYYMMDD.jsonl`(#774). 판정 근거는 이벤트
자체에 내재: 발동가(1221) vs 기준가(1236/1237) 대소·괴리율(1238/1239) 부호·
그리고 `1279` 복합 문자열. 60건 전건 무모순.

| FID | 의미 | legend (실측) |
|---|---|---|
| **9069** | 발동방향구분 | **1=상승, 2=하락** |
| **9068** | VI발동구분 | **1=정적, 2=동적, 3=동적+정적** (1225 한글값·ka10054 `motn_tp` 문서 legend 와 3중 일치) |
| **9075** | 장전구분 | **1=정규시장** 관측. 2=시간외단일가 추정(ka10054 `bf_mkrt_tp` legend 대응, 미관측) |
| **1279** | (문서 "Extra Item") | **부호+적용구분 복합 문자열**: `+정적`/`-동적`/`+동적+정적` … 부호=방향의 이중 확인 소스 |

소비 시 주의:

- **_AL 중복**: 시장 전체 구독이라 같은 이벤트가 `109670_AL`(통합)과 `109670`(KRX)
  두 row 로 온다 — dedup 또는 접미 필터 필수.
- **해제 = 같은 프레임 재발화**: 발동 시 1224=`000000`, 해제 시 1224 에 시각이
  채워진 동일 이벤트가 다시 온다.
- 동적VI 이벤트는 1236(정적기준)=0, 정적VI 는 1237(동적기준)=0 — 0 은 "해당 없음".
- 1489 = 발동가 등락률(전일 대비, 부호 있음). 발동 방향과 부호가 다를 수 있다
  (예: 하락 동적VI 인데 전일 대비 +5.16%).

교차 검증: 같은 이벤트(씨싸이트 114359 정적 +10.60%)가 ka10054 응답과 WS 채록에
동일하게 나타남 — 두 소스의 시각·가격·구분 필드가 정합.

## 4. 후속 배선 설계 함의

- 예상 발동가(평시) = 프론트 계산: `기준가(dayOpen ?? base_price) × 1.1/0.9` +
  호가단위 반올림 (상한가 검산과 동일 산술 — ka10001 `upl_pric` = base×1.3 틱
  반올림이 실측 일치했던 것과 같은 규칙).
- 발동 중 강조·기준가 갱신 = `1h` 소비(legend 확정됨). 관심종목만 필터(9001),
  _AL dedup, 해제 프레임으로 강조 해제.
