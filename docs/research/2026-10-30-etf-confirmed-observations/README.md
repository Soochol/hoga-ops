# ETF 편입 주식 477종목의 확정 수정주가 확보

2026년 10월 30일, 선정 ETF의 편입 주식 **477종목 전부**에 대해 키움 공급자 확정 관측을 실제 수집하고 수정 기준일을 **2026년 10월 30일**로 정렬했다. 가격 구간은 **4월 24일부터 10월 29일까지 125거래일**이다. 당일 진행 중인 10월 30일 봉은 계산 데이터에 넣지 않았다.

477종목 모두 20·60·120일 이동평균과 120일선의 5거래일 전 비교에 필요한 가격을 갖췄다. 기존 이동평균 엔진과 독립 계산의 종목 집합도 전부 일치했다. 기존 원주가·거래량 충돌은 자동으로 덮어쓰지 않고 별도 검토 대상으로 유지했다.

각 종목은 원주가와 수정 가격을 두 번 독립 조회했다. 첫 수신 종료 후 최소 2초를 두었고, 요청 구간의 OHLCV·금액·가격 이벤트·파싱 위반이 일치하는지 기존 `historical_recheck_v1` 계약으로 검증했다. 원응답과 수신 시작·종료 시각은 운영 `series_v2`의 불변 관측 객체에 남아 있다. [stocks.json](stocks.json)에 후보·관측 객체 ID, 두 수신 시각, 간격, 기준일, 기간별 준비 상태를 기록했다.

이 자료는 `kiwoom:ka10081`, venue `KRX`, 세션 `provider_daily_all_sessions`, 종가 `provider_last_price` 계약이다. **15:30 정규장 종가만을 뜻하지 않는다.** 해당 시점에 일치한 공급자 과거 관측이며 미래 공급자 정정이 없다는 보증이나 독립 주식 수 이력 인증은 아니다. [프로젝트 확정 관측 계약](../../plans/2026-10-24-screener-confirmed-recovery.md)을 적용했다.

## 기존 검증 이력 보존

기존 승인 기록은 이전 근거를 새 확정 관측에 다시 대조하고, 승인된 행 전체가 이전과 정확히 같을 때만 새 관측에 연결했다. 24종목 중 하나라도 근거 검증에서 거부되거나 선택값·날짜가 달라지면 전체 공개를 중단하는 방식이다. 검증된 묶음은 한 번의 manifest CAS로 공개했다. 이전 관측·판정 객체는 유지했다.

[review-preservation.json](review-preservation.json)은 적용 요약, [review-preflight.json](review-preflight.json)은 개별 재검증 결과다. [existing-history-preservation.json](existing-history-preservation.json)에서 기존 25종목의 가격 날짜와 승인 정정 날짜가 줄지 않았음을 확인할 수 있다. 미확인이었던 기존 ETF 관측 2개를 확정 관측으로 승격하지 않았다.

## 이동평균 계산 검증

고정 스냅샷과 기존 `calendar_evaluate` 엔진으로 종가가 단순이평선 이상인 종목을 찾고, 같은 확정 종가를 유리수로 직접 계산한 결과와 대조했다. 진행 중 봉은 제외했다.

| 조건 | 엔진 일치 종목 | 독립 계산 일치 종목 | 계산 불가 |
|---|---:|---:|---:|
| 종가 ≥ SMA20 | 72 | 72 | 0 |
| 종가 ≥ SMA60 | 80 | 80 | 0 |
| 종가 ≥ SMA120 | 75 | 75 | 0 |

건수뿐 아니라 실제 종목 Code 집합이 모두 같았다. [ma-verification.json](ma-verification.json)에 요청 기준과 종목 집합을 보존했다. 이 표는 거래정지 종목 등의 제외 정책을 적용하기 전, 편입 집합 477개 전체를 사용한 계산 검증이다. 완성된 공탐 점수로 해석하지 않는다.

## 남겨 둔 원주가 충돌

요청한 최근 125거래일에서 **474종목·5,180개 종목 날짜**에는 미해결 원주가 OHLCV 충돌이 남아 있다. 새로운 공급자 관측을 얻었다는 이유만으로 기존 원본을 정정 승인하지 않았다. 새 수정주가 가격의 확인 계약은 원주가 수량 분쟁과 독립적이므로, 위 이동평균 계산에는 부족 사유가 발생하지 않았다.

복구 작업의 원래 상태는 `partial`이다. 이는 원주가 충돌까지 포함한 작업 상태이며, **477종목의 확정 수정주가 확보 여부는 모두 준비 완료**다. 독립 주식 수 이력의 검증 완료도 주장하지 않는다.

[raw-conflicts.json](raw-conflicts.json)은 공급자 원주가 후보와 불변 baseline을 직접 비교한 5,220개 행을 담는다. 이 중에는 기존 근거로 승인되어 현재 해소된 40개도 포함돼 있어, 미해결 충돌 5,180개와 구분한다. 현재 미해결 날짜는 [stocks.json](stocks.json)의 `raw_conflict_dates`를 기준으로 한다.

`verify_observations.py --snapshot-id <위 ID>`는 원본을 읽고 이 연구 디렉터리에만 검사 결과를 쓴다. `preserve_reviews.py`의 기본 동작은 사전 검사이며, `--apply`는 기존 승인 기록만 완전히 같은 값으로 재검증한 경우 한 번에 연결하는 운영 명령이다. 같은 작업을 반복 실행해 신규 정정을 추가하는 도구로 쓰지 않는다.

운영의 기존 parquet·factor·저장 조건·발생 제외 파일은 실행 전후 내용 해시가 같았다. 앱 코드나 서버 실행 환경도 교체하지 않았다. 이번 결과로 477종목의 20·60·120일 가격 브레스 계산을 진행할 수 있다.
