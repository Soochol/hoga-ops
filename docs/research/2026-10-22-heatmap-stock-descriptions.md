# 히트맵 종목 설명 — 2026-10-22

사용자가 승인한 간결형 툴팁의 문구·데이터 기준.

- 대상: 실행 중인 `/api/heatmap`에서 확인한 48개 그룹, 347개 등록, 330개 고유 Code.
- `frontend/src/heatmap/stockDescriptionUniverse.json`에 당시의 고유 코드 집합을 보존한다.
- `frontend/src/heatmap/stockDescriptions.json`에 각 회사의 이름·직접 작성한 2줄 소개·출처 URL을 보존한다.
- 모든 330개 Code에 대해 KRX KIND 회사개요를 조회하고 응답의 종목코드 일치를 확인했다.
  법인명과 상장 약명은 다를 수 있다. 화면 이름은 당시 히트맵 이름을 기준으로 한다.
- 주요 제품이 비어 있거나 회사개요가 과거 사업을 담은 경우 회사의 사업보고서·IR·제품
  소개를 추가로 참고했다. 한화비전·HD건설기계·SK이터닉스·멜콘·엘리스·덕산넵코어스 등은
  별도 자료를 대조했다. 추가 자료도 각 항목의 `sources`에 남긴다.
- 문구는 사업·제품·용도의 개요다. 테마 그룹에 들어 있다는 이유만으로 해당 사업의
  매출·양산·고객 관계를 확정하지 않는다. 의약품 연구개발과 상용 판매도 구분한다.
- 현재가·실적 숫자·점유율·목표주가·상승 전망은 문구에 넣지 않는다.

한 종목의 정체성은 Code다. 그룹·표시 이름에 따라 다른 소개를 만들지 않는다.
알파벳이 포함된 국내 Code `0158S0`도 보존한다. 새 종목 추가 시 출처를 확인해
문구를 작성하고, 검토 대상 코드 집합을 함께 갱신한다. 미등록 종목에는 임의의
테마 설명을 대신 표시하지 않는다.

본문은 기존 sm 글자와 20rem 툴팁에서 2~3개 시각적 줄을 목표로 작성했다.

확인한다. 수집일 안내는 소개 본문과 구분한 하단 보조 영역이며 본문 줄 수에 포함하지 않는다.
